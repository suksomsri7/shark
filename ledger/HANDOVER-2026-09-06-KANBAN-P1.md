## บัคที่ Fable หาเจอเองระหว่างตรวจรับ (นอกเหนือจาก oracle)
- K1.7 ติ๊ก 2 ข้อสุดท้ายพร้อมกัน → event "เช็คลิสต์ครบ" หาย → ล็อกแถว `FOR UPDATE`
- K1.8 `notify.ts` import env แบบ static → ทุกที่ที่โหลดโมดูลต้องมี env (pre-commit ตก) → lazy import
- K1.9 server action body ปริยาย 1MB → ไฟล์ >1MB ล้มบน prod ทั้งบอร์ดและแชท → `bodySizeLimit 12mb`
- K1.11 พิมพ์ `%`/`_` ในค้นหาเห็นทุกใบ (LIKE wildcard) → escape
- oracle ของ Fable เองผิด 4 จุด (builder แย้งพร้อมหลักฐาน ตรวจแล้วแก้): K1.11 due=none 6→7 · K1.13 สัปดาห์ Mon–Sun ของ 30 ก.ย. 2569 · K1.13 คอลัมน์เสร็จของบอร์ดซ่อม · K1.15 Response.text() ลอก BOM
- builder หาเจอเอง: seed QC ถูก spec ภาพ 1.5 ลากจนกล่องงานเข้าเหลือ 0 (คืนแล้ว + harness snapshot/restore) · webhooks/labels ประกาศ event ซ้ำ · toLocaleString ในหน้าคลัง (hydration) · ปัดชนกับ scroll แนวนอน
