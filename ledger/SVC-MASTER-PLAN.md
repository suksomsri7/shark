**ทำไมหอช้ากว่าเป้า**: (1) เส้นวิกฤตหอเป็นเส้นเงินต่อกันยาว R0.1 → R0.8 → D.0 → D.2 บัญชี → D.5 สัญญา → D.8 รอบบิล → D.9 LINE → D.10 สลิป → D.15 ≈ 17 วันเลนแม้มีเลนเปล่าตลอด (≈ 3.3 สัปดาห์ที่ 85%) และเกือบทุกใบเป็น "เข้ม" (2 รอบ reviewer) ตามกติกาที่ห้ามตัด · (2) 3 เลนต้องแบ่งให้ร้านตัดผมที่ขอเร็วกว่า · (3) ชิ้น "ตั้งค่าได้ทุกข้อ" + ศูนย์ฯ + กฎหมาย สคบ. เพิ่มจากแบบรอบแรก ~2 สัปดาห์-เลนรวม
