## 2. Contract
R1 **Route `/app/me/hr`** (HQ30 default; the employee fixes the HR system ⇒ no `[id]`): `layout.tsx` · `page.tsx` (วันนี้) · `week/` · `requests/` · `pay/` · `profile/` (ฉัน). Tab bar (07a) fixed bottom < `lg`, top strip ≥ `lg`, page-local (shell untouched).
R2 **Facade `hr/self.ts`** (server only, not "use server"). Every export takes `actor: SelfActor = {tenantId, userId, role, unitAccess, permissions}` first, `opts: {now?}` last (oracle only). One resolver **`resolveSelf(actor)`** → `employeeOfUser` → `{employeeId, systemId, name, active, unitId}`; **every export calls it — nothing else picks the employee or HR system.** Any `employeeId`/`userId`/`systemId`/`tenantId` inside `input` (or extra keys on `actor`) is ignored. The only foreign id accepted is the swap peer (R9). Object ids (leave/OT/swap/correction/advance/note) must be own, checked **before** the underlying call, else `SELF_TEXT.notFound` (same bytes: missing · other employee · branch · tenant). Unlinked ⇒ `{ok:false, reason: noEmployee}` from every export (never throws, never writes). ENDED/inactive ⇒ writers `inactive` (no write); readers still return own history (R11).
R3 **`hr/self-actions.ts`** ("use server"): async wrappers only = `requireTenant()` + `requireMembership` → actor from the session → facade; reads **no** `employeeId|userId|systemId|tenantId` form field; no DB import; no `now:`.
R4 **Readers** (DTO keys exact; `ok:true` plus):
- `mySelf` → `active name position unitName`.
- `myToday(actor, opts)` → `day shift clock colleagues`; `shift` = own **published** entry of the Bangkok day `{shiftName startMin endMin breakMin crossesMidnight unitName}` | null; `clock` = `myClockState` result verbatim; `colleagues[]` = other active, not ENDED employees with a published entry the same day, same unit, overlapping time, not on APPROVED full-day leave: keys **`name position shiftName startMin endMin`** (≤ 20).
- `myWeek(actor, {week?}, opts)` → `weekStart days[7]`; day `{date entries[] leave holiday}`; entry `{shiftName startMin endMin crossesMidnight unitName}` published only; `leave` = own `{label half}` (PENDING/APPROVED) | null; `holiday` name | null; `week` any day ⇒ Monday; clamp to −4…+8 weeks.
- `myRequests(actor, opts)` → `leaves ot swaps corrections advances`; keys: leave `id policyName type fromDate toDate days halfDay hours status statusText canCancel createdAt` (no `reason`, Q3) · ot `id date start end minutes status timing amountSatang canCancel` · swap `id role status fromDate fromShiftName toDate toShiftName peerName canRespond canCancel` · correction `id action kind day proposedAt status canCancel` · advance `id periodKey amountSatang status canCancel createdAt`. `statusText` = H2.7 D4 / H2.6 D6.
- `myBalances(actor, {year?})` → `items` = `myLeaveBalances` items (keys of `LeaveBalanceItem`).
- `myLeaveForm(actor, opts)` → `policies[{id name category allowHalfDay allowHours}]` + `balances`; `myLeavePreview(actor, {policyId fromDate toDate halfDay hours})` → `days shifts[{date shiftName}] availableAfter` (own shifts only — 07b "กระทบกะ"; **never** H4.1 booking impact).
- `mySwapTargets(actor, {fromEntryId})` → `items[{employeeId name position entryId shiftName}]` peers of the same unit/day, active; only for the actor's own future published entry, else notFound.
- `myCorrectablePunches(actor, {from,to})` → `correctablePunches` with no employee ids passed.
- `myDocuments(actor)` → `payslips[{runId periodKey status netSatang href}]` (APPROVED/PAID own items, `href` = existing slip route) · `notes` = `myReviewNotes` items · `certificate: null` (H3.8 slot) · `myRequestsSlot: null` (H4.6 slot).
R5 **Writers** (return `{ok:true, …} | {ok:false, reason}`; refusals = the underlying Thai text byte-identical, plus SELF_TEXT):
`selfClock(actor, {kind, latitude, longitude, accuracy, deviceId})` → `mobileClock` · `selfRequestLeave(actor, {policyId, fromDate, toDate, halfDay?, hours?, reason?})` → `requestLeave(ownCtx, {employeeId: own, actorUserId: userId, …})`, refusal = `leaveRefusalText(e)` ?? the `HrLeaveRequestError` message — **no `hr.leave.request` key needed** (identity is the gate, REVIEW #14) · `selfCancelLeave(actor, leaveId)` → `cancelLeave` · `selfRequestOt(actor, {date,start,end,reason})` → `requestOt` without `employeeId` · `selfCancelOt` → `cancelOtRequest` · `selfRequestSwap(actor, {fromEntryId, targetEmployeeId, toEntryId?, reason?})` → `requestSwap` (target must be in `mySwapTargets`, else notFound) · `selfRespondSwap(actor, swapId, accept)` / `selfCancelSwap` → `respondSwap`/`cancelSwap` · `selfRequestCorrection(actor, {action, attendanceId?, kind?, at?, reason})` → `requestCorrection` self mode · `selfCancelCorrection` · `selfRequestAdvance` / `selfCancelAdvance` (R6) · `selfAcknowledgeNote(actor, noteId)` → `acknowledgeReviewNote`.
