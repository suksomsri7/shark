## 3. Contract
R1 **Migration** (additive, Prisma models in `payroll.prisma`, `sys()` in `core/scope.ts`, entries in `scripts/hr-qc-env.mts`):
`HrBankProfile {id, tenantId, systemId UNIQUE, debitBankCode, debitAccountNo, debitBranchCode, companyNameEn, ktbCompanyId, formatsEnabled text[] NOT NULL DEFAULT '{}', updatedById, createdAt, updatedAt}` CHECKs: bank ∈ {002,004,006,014} · account `^[0-9]{10}$` · branch `^[0-9]{4}$` · company ≤ 50 · ktbCompanyId ≤ 16 · formats ⊆ {KBANK_PCT,KTB_IPAY}.
`HrBankExportPreset {id, tenantId, systemId, name 1–60, kind CSV|XLSX, columnsJson jsonb, includeHeader bool DEFAULT true, includeSummary bool DEFAULT false, amountStyle, dateStyle, encoding, createdById, createdAt, updatedAt}` UNIQUE (systemId, name).
`HrBankFile {id, tenantId, systemId, runId (no FK), format, optionsJson jsonb (resolved mapping, no account data), fileName, byteLength int, sha256 text, itemCount int, totalSatang int, excludedCount int, createdById NOT NULL, createdAt, expiresAt NOT NULL, downloads int DEFAULT 0}` index (systemId, runId). **No HrEmployee/HrPayrollRun/HrPayrollItem column changes; `bankFileKey` stays unread/unwritten (Q3).**
R2 **Pure layer** `hr/bank-files/{build,codes,encode,kbank,ktb,generic,xlsx}.ts` — imports only each other + `node:zlib`; no db, no clock, no random. One entry: `buildBankFile({run, payees, profile, options, now}) → {ok:true, bytes: Uint8Array, fileName, contentType, itemCount, totalSatang, notIncluded:[{employeeId, cause, netSatang}], warnings:[{employeeId|null, code}]} | {ok:false, code, text, employees:[{employeeId,name}], notIncluded?}`. `run {runId periodKey payDate "YYYY-MM-DD" status totalNetSatang}`, payee `{employeeId name code bankName accountNo accountName netSatang paymentRef?}` (input order = file order), profile as R1 (or null). Exports also `BANK_TEXT`, `BANK_PRESETS`, `resolveBankCode`. Fixture shapes = `hr-h3.5-vectors.json`.
R3 **Run checks (in order):** status ∉ {APPROVED,PAID} ⇒ `STATUS` · any net < 0 ⇒ `NEGATIVE` · Σ payee net ≠ totalNetSatang ⇒ `MISMATCH` · options ⇒ `OPTIONS` · profile fields the format needs ⇒ `PROFILE`. Then selection, then encoding/formula ⇒ `ENCODING`/`FORMULA` (list every offending employee, file order) · nothing selected ⇒ `EMPTY` (with notIncluded). **Integer satang, formatted at the edge; Σ file + Σ notIncluded = totalNetSatang.**
R4 **Selection** per payee, first match wins: net = 0 `NET_ZERO` · account blank/null `NO_ACCOUNT` · digits after removing spaces and `-` not `^\d{10}$` (fixed formats) / `^\d{10,15}$` (generic) `ACCOUNT_FORMAT` · fixed formats: bank unresolved `BANK_UNKNOWN` · PCT bank ≠ 004, DIRECT ≠ 006 `NOT_THIS_BANK` · STANDARD = 006 `SAME_BANK`. `resolveBankCode`: lowercase, drop whitespace, drop prefix `ธนาคาร`/`ธ.`, drop `-` `.`, drop suffixes `จำกัด(มหาชน)` `(มหาชน)` `จำกัด` `publiccompanylimited` `pcl`; aliases 002 {กรุงเทพ, bangkokbank, bbl} · 004 {กสิกรไทย, กสิกร, kasikorn, kasikornbank, kbank} · 006 {กรุงไทย, krungthai, krungthaibank, ktb} · 014 {ไทยพาณิชย์, siamcommercial, siamcommercialbank, scb} · literal 002/004/006/014; else null (only these four codes are [V]; Q5). Payee name = `accountName` trimmed, else `name` + warning `NAME_FROM_PROFILE`; included payees sharing account digits ⇒ `DUP_ACCOUNT` each.
R5 **KBANK_PCT** exactly the research A1 tables (header 178, detail 487, CRLF after every line incl. last): batch ref `options.batchRef` (`^[A-Za-z0-9]{1,16}$`, default `HR`+YYYYMM), file date = Bangkok day of `now` `yyMMdd` CE, effective `yyMMdd` CE, names cut to 50 (`NAME_CUT`), company = `companyNameEn` (≤ 50, required) and debit account (bank 004 required). Warn `OVER_LIMIT` > 3,000,000.00 [V]. File name `PCT`+`yyMMddHHmmss`(BKK `now`)+`.txt` (≤ 15 + ext, [V]).
R6 **KTB_IPAY** exactly OCA (research A4 tables): batch `000001`, company ID 16, debit bank 006 + branch 4 + account (zero-padded 11), sender name = `companyNameEn` (≤ 100), service `01` STANDARD / `02` DIRECT, ref = `paymentRef` (default `HR`+YYYYMM+`-`+4-digit seq), running no. 1-based, **truncate** names to 100 (`NAME_CUT`). Unknowns are options, each tested both ways: `ktbDateEra` CE (default, OCA) | BE · `ktbReceivingBranch` SPACES (default, OCA: no branch code) | ZEROS. File name `KTB_IPAY_<YYYYMM>_<yyMMddHHmmss>.txt`.
R7 **Encoding** (fixed formats) `ASCII` | `TIS620` (default; ASCII is a subset). Width = characters = bytes. UTF-8 is **not offered** for fixed formats (pad rule [U]). A name/company char outside the set (incl. tab/CR/LF) ⇒ refusal, never replaced. Content types: `text/plain; charset=us-ascii` | `text/plain; charset=windows-874`.
R8 **Generic** columns from `field` ∈ {seq, employeeCode, employeeName, payeeName, bankName, bankCode, accountNo, amount, effectiveDate, paymentRef, blank, `const:<1–40 printable>`} with a header text each (≤ 60). `amountStyle` BAHT_2DP (`15000.00`, no separators) | SATANG · `dateStyle` ISO_CE | DMY_CE | DMY_BE · `encoding` UTF8_BOM | TIS620 (CSV) · header row on/off · summary rows (`จำนวนรายการ,<n>` and `ยอดรวม,<total in amountStyle>`) on/off. CSV: `,` · CRLF incl. last · quote a cell containing `,` `"` CR LF or edge spaces (`""` escape). Any written cell starting with `=` `+` `-` `@` ⇒ `FORMULA`. `BANK_UNKNOWN` is a warning here. XLSX: one sheet, same rows, every cell a string with number format 49 (Text), readable by `parseImportFile`. Presets `GENERIC` and `KTB_BUSINESS` = exact columns of vectors G5A/G7. File name `HR_<YYYYMM>_<yyMMddHHmmss>.csv|.xlsx`.
R9 **Service** `hr/bank-files/service.ts` (server only): `getBankProfile`, `saveBankProfile`, `listBankPresets`, `saveBankPreset`, `deleteBankPreset`, `previewBankFile`, `generateBankFile`, `downloadBankFile`, `listBankFiles` — `(ctx, viewer, input, opts?)` — shapes `wo-notes/hr-H3.5-oracle.md` §2 (part of this brief); `opts.now` oracle only. Payee order = `code` (null last) → `name` → `employeeId`, JS code-unit compare. Effective date default = Bangkok day of `payDate`; earlier than file date ⇒ warning `EFFECTIVE_PAST`. Run + items + employees read in one tx with the run row `FOR SHARE`. **Generating never changes the run** (no run/item/adjustment/outbox write).
R10 **Gate** (generate/preview/download/list/presets) = OWNER ∨ (`permissions["hr.payroll.read"] === true` ∧ `permissions["hr.payroll.pay"] === true` ∧ all-branch scope). Role MANAGER alone never. Profile write = OWNER (`profileOwner`); profile read: OWNER gets `debitAccountNo`, gate holders `debitAccountMasked` only. Unknown/other tenant/other system/non-holder ⇒ `{ok:false, code:"NO", reason: no}` identical bytes. Enabling a fixed format needs `acknowledgeUntested: true` (`ackUntested`); generating a disabled one ⇒ `formatOff`.
R11 **Storage = none (Q2).** `generateBankFile` writes one `HrBankFile` manifest (sha256 of bytes, counts, totals, resolved options, `createdAt` = now, `expiresAt` = now + 7 days). `downloadBankFile` rebuilds with the manifest options and `now = createdAt`: run not APPROVED/PAID ⇒ `status` · past `expiresAt` ⇒ `expired` · sha ≠ ⇒ `changed` · else bytes, `downloads + 1`.
R12 **Audit** (`writeAudit`, targetType `HrPayrollRun`, targetId runId): `hr.bankfile.generate` and `hr.bankfile.download`, `after` keys exactly `fileId format itemCount totalSatang excludedCount`; `hr.bankfile.profile` after `{formatsEnabled}`; `hr.bankfile.preset` after `{presetId, op}`. **No account number, name or byte content in audit, logs, outbox, manifest.**
R13 **DTOs** (keys exact): preview `{ok, itemCount, totalSatang, runNetSatang, rows, notIncluded, warnings, untested}` · row `seq employeeId name bankCode accountMasked amountSatang` (`accountMasked` = `•••`+last 4) · notIncluded `employeeId name cause netSatang` · warning `employeeId name warning` · file list row `id format fileName itemCount totalSatang excludedCount createdAt expiresAt createdByName downloads`. None carries an HR_FORBIDDEN_DTO_KEY.
R14 **Actions + route.** `hr/bank-files/actions.ts` ("use server"): save profile, save/delete preset, generate (then redirect to the route). Route `src/app/app/sys/[id]/hr/payroll/bank-file/[fileId]/route.ts` GET → `downloadBankFile`; headers `Content-Disposition: attachment`, `Cache-Control: no-store`, `X-Content-Type-Options: nosniff`; refusal = fixed text, no bytes.
