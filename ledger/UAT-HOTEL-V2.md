# แพ็ก UAT — ระบบโรงแรม V2 (SHARK · เฟส H)

> ผู้คุม RUN HOTEL · ร่าง 8 พ.ย. 2569 · สำหรับเจ้าของ/ลูกค้าโรงแรมรายแรกทดลองก่อนเปิดใช้จริง
> โค้ดอยู่ที่ branch `session/svc` (ยังไม่ขึ้น main · ยังไม่ deploy) · ทดลองบนร้านตัวอย่าง "บ้านสวน โฮเทล" (14 ห้อง · 3 ประเภท) ในฐาน QC

## 0. ⛔ ต้องทำก่อนเปิดใช้จริง (go-live blockers)
1. **ไฟล์ส่วนตัวบน CDN (Bunny) ยังไม่มีรหัสป้องกัน** — รูปบัตร/พาสปอร์ต/ลายเซ็น/สลิป ต้องตั้ง token auth ของ pull zone ก่อน (Q-H4-3)
2. **ปิดวันอัตโนมัติเปิดเป็นค่าเริ่ม** — คืนแรกที่เปิดใช้ ระบบจะปิด "เมื่อวาน" เองตอนตีสาม ตั้ง "ไม่มา" + ริบมัดจำตามนโยบาย · เลือกก่อนว่าจะเปิดอัตโนมัติ หรือให้พนักงานกดปิดเองช่วงแรก (Q-H7-1)
3. **กันบอทจองหน้าเว็บ (Turnstile) ยังไม่มีคีย์** — ตอนนี้ใช้เพดาน "ถือห้องรอจ่ายได้ไม่เกินครึ่งหนึ่งของห้องประเภทนั้นต่อคืน" + จำกัดต่อเครื่องแทน (Q-H8-1)
4. **เชื่อม OTA เจ้าจริง (Agoda/Booking ผ่าน channel manager) ยังไม่เปิด** — มีแค่ตัวต่อทดสอบ · ก่อนเปิดต้องปิดงาน H.5b (การจองที่ OTA เก็บเงินแล้วต้องไม่ถูกเก็บค่าห้องซ้ำที่เคาน์เตอร์)
5. **คูปองหน้าเว็บ** จดไว้ตอนจองแต่ยังไม่หักตอนเช็กเอาต์ (H.5b)

## 1. ไล่ทดลองต่อบทบาท (เช็กลิสต์)
### เจ้าของ / ผู้จัดการ
- [ ] **ราคา**: ปฏิทินราคา 14 วัน · แก้ราคาวันเดียว (เช่น ส. ฿1,690) · แผนราคา 3 แบบ (มาตรฐาน · รวมอาหารเช้า · จ่ายก่อนไม่คืนเงิน) · ฤดู/วันหยุด
- [ ] **ตั้งค่าโรงแรม**: การ์ด 11 ใบ · เวลาเช็กอิน/เอาต์ · นโยบายยกเลิก · มัดจำ · ปิดวันอัตโนมัติ · ใบอนุญาตโรงแรม (ใช้บนบัตร ร.ร.3/ร.ร.4)
- [ ] **ปฏิทินห้อง (tape chart)**: แถบการจองทุกสถานะ · ปิดห้องซ่อม · ย้ายห้อง/เลื่อนวัน
- [ ] **รายงาน**: อัตราเข้าพัก · ADR · RevPAR · รายได้ (แยกแหล่ง/แผน/ประเภท) · ล่วงหน้า 30 วัน · แม่บ้าน · มัดจำ · ส่งออก CSV
- [ ] **ปิดวัน**: ดูตัวอย่าง (ไม่มา · ลงค่าห้อง · ห้องค้างต่อ) → ปิดวัน → ประวัติ · เปิดวันซ้ำ (ผู้จัดการ) แล้วปิดใหม่
- [ ] **ช่องทาง OTA** (ทดสอบ): แม็ปห้อง/แผน · markup · buffer · คิว "ต้องจัดห้อง"
### หน้าเคาน์เตอร์
- [ ] **จองใหม่** 3 ขั้น (เลือกวัน/ห้อง → แขก → มัดจำ 5 วิธี) · จองกลุ่ม · ยกเลิกตามขั้นบันได
- [ ] **เช็กอิน**: ห้อง → ลงทะเบียนผู้พัก (ไทย = บัตร 13 หลัก · ต่างชาติ = พาสปอร์ต) → แขกลงชื่อบนแท็บเล็ต (ร.ร.3) → เงินประกันห้อง
- [ ] **ตม.30**: คิวแขกต่างชาติ · ดาวน์โหลดไฟล์อัปโหลด · บันทึกเลขรับแจ้ง · ป้ายแดงเมื่อเลย 24 ชม.
- [ ] **ทะเบียนผู้พัก (ร.ร.4)**: พิมพ์/บันทึก PDF · เลขเอกสารเห็น 4 ตัวท้าย (เปิดเต็มต้องมีสิทธิ์ + มีบันทึก)
- [ ] **บิลระหว่างพัก (folio)**: ค่าห้อง · ลงห้องจาก POS (ร้านอาหาร/มินิบาร์) · void · **เช็กเอาต์** รับเงิน 5 วิธี → บิล POS 1 ใบ → ลงบัญชีอัตโนมัติ
- [ ] **สลิปมัดจำจากเว็บ**: แถบ "สลิปรอตรวจ" → อนุมัติ/ปฏิเสธ · "มัดจำรับไม่ครบ"
### แม่บ้าน (มือถือ)
- [ ] งานห้องวันนี้ (ของฉัน/ทั้งหมด/เสร็จ) · ด่วนก่อน · เริ่มทำ → เช็กลิสต์ → มินิบาร์ลงบิลห้อง → เสร็จ · ส่งตรวจ
- [ ] หัวหน้าแม่บ้าน: ตรวจห้อง → ขายได้ · แจ้งของเสีย → ปิดห้อง/แจ้งช่าง
### แขก (หน้าเว็บ · มือถือ · ไทย/อังกฤษ)
- [ ] ค้นหา → เห็นราคารวมตามคืนจริง + "เหลือ N ห้อง" + ห้องเต็มบอกคืนที่เต็ม
- [ ] จอง → ถือห้อง 15 นาที → QR พร้อมเพย์ยอดล็อก → แนบสลิป → โรงแรมอนุมัติ → หน้าสถานะ "จองสำเร็จ"
- [ ] ยกเลิกเองจากลิงก์ (เฉพาะจองผ่านเว็บ/LINE · ระหว่างสลิปรอตรวจยกเลิกไม่ได้) · ดูการจองของฉันด้วยรหัส+อีเมล
