**แนวทาง 3 ชั้น**
1. **ชั้นเอเจนซี่** «src/lib/modules/agency/» — ตัวเดียวใช้กับตั๋ว ทัวร์ Liveaboard และ (ภายหลัง) โรงแรม
2. **แกนรอบเดินทาง** «src/lib/modules/trips/» — สินค้า → ตัวเลือก → รอบ → หน่วยที่ขาย → จอง → ผู้เดินทาง → งวดจ่าย ใช้ร่วมกันระหว่างทัวร์กับ Liveaboard

## 2. ชั้นเอเจนซี่ (ใช้ร่วมทั้ง 3 ระบบ)

### 2.1 ประเภทผู้ขาย
| ประเภท | ตัวอย่าง | ลักษณะ |
|---|---|---|
| เอเจนซี่ท่องเที่ยว | บริษัททัวร์ ร้านดำน้ำอื่น | มีสัญญา ราคาเน็ตหรือคอมมิชชัน มีเครดิต |
| เคาน์เตอร์/โต๊ะทัวร์ | โรงแรม ร้านริมหาด | ขายหน้าร้าน เก็บเงินลูกค้าเอง ส่งยอดเน็ต |
| ตัวแทนอิสระ | ไกด์ ครูสอนดำน้ำ อินฟลูเอนเซอร์ | ลิงก์/รหัสแนะนำ รับคอมมิชชัน ไม่มีเครดิต |
| ช่องทางออนไลน์ | Klook · KKday · GetYourGuide · Viator · liveaboard.com | ต่อผ่านศูนย์เชื่อมต่อ ไม่ใช้พอร์ทัล |
| ลูกค้าองค์กร | บริษัทจัดเอาต์ติ้ง โรงเรียน | ราคาสัญญา วางบิล |
| เอเจนซี่ย่อย | ตัวแทนของเอเจนซี่ | คอมมิชชัน 2 ชั้น (เฟส 2) |

ข้อมูลเอเจนซี่: ชื่อนิติบุคคล · เลขภาษี · **เลขใบอนุญาตนำเที่ยว + วันหมดอายุ** · ผู้ติดต่อ · บัญชีธนาคาร · สกุลเงิน · ระดับ (A/B/C) · สถานะ (รออนุมัติ / ใช้งาน / ระงับ) · เอกสารแนบ · ผู้ดูแลฝั่งเรา

### 2.2 รูปแบบราคา (หัวใจของระบบ)
รองรับ 3 แบบ ตั้งได้ต่อเอเจนซี่ ต่อสินค้า:

| แบบ | เอเจนซี่จ่ายเรา | ราคาที่ลูกค้าจ่าย | ใช้กับ |
|---|---|---|---|
| **ราคาเน็ต** | ราคาเน็ตตามสัญญา | เอเจนซี่ตั้งเอง (กำหนดราคาขายขั้นต่ำได้ กันตัดราคา) | เอเจนซี่ท่องเที่ยว เคาน์เตอร์ |
| **คอมมิชชัน** | ราคาขายปลีก − คอมมิชชัน (% หรือบาทต่อคน) | ราคาขายปลีกของเรา | ตัวแทนอิสระ ช่องทางออนไลน์ |
| **บวกเพิ่ม** | ราคาเน็ต | เน็ต + ส่วนบวกที่เราอนุญาตไม่เกินเพดาน | ลูกค้าองค์กร เอเจนซี่ย่อย |

**มิติของราคา** (ทุกแบบ)
- ประเภทคน: ผู้ใหญ่ · เด็ก (ช่วงอายุตั้งได้) · ทารก · คนไทย/ต่างชาติ · นักดำน้ำ/ไม่ดำน้ำ
- หน่วยที่ขาย: ที่นั่ง · ประเภทตั๋ว · ประเภทเคบิน (ต่อเตียง / เหมาห้อง / พักเดี่ยวจ่ายเพิ่ม) · เหมาลำ
- ฤดูกาล · วันในสัปดาห์ · รอบเฉพาะ (ราคาทับรายรอบ)
- ช่วงวันที่จอง และช่วงวันที่เดินทาง แยกกัน · วันห้ามใช้ราคา
- จองล่วงหน้า (early bird) · นาทีสุดท้าย · ขนาดกลุ่ม (ขั้นบันได) · **ฟรีหัวหน้ากลุ่ม** (เช่น 10 จ่าย 1 ฟรี)
- สกุลเงิน: บาทเป็นหลัก ตั้งราคา USD/EUR แยกได้ ล็อกอัตราแลกเปลี่ยน ณ วันจอง

**รายการเสริมและค่าธรรมเนียม** — ทุกบรรทัดมีธง 2 ตัว: "คิดคอมมิชชันไหม" และ "ลดได้ไหม"
ค่าอุทยาน ค่าท่าเรือ ค่าน้ำมัน = ไม่คิดคอมมิชชัน ไม่ลด · เช่าอุปกรณ์ ไนตร็อกซ์ รถรับส่ง = ตั้งได้

**ลำดับการเลือกราคา** (ตัวท้ายชนะ)
`ราคาขายปลีก → ฤดูกาล/รอบ → ระดับเอเจนซี่ (A/B/C) → สัญญาเฉพาะเอเจนซี่ → โปรโมชันที่เอเจนซี่มีสิทธิ์ → ราคาแก้มือ (ต้องมีสิทธิ์ + เหตุผล + อนุมัติถ้าเกินเพดาน)`

ตัวอย่าง: ทริปเดย์ทริป ขายปลีก 3,500 + ค่าอุทยาน 600
- เอเจนซี่ระดับ B คอมมิชชัน 15% → คอมฯ 525 (คิดจาก 3,500 เท่านั้น) เอเจนซี่ส่งเรา 3,575
- เอเจนซี่ X สัญญาเน็ต 2,800 → ส่งเรา 3,400 ขายลูกค้าเท่าไรก็ได้แต่ไม่ต่ำกว่า 3,300 + 600

ราคาที่ใช้จริงถูกจดลง `policySnapshot` ของการจอง แก้สัญญาภายหลังไม่กระทบการจองเดิม

### 2.3 โควตาและการถือที่
| ฟังก์ชัน | รายละเอียด |
|---|---|
| ขายอิสระ | เอเจนซี่จองได้ทันทีจากที่ว่างรวม |
| โควตาเฉพาะ | กันที่/เคบินให้เอเจนซี่ต่อรอบ หรือเป็นชุดทั้งฤดูกาล |
| วันคืนโควตา | ไม่ขายภายใน N วันก่อนเดินทาง → คืนเข้าที่ว่างรวมอัตโนมัติ |
| ต้องขอก่อน | เอเจนซี่ส่งคำขอ ร้านยืนยันภายในเวลาที่ตั้ง ไม่ตอบ = หมดอายุ |
| ถือที่ชั่วคราว | ถือได้ N ชั่วโมง/วันโดยยังไม่จ่าย (Liveaboard มักให้ 3–7 วัน) หมดเวลาปล่อยอัตโนมัติ จำกัดจำนวนที่ถือพร้อมกันต่อเอเจนซี่ |
| หยุดขาย | ปิดต่อรอบ ต่อเอเจนซี่ ต่อช่องทาง |
| โควตาต่อช่องทาง | แบ่งที่ระหว่างเว็บ หน้าร้าน เอเจนซี่ ช่องทางออนไลน์ |
| กันขายเกิน | ตัดที่ในคำสั่ง SQL เดียว (บทเรียนตัวนับร่วม) |

### 2.4 เงิน เครดิต และการปิดยอด
- **ใครเก็บเงินลูกค้า** ตั้งต่อเอเจนซี่: (ก) เอเจนซี่เก็บ แล้วส่งยอดเน็ตให้เรา (ข) เราเก็บ แล้วจ่ายคอมมิชชันให้เอเจนซี่
- **วิธีจ่ายของเอเจนซี่**: จ่ายทันทีต่อการจอง · กระเป๋าเงินเติมล่วงหน้า · วงเงินเครดิต + เทอม (7/15/30 วัน)
- เกินวงเงินหรือค้างเกินกำหนด → บล็อกการจองใหม่อัตโนมัติ (ตั้งได้ว่าบล็อกหรือแค่เตือน)
- **ใบแจ้งยอดรายงวด** (รายสัปดาห์/เดือน) รวมการจอง ยกเลิก ปรับปรุง → ออกใบแจ้งหนี้ในระบบบัญชี
- **รอบจ่ายคอมมิชชัน**: คิดเมื่อลูกค้าเดินทางแล้ว (ไม่ใช่ตอนจอง) · หัก ณ ที่จ่าย 3% · ออกหนังสือรับรอง · ยกเลิก = ดึงคอมมิชชันคืน
- มัดจำและงวดจ่ายตามสัญญาเอเจนซี่ (ต่างจากลูกค้าตรงได้)
- นโยบายยกเลิก/เลื่อน/เปลี่ยนชื่อ ต่อสัญญาเอเจนซี่
- สมุดบัญชีเอเจนซี่แบบต่อท้ายอย่างเดียว ทุกรายการอ้างการจอง

### 2.5 พอร์ทัลเอเจนซี่
- สมัครเอง → ร้านอนุมัติ · ผู้ใช้หลายคนต่อเอเจนซี่ มีบทบาท (เจ้าของ / พนักงานขาย / บัญชี)
- ค้นที่ว่างสด เห็นเฉพาะสินค้าและราคาที่ตัวเองมีสิทธิ์
- จอง · ถือที่ · แก้ไข · ยกเลิก · กรอกรายชื่อผู้เดินทาง · ส่งลิงก์ให้ลูกค้ากรอกเอง
- ใบยืนยัน/วอเชอร์ใส่โลโก้เอเจนซี่ ซ่อนราคาได้
- ดูยอดค้าง ใบแจ้งยอด จ่ายเงิน เติมกระเป๋า ดูคอมมิชชัน
- คลังสื่อการขาย: รูป คำบรรยาย ตารางรอบ ไฟล์ราคา
- ลิงก์ขาย/QR/วิดเจ็ตติดรหัสเอเจนซี่ (สำหรับตัวแทนอิสระ)
- คีย์ API + webhook สำหรับเอเจนซี่ที่มีระบบของตัวเอง
- แจ้งเตือน: ยืนยันการจอง · ที่ถือใกล้หมดเวลา · งวดจ่ายใกล้ครบ · รอบถูกยกเลิก/เปลี่ยน

### 2.6 ฝั่งร้าน
ทะเบียนเอเจนซี่ · ตัวสร้างสัญญาและตารางราคา (คัดลอกจากระดับ แล้วแก้เฉพาะจุด) · ตารางโควตา · คิวอนุมัติ (คำขอจอง ราคาแก้มือ ขอเครดิตเพิ่ม) · ลูกหนี้เอเจนซี่แยกอายุ · รายงาน: ยอดขายต่อเอเจนซี่ · อัตราใช้โควตา · อัตรายกเลิก · คอมมิชชันค้างจ่าย · กำไรต่อช่องทาง

## 3. แกนรอบเดินทาง (ทัวร์ + Liveaboard)

```
สินค้า → ตัวเลือก → รอบ (วันที่ + ทรัพยากร) → หน่วยที่ขาย (ที่นั่ง / เตียงในเคบิน)
                                  ↓
              ถือที่ → การจอง → รายการ → ผู้เดินทาง → งวดจ่าย → วอเชอร์ QR
```
- **สินค้า**: ชื่อ รูป คำบรรยายหลายภาษา กำหนดการ สิ่งที่รวม/ไม่รวม จุดนัดพบ เงื่อนไข
- **รอบ**: สร้างจากกฎซ้ำ (ทุกวัน / บางวัน / ช่วงวันที่) + ข้อยกเว้น หรือสร้างทีละรอบ · สถานะ: เปิดขาย / ยืนยันออกเดินทาง / เต็ม / ปิด / ยกเลิก
- **ขั้นต่ำออกเดินทาง**: ไม่ถึงภายในเวลาที่ตั้ง → เตือนร้านให้ตัดสิน (รวมรอบ / เลื่อน / คืนเงิน)
- **เวลาปิดรับจอง** ต่อช่องทาง
- **การจอง**: ช่องทาง + เอเจนซี่ + ผู้ขาย · สถานะ: ถือที่ / รอยืนยัน / ยืนยัน / จ่ายบางส่วน / จ่ายครบ / เดินทางแล้ว / ยกเลิก / ไม่มา
- **งวดจ่าย**: มัดจำ + ส่วนที่เหลือตามวันก่อนเดินทาง · เตือนอัตโนมัติ · เลยกำหนดปล่อยที่อัตโนมัติ (ตั้งได้)
- **ยกเลิก**: ตารางขั้นบันไดตามวันก่อนเดินทาง · คืนเป็นเงินหรือเครดิต · ร้านยกเลิกรอบ = ย้ายทั้งรอบหรือคืนทั้งรอบในคำสั่งเดียว
- **ผู้เดินทาง**: แบบฟอร์มตั้งได้ต่อสินค้า · ลิงก์ให้ลูกค้ากรอกเอง · เอกสารสละสิทธิ์เซ็นออนไลน์
- **รายการเสริม**: ต่อคน / ต่อการจอง / ต่อวัน · บังคับหรือเลือกได้
- **ต้นทุนต่อรอบ**: ค่าเรือ ไกด์ อาหาร อุทยาน → กำไรต่อรอบ

## 4. ฟังก์ชันรายระบบ

### 4.1 ระบบจองทัวร์
| กลุ่ม | ฟังก์ชัน |
|---|---|
| สินค้า | ร่วมกลุ่ม / ส่วนตัว / เหมา · ครึ่งวัน เต็มวัน หลายวัน · แพ็กเกจรวมหลายทัวร์ |
| ความจุ | ตามทรัพยากรจริง (เรือ รถตู้ ไกด์) · ทรัพยากรเดียวใช้หลายสินค้าไม่ขายซ้อน |
| รับส่ง | โซนรับส่ง · เวลารับต่อโซน · ค่าบวกเพิ่มนอกโซน · จุดนัดพบ |
| ข้อมูลลูกค้า | โรงแรมที่พัก · อาหารที่แพ้ · ไซซ์อุปกรณ์ · ระดับบัตรดำน้ำ · น้ำหนัก (บางกิจกรรม) |

## 9. หน้าจองสำหรับลูกค้าและเอเจนซี่ + UX/UI (เพิ่ม 11 พ.ย. ตามเจ้าของ)

โจทย์: ร้านไทยขายผ่าน LINE เป็นหลัก ต้องมีหน้าที่ **ลูกค้าจองเอง** และหน้าที่ **เอเจนซี่จองและดูสรุป** เอาไปใส่ LINE (LIFF) ฝังหน้าเว็บ หรือส่งลิงก์ได้ทันที
ภาพ: `ledger/design-trips/` (15 ภาพ · รายละเอียดและตัวเลขใน `design-trips/README.md`)

### 9.1 หน้าชุดเดียว ใช้ได้ 3 ที่
| ช่องทาง | ที่อยู่ | พฤติกรรมเฉพาะ |
|---|---|---|
| ลิงก์ / QR | `shark.in.th/b/<ร้าน>` · `/<สินค้า>` · `?d=<วัน>` | เปิดในเบราว์เซอร์ · ใช้โดเมนของร้านเองได้ |
| LINE (LIFF) | `liff.line.me/<id>` | ไม่ต้องล็อกอิน · เติมชื่อจากโปรไฟล์ · วอเชอร์และแจ้งเตือนเข้าแชท · ผูกกับทะเบียนลูกค้าอัตโนมัติ |
| ฝังเว็บ | `<script src=".../embed.js" data-shop data-product data-mode>` | 3 แบบ: ปุ่ม "จองเลย" (เปิดซ้อน) · ฝังทั้งหน้า · ปฏิทินที่ว่าง · จำกัดโดเมนที่ฝังได้ |
| พอร์ทัลเอเจนซี่ | `shark.in.th/agent/<ร้าน>` (เปิดใน LIFF ได้เช่นกัน) | ต้องล็อกอิน (LINE หรืออีเมล) · หลายผู้ใช้ต่อเอเจนซี่ |

ตัวติดตามในลิงก์: `?a=<รหัสเอเจนซี่>` · `?s=<รหัสพนักงานขาย>` ใช้ได้กับทั้ง 3 ช่องทาง เอเจนซี่จึงเอาหน้าจองของร้านไปใส่ LINE OA หรือเว็บของตัวเองได้ ยอดและคอมมิชชันเข้าเอเจนซี่อัตโนมัติ

### 9.2 หลักคิด
1. **มือถือก่อน** กว้าง 360–430 ใช้นิ้วโป้งมือเดียว ปุ่มหลักอยู่แถบล่างเสมอ จอใหญ่ใช้โครงเดียวกันขยายเป็น 2 คอลัมน์
2. **ราคารวมเห็นตลอด** ที่แถบล่าง ไม่มีค่าใช้จ่ายโผล่ตอนท้าย ค่าอุทยานแยกบรรทัดตั้งแต่หน้าแรก
3. **ไม่บังคับสมัครสมาชิก** ใช้เบอร์โทรหรือ LINE กลับมาดูการจองด้วยลิงก์เดิม
4. **ขั้นน้อยที่สุด**: ตั๋ว 3 ขั้น · ทัวร์ 4 ขั้น · Liveaboard จ่ายมัดจำก่อน ข้อมูลนักดำน้ำกรอกทีหลังได้
5. **หลังจองคือรายการสิ่งที่ต้องทำ** ไม่ใช่แค่ใบยืนยัน (รายชื่อ เอกสาร งวดจ่าย) ร้านไม่ต้องตามทางแชท
6. **สถานะแยกด้วยรูปทรง** ไม่ใช่สีอย่างเดียว (เคบิน: ทึบ / เส้นประ / ลายขีด / กรอบ)
7. **เอเจนซี่เห็น 3 ตัวเลขทุกครั้ง**: เก็บลูกค้า · ส่งร้าน · ฉันได้ และเห็นวงเงินคงเหลือก่อนกดยืนยัน
8. **ไม่มีทางตัน**: ทุกจอผิดปกติบอกว่าเกิดอะไร เงินอยู่ไหน ทำอะไรต่อได้

## 11. ตัวสร้างผังเรือ (เพิ่ม 11 พ.ย. — เจ้าของ: ร้านส่วนมากเป็นเจ้าของเรือเอง ต้องแก้ผังเองได้)

ร้านสร้างและแก้ผังเรือเองทั้งหมด ไม่ต้องให้ทีม SHARK ทำให้ · ภาพ 08 คือผลลัพธ์ของตัวสร้างนี้ (ยังไม่ได้วาดหน้าตัวสร้าง → จอ 09)

| ส่วน | ร้านทำอะไรได้ |
|---|---|
| เรือ | เพิ่มได้หลายลำ · ชื่อ รูป ความยาว จำนวนแขกสูงสุด · คัดลอกเรือเดิมเป็นลำใหม่ |
| ดาดฟ้า | เพิ่ม/ลบ/เรียงลำดับ/ตั้งชื่อเอง (กี่ชั้นก็ได้) |
| เคบิน | ลากวางบนตาราง · ปรับขนาด · ตั้งรหัส (M1, D1…) · ผูกประเภทเคบิน · จำนวนเตียง + แบบเตียง (คู่/เดี่ยว 2/สองชั้น/เตียงเสริม) · ขายแยกเตียงได้หรือไม่ · ห้องน้ำในตัว · รูปถ่ายต่อเคบิน |
| พื้นที่อื่น | ลานดำน้ำ · ห้องอาหาร · ดาดฟ้าอาบแดด · ห้องถือท้าย · ห้องลูกเรือ (ป้ายเท่านั้น ไม่ขาย) |
| ทางเลือกง่าย | ไม่อยากวาด = ใช้ "รายการเคบิน" อย่างเดียว (ระบบจัดเป็นตารางให้) · หรืออัปโหลดรูปผังเรือที่มีอยู่แล้ววางจุดเคบินทับ |
| แม่แบบเริ่มต้น | เรือ 6 / 8 / 10 / 12 เคบิน ให้เลือกแล้วแก้ต่อ |
| ประเภทเคบิน | ร้านตั้งเอง (ชื่อ · คำบรรยาย · ราคาฐาน) — ราคาจริงตั้งที่ทริป/ฤดูกาล |

**กติกาเมื่อแก้ผังที่มีการจองแล้ว**
- ผังมี **เวอร์ชัน** · ทริปจดเวอร์ชันผังตอนสร้าง (หลักเดียวกับ `policySnapshot`) → แก้ผังไม่กระทบทริปที่มีการจองอยู่ โดยค่าเริ่มต้น
- ร้านเลือกได้ว่าเวอร์ชันใหม่ใช้ "ตั้งแต่ทริปวันที่ …" (เช่น หลังขึ้นคานปรับปรุงเรือ)
- ลบหรือลดเตียงของเคบินที่มีแขกในทริปที่จะใช้เวอร์ชันใหม่ → ระบบโชว์รายการจองที่กระทบ ให้ย้ายเคบินก่อน จึงบันทึกได้
- เปลี่ยนชื่อ/รูป/คำบรรยาย มีผลทันทีทุกทริป (ไม่กระทบที่นั่ง)
- ปิดเคบินชั่วคราวต่อทริป (ซ่อม · ให้ลูกเรือ/ไกด์พัก) ทำที่หน้าทริป ไม่ต้องแก้ผัง

### 12.1 จุดอ่อนที่พบในแบบ (แก้ในแบบแล้ว = กติกาด้านล่างถือเป็นส่วนของแบบ)
| # | จุดอ่อน | กติกาที่เพิ่ม |
|---|---|---|
| R1 | **เงินผ่านมือใคร** ไม่เคยเขียนชัด | SHARK **ไม่ถือเงินลูกค้าเลย**: พร้อมเพย์/บัตร/สลิป เข้าบัญชีของร้านโดยตรง (ผ่านตัวเชื่อมที่ร้านตั้งในศูนย์เชื่อมต่อ) · "กระเป๋าเอเจนซี่" = เงินที่เอเจนซี่จ่ายล่วงหน้าให้ร้าน บันทึกเป็นยอดในสมุดบัญชี ไม่ใช่เงินฝากกับ SHARK · คอมมิชชันร้านโอนให้เอเจนซี่เอง ระบบออกรายการและเอกสาร |
| R2 | **ที่ว่างที่ลูกค้าเห็น vs โควตาเอเจนซี่** กำกวม | ที่ว่างสาธารณะ = ความจุ − ขายแล้ว − ถืออยู่ − โควตาเอเจนซี่ที่ยังไม่คืน · เอเจนซี่เห็น = โควตาตัวเองที่เหลือ + ที่ว่างสาธารณะ (ถ้าสัญญาเปิดขายอิสระ) · ตัวเลข "เหลือ N" บนหน้าจองต้องเป็นเลขจริงเสมอ ห้ามปั้นเพื่อเร่งขาย |
| R3 | **ลูกค้าของเอเจนซี่เป็นของใคร** — เอเจนซี่จะไม่ใช้ระบบถ้ากลัวร้านดึงลูกค้า | ค่าเริ่มต้น: ลูกค้าที่จองผ่านเอเจนซี่ (เอเจนซี่เก็บเงิน) **ไม่เข้ารายชื่อการตลาดของร้าน** · ร้านเห็นเฉพาะข้อมูลที่ต้องใช้ให้บริการ (ชื่อ จุดรับ เอกสาร) · ช่องติดต่อแสดงตามที่เอเจนซี่เลือก (ตรง / ผ่านเอเจนซี่) — ภาพ 12 แถว "ผ่านเอเจนซี่" |
| R4 | **ลูกค้าของเอเจนซี่แก้การจองเองได้แค่ไหน** | หน้า "การจองของฉัน" ของการจองผ่านเอเจนซี่: ดูวอเชอร์ + กรอกรายชื่อ/เอกสาร ได้ · เลื่อน/ยกเลิก/คืนเงิน = ติดต่อเอเจนซี่ (ปุ่มเปลี่ยนเป็นช่องทางของเอเจนซี่) · **ไม่แสดงราคา** ถ้าเอเจนซี่ตั้งซ่อนราคา · ร้านยกเลิกรอบ → ตัวเลือก 3 ทาง (ภาพ 07ง) ส่งไปที่เอเจนซี่ ไม่ใช่ลูกค้า |
| R5 | **ใครส่งข้อความหาลูกค้าของเอเจนซี่** | ค่าตั้งต่อสัญญา: ร้านส่งในชื่อร้าน (เริ่มต้นสำหรับลิงก์ขาย) / ร้านส่งเฉพาะข้อความปฏิบัติการ เช่น เวลารับ (เริ่มต้นสำหรับเอเจนซี่เก็บเงิน) / ไม่ส่ง เอเจนซี่ส่งเอง |
| R6 | **แชร์ห้องตามเพศ** แข็งเกิน | ค่าตั้งต่อเรือ: เพศเดียวกันเท่านั้น (เริ่มต้น) / ไม่จำกัด / ร้านยืนยันก่อน · แบบฟอร์มมีตัวเลือก "ไม่ระบุ" → เข้าคิวร้านยืนยัน |
| R7 | **คอมมิชชันของการจองสกุลเงินต่างประเทศ** | คิดและจ่ายในสกุลของการจอง หรือแปลงเป็นบาทด้วยอัตราที่จด ณ วันจอง — ค่าตั้งต่อสัญญา (เริ่มต้น: บาท) |
| R8 | **เด็ก/ผู้สูงอายุ/คนไทย** พิสูจน์อย่างไร | ระบบไม่พิสูจน์ · วอเชอร์/ตั๋วพิมพ์ประเภทชัด + ข้อความ "แสดงหลักฐานที่จุดบริการ" · ไกด์/คนตรวจตั๋วมีปุ่ม "เก็บส่วนต่าง" ลง POS |

## 13. ผลจากการตรวจกฎหมาย → สิ่งที่แบบต้องเปลี่ยน (12 พ.ย. 2569 · อ้าง `LEGAL-TRIPS-TH.md` = LG)

⚠️ LG เป็นการค้นคว้าจากเว็บ ไม่ใช่คำปรึกษากฎหมาย · หลายข้อมาจากแหล่งรองหรือยังไม่ยืนยัน (LG §9 รวม 27 ข้อ) · ทุกข้อด้านล่างเป็น **ค่าเริ่มต้นที่ร้านปรับได้ + คำเตือน** ไม่มีการบล็อก (มติรอบ 3–4)

**ไม่พบข้อมูล (ออกแบบแบบยืดหยุ่นไว้ก่อน):** รูปแบบบัญชีรายชื่อผู้โดยสารของกรมเจ้าท่า · เอกสาร ตม. สำหรับเรือค้างคืน/ออกนอกน่านน้ำ → ใบ L1.10 ทำเป็น "ส่งออกรายชื่อ เลือกคอลัมน์ได้ + แม่แบบที่ร้านอัปโหลด" แทนแบบฟอร์มตายตัว

**ของที่ต้องให้นักบัญชี/ทนายของเจ้าของยืนยัน (O3 · เรียงตามผลกระทบ):**
1. อัตราและแบบยื่นเมื่อจ่ายคอมมิชชันให้ **บุคคลธรรมดา** (ไกด์ · ตัวแทนอิสระ)
2. กรณีเอเจนซี่เก็บเงินแล้วส่งยอดเน็ต — ร้านต้องหัก ณ ที่จ่ายจริงหรือไม่ และยอดส่งคิดอย่างไร (L2)
3. ค่าอุทยานถือเป็นเงินเก็บแทนนอกฐาน VAT ได้หรือไม่ ด้วยหลักฐานแบบ e-ticket
4. แบบ "ราคาเน็ต": เอกสารภาษีของแต่ละฝั่ง (L7)
5. ตารางคืนเงินตามประกาศปี 2563 — ร้านตกลงเข้มกว่าได้หรือไม่ และใช้กับ Liveaboard/ตั๋วไหม
6. SHARK ต้องมีข้อตกลงประมวลผลข้อมูล (DPA) กับร้าน + ที่ตั้งเซิร์ฟเวอร์ต่างประเทศ — เป็นงานเอกสารของ SHARK เอง ไม่ใช่ของระบบ
