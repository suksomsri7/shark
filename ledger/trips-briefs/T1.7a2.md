- `reportQueryOf`: อ่านเฉพาะชื่อใน `REPORT_QUERY_PARAMS` · ค่าอาร์เรย์ใช้ตัวแรก · สตริงว่าง ⇒ ไม่ใส่คีย์ · `product` ⇒ `productId` · `page` = `/^\d{1,4}$/` ⇒ จำนวนเต็ม (อื่น ⇒ ไม่ใส่) · ค่าอื่นส่งต่อเป็นสตริงตามจริง (ตัวโหลดตัดสินรูป) · ไม่มีคีย์อื่นในผล
- `reportRangeOf` (ลำดับตัดสิน): ไม่มีทั้งคู่ ⇒ เดือนของ `today` · มี from อย่างเดียว ⇒ ถึงสิ้นเดือนของ from · มี to อย่างเดียว ⇒ จากต้นเดือนของ to · รูปไม่ใช่ `YYYY-MM-DD` / วันไม่มีจริง / from > to ⇒ `INVALID_INPUT` · `days` (นับรวมปลาย) > 366 ⇒ `RANGE_TOO_LARGE`
- `reportGroupOf`: ≤ 31 ⇒ day · ≤ 92 ⇒ week · อื่น ⇒ month · ผู้ใช้เลือก `group` เองได้ — `day` เมื่อ days ≤ `REPORT_DAY_GROUP_MAX_DAYS` เท่านั้น (เกิน ⇒ `INVALID_INPUT`)
- `reportUtcBoundsOf` (N10 · **คำนวณในโค้ด ไม่ใช้ `AT TIME ZONE` ใน WHERE**): `gte = localToUtc(tz, from, 0)` · `lt = localToUtc(tz, addDaysYmd(to, 1), 0)` — กรุงเทพ เม.ย. 2570 = [2027-03-31T17:00Z, 2027-04-30T17:00Z) · โตเกียว = [2027-03-31T15:00Z, 2027-04-30T15:00Z)
- `reportPresetsOf("2027-04-15")` = thisMonth 04-01..04-30 · lastMonth 03-01..03-31 · last30 03-17..04-15 · next30 04-15..05-14 (ลำดับนี้)
- `periodKeyOf`: day = วันนั้น · week = วันจันทร์ ISO (เสาร์ 10 เม.ย. 2570 ⇒ 2027-04-05 · ศุกร์ 1 ม.ค. 2570 ⇒ 2026-12-28) · month = `YYYY-MM` · `periodsOf` = ช่วงต่อเนื่องครบทุกช่วง (ช่วงไม่มีข้อมูลก็มี) ตัดหัวท้ายให้อยู่ในช่วงที่เลือก (`from`/`to` ของช่วงย่อย)
- `leadDaysOf` = จำนวนวันปฏิทินจากวันที่ของ `createdAt` **ในเขตเวลาหน่วย** (`utcToLocal`) ถึงวันเดินทาง (ติดลบได้) · `leadBucketOf`: < 0 ⇒ `null` (ไม่เข้าช่อง · นับใน `excludedNegative`) · ตามตาราง LEAD_BUCKETS
- `medianOf` = ค่ากลางล่าง: เรียงจากน้อย → `xs[floor((n − 1) / 2)]` · ว่าง ⇒ `null` (จำนวนวันเป็นจำนวนเต็มเสมอ · ไม่มีทศนิยม)
- `bahtPlain`: สตางค์ → บาท 2 ตำแหน่ง ไม่มีตัวคั่นหลักพัน ไม่มี `'` (`-120000` ⇒ `-1200.00` · `5` ⇒ `0.05` · `-5` ⇒ `-0.05`) · `pctPlain`: bp → `62.50` · `-1` ⇒ `-0.01` · `null` ⇒ `""` — ไม่ผ่านทศนิยมลอย
- `reportCsv` = BOM + หัว + แถว + บรรทัดท้าย (`footer` ทีละบรรทัด · เซลล์แรก + ว่างจนเท่าหัว) · คั่น `,` · จบทุกบรรทัด CRLF · สตริงผ่าน `csvCell` (อักขระควบคุมรวม tab/CR/LF ⇒ ช่องว่าง → trim → ขึ้นต้น `= + - @` ⇒ นำ `'`) · `{satang}` ⇒ `bahtPlain` (ไม่ผ่านตัวกันสูตร — ตัวเลขที่โค้ดสร้าง) · `{bp}` ⇒ `pctPlain` · จำนวนเต็ม ⇒ เลข · `null` ⇒ ว่าง · แถวสั้น/ยาวปรับให้เท่าหัว

## 4. นิยามระดับช่วงเวลา (ตัดสินแล้ว · ข้อสอบผูก)
### 4.1 ชุดข้อมูลตามฐาน

### 4.2 ยอดรวม = Σ สรุประดับรอบ (ฐานวันเดินทาง ไม่กรองช่องทาง)
- ทุกรอบในช่วงผ่าน**ตัวคิดเดียวกับ a1** (`computeMoney` แบบชุด §4.4) ⇒ `DepartureMoneyVM` ต่อรอบ · ช่องบวกได้ของ `totals` = Σ ช่องเดียวกันของทุกรอบ: `bookings cancelledBookings pendingRefundBookings seats salesSatang passThroughSatang vatSatang revenueExVatSatang commissionCostSatang collectedSatang outstandingSatang heldSatang retainedSatang agentCollectBookings noShowUnpaid pendingBookings costSatang` (**ข้อสอบ RC พิสูจน์ด้วย `departureMoneySummary` ของ a1 ทีละรอบ**)
- `departures` = จำนวนรอบ (รวมยกเลิก) · `cancelledDepartures` · `capacity` `sold` = Σ เฉพาะรอบที่ไม่ยกเลิก (รอบยกเลิกมี `loadFactorBp null` ระดับรอบ — `costs.ts:275`) · `loadFactorBp = loadFactorBp(Σsold, Σcapacity)` · `charterLikeDepartures` = จำนวนรอบ `charterLike` (นับรวมในอัตราเต็ม + ป้าย C9)
- `grossProfitSatang` = `revenueExVat − commissionCost − cost` ของยอดรวม (เอกลักษณ์ · **ไม่ใช่** Σ กำไรรายรอบ เพราะรอบไม่มีต้นทุนมีกำไร null) · `marginBp` จาก `profitOf` · **`null` เมื่อไม่เห็นต้นทุน หรือทั้งช่วงไม่มีแถวต้นทุนเลย** (ขยาย Q2/OQ50) · `departuresWithoutCosts` = รอบไม่ยกเลิกที่ `noCosts === true` (ผู้เห็นต้นทุน) — มีค่า > 0 ⇒ จอขึ้น "ยังไม่บันทึกต้นทุน {n} รอบ — กำไรอาจสูงกว่าจริง" · ผู้ไม่เห็นต้นทุน ⇒ `null` (Q16 · ไม่อ่านแถวต้นทุนเลย)
- `estimate: true` เสมอ (N7) · สถานะรอบรายแถว = `departureReportStateOf` ด้วย `now` ที่ฉีด · คำเตือน = รวมของทุกรอบ (เรียงตาม `MONEY_WARNING_CODES` · `n` = ผลบวก · `PARK_FEE_WITH_PASS_THROUGH` เฉพาะผู้เห็นต้นทุน · `VAT_STATUS_UNKNOWN` ตามหน่วย)
- บรรทัด VAT / คำว่า "ก่อน VAT" แสดงเมื่อ `totals.vatSatang > 0` (Q11 · ผ่าน `vatShown` ของ `CostParts.tsx:25` เท่านั้น)
### 4.3 แท็บ
- **ยอดขาย (`periods`):** `periodsOf(from, to, group)` · ต่อช่วง `{ key, from, to, departures (ฐานวันจอง/ช่องทาง ⇒ null), bookings, seats, salesSatang, vatSatang, revenueExVatSatang, commissionCostSatang|null, costSatang|null, grossProfitSatang|null }` · ฐานวันเดินทาง: ช่วงของรอบ = `localDate` · ฐานวันจอง: ช่วงของการจอง = วันที่ของ `createdAt` ในเขตเวลาหน่วย · กำไรต่อช่วงใช้กติกาเดียวกับยอดรวม (ช่วงไม่มีแถวต้นทุน ⇒ null) · Σ ช่วง = ยอดรวม
- **อัตราเต็ม (`load`):** ต่อสินค้า (เฉพาะรอบไม่ยกเลิก) `{ productId, titleTh, titleEn, departures, capacity, sold, loadFactorBp, charterLikeDepartures }` เรียง loadFactorBp มาก→น้อย (null ท้าย) แล้ว titleTh · ฐานวันจอง/กรองช่องทาง ⇒ `load = null` + ข้อความ
- **ระยะจองล่วงหน้า (`lead`):** การจองที่นับ LIVE เท่านั้น (ไม่นับยกเลิก/รอคืนเงิน/ถือ/รอ) · **ไม่นับช่องทาง `IMPORT`** (N10 · นับใน `excludedImport`) · `{ buckets: 7 ช่องตามลำดับ { key, bookings, seats, salesSatang } (ช่องศูนย์ก็มี), medianDays, counted, excludedImport, excludedNegative }` · ค่ากลางนับต่อการจอง (ไม่ถ่วงที่นั่ง)
- **ช่องทาง (`channelsTab`):** 3 กลุ่มเสมอตามลำดับ DIRECT → AGENT → OTHER · ต่อกลุ่ม/ช่องทาง `{ bookings, cancelledBookings, seats, salesSatang, revenueExVatSatang, commissionCostSatang|null, shareBp|null }` · ช่องทางที่มีการจอง LIVE/CANCELLED เท่านั้น (เหมือน `costs.ts:357`) เรียงตาม SELL_CHANNELS · `shareBp = mulDivHalfUp(sales, 10000, totals.salesSatang)` (ยอดรวม ≤ 0 ⇒ null) · การจองรอคืนเงินไม่อยู่ในแถวช่องทาง (ยอดขาย 0 อยู่แล้ว) ⇒ Σ ยอดขายช่องทาง = ยอดขายรวม
- ตัวโหลดเติมเฉพาะแท็บที่ขอ (อีก 3 แท็บ = `null`) · `totals` + `departures` เติมทุกแท็บ

- ตารางรอบ `trips-rp-deps` (ฐานวันเดินทาง ไม่กรองช่องทาง): แถว `trips-rp-dep-${i}` (วัน · เวลา · สินค้า/ตัวเลือก · สถานะเป็นข้อความ + ป้ายประมาณการ · ขาย/ความจุ · อัตราเต็ม · ยอดขาย · รับแล้ว · ค้างรับ · [ต้นทุน · กำไร — ผู้เห็นต้นทุน · ไม่มีแถว ⇒ "—"]) · ลิงก์ `trips-rp-dep-link-${i}` · แบ่งหน้า `trips-rp-page` "หน้า {page} จาก {pageCount}" · `trips-rp-page-prev` `trips-rp-page-next` = `<a href>` คงตัวกรอง (ไม่มีหน้าก่อน/ถัดไป ⇒ ไม่แสดง)
- ส่งออก: `trips-rp-export` (ReportExport · "use client" · ปุ่มส่ง `{ from: vm.filter.from, to: vm.filter.to, productId: vm.filter.productId }` → Blob ดาวน์โหลด · ระหว่างรอปุ่ม disabled "กำลังเตรียมไฟล์…") · `<noscript>` `trips-rp-export-nojs` · ฐานวันจอง/กรองช่องทาง ⇒ ไม่มีปุ่ม + `trips-rp-export-note` · ผิด ⇒ `trips-rp-export-error` (`role="alert"` · ข้อความตามรหัส)
### 5.3 ภาษาอังกฤษ
- ทุกคีย์ `report.*` มีสองภาษา · อังกฤษไม่มีอักษรไทย · เอกพจน์/พหูพจน์ ("1 departure" / "2 departures" · "1 booking" / "2 bookings") ของ `report.noCosts` `report.charter` `report.lead.excluded` · ฉาก en ของรายงาน **และจอต้นทุน** (หนี้ a1 — ไม่เคยเปิดดู)
### 5.4 ไม่มี JavaScript
- ตัวกรอง แท็บ ช่วงสำเร็จรูป กลุ่มช่วง หน้า = ฟอร์ม GET / ลิงก์จริง ⇒ ใช้ได้ครบโดยไม่มี JS · **การส่งออกต้องใช้ JS** (server action + Blob) ⇒ `<noscript>` บอกตรง ๆ (หนี้ §12)
### 5.5 สิทธิ์บนจอ
- ผู้ไม่เห็นต้นทุน: ไม่มีคอลัมน์ต้นทุน/กำไรในตารางรอบ ไม่มี KPI ต้นทุน ไม่มี `trips-rp-nocost-note` ไม่มีคำเตือน `PARK_FEE_WITH_PASS_THROUGH` · ข้อมูลที่หน้าส่งลงคอมโพเนนต์ = VM เท่านั้น
### 5.6 หนี้ a1 (จอต้นทุน + การ์ดแผงรอบ)
- รอบที่ `money.noCosts === true`: `trips-cost-kpi-cost` = "—" (ไม่มี "0.00" และไม่มี "ต่อที่นั่ง 0.00") · บรรทัด "− ต้นทุนรอบ" ใน `trips-cost-breakdown` = "—" · การ์ดแผงรอบไม่แสดงยอดต้นทุน 0.00 · จอต้นทุนภาษาอังกฤษไม่มีอักษรไทย (นอกจากชื่อสินค้าที่ไม่มีชื่ออังกฤษ)

### 6.1 `loadTripReportVM(ctx, { unitId, from?, to?, basis?, productId?, channel?, tab?, group?, page? }, opts)` ⇒ `{ ok: true, vm: TripReportVM }`

### 6.2 `exportTripReportCsv(ctx, { unitId, from?, to?, productId?, locale?: "th" | "en" }, opts)` ⇒ `{ ok: true, value: { filename; csv; rows; total; truncated; withCost } }`
- สิทธิ์เดียวกับ 6.1 · **ฐานวันเดินทางเสมอ ไม่รับ basis/channel** (คีย์เกิน ⇒ `INVALID_INPUT`) · ลำดับ: อินพุต → ด่าน → สิทธิ์ → ช่วง → **เพดานความถี่** `checkRateLimitDb("trips:report:export:<tenantId>:<unitId>:<actorUserId>", REPORT_EXPORT_RATE, now.getTime())` (เกิน ⇒ `RATE_LIMITED` · ไม่เขียน audit) → ข้อมูล → audit → คืนไฟล์

- `filename = reportFileName(from, to)` · audit 1 แถว `trips.report.exported` · `targetType "BusinessUnit"` · `targetId = unitId` · `unitId` · `actorId` · `before null` · `after = { from, to, productId, rows, total, truncated, withCost, locale }` เท่านั้น (**ไม่มียอดเงิน ไม่มีชื่อสินค้า**) · เขียนก่อนคืนไฟล์ (เขียนไม่ได้ ⇒ `BUSY` ไม่คืนไฟล์) · เรียกซ้ำ = ไฟล์เดิมทุกไบต์ + audit ใหม่
