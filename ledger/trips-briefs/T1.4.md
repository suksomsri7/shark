## 4. ตัวโหลด `loadManifestVM(ctx, input, opts)` (`manifest.ts`) — ข้อสอบเรียกตรง

- ตาราง (`trips-mf-table` · กล่อง `relative min-w-0 overflow-x-auto`): แถว `trips-mf-row-<bookingId>`: **เวลารับ** (ตัวหนา · ไม่มี ⇒ "—") · **จุดรับ** + บรรทัดรอง `note` (ไม่มี stop แต่มี `hint` ⇒ "{hint}" ตัวจาง + "(จากแบบฟอร์ม)") · **ผู้จอง** (ตัวหนา · `bookerPurged` ⇒ "ข้อมูลผู้จองถูกลบตามนโยบายแล้ว") + เลขจอง (ลิงก์ `…/bookings?when=all&b=<id>` เฉพาะ `canSeeMoney`) + ช่องทาง (`departures.channel.*` ของ T1.2 — ห้ามคำว่า POS/เครื่องขาย: ใช้ชื่อเดียวกับที่ T1.3a V13 ตั้ง) · **คน** "{qty} {ประเภทคน}" ชิดขวา · **รายชื่อ·เอกสาร** ป้ายตาม `doc.state` (`COMPLETE` ทึบ "ครบ" · `MISSING_NAMES` กรอบสีอันตราย + ไอคอน "ขาดรายชื่อ {missingNames}" · `INCOMPLETE` เส้นประ "แบบฟอร์มยังไม่ครบ" · `PURGED` จาง "ลบตามนโยบายแล้ว") + "เซ็นแล้ว {waiverSigned}/{waiverRequired}" (เมื่อ `waiverRequired > 0`) + "ต้องแก้ {needsFix}" · **หมายเหตุ** รายการเสริม · ขนาดตีนกบ · ป้าย "มีข้อมูลสุขภาพ {healthProvided}" / "ยังไม่ตอบสุขภาพ {healthMissing}" (สถานะ) · **ติดต่อ** `phoneMasked` หรือ "ติดต่อผ่านเอเจนซี่" · ปุ่มขยายรายคน `trips-mf-pax-toggle-<bookingId>` ⇒ `trips-mf-pax-<bookingId>` (ตารางย่อย/รายการ: ลำดับ · ชื่อ ("ยังไม่กรอกชื่อ" / "ลบตามนโยบายแล้ว") · ประเภทคน · สัญชาติ · เอกสาร "{ชนิด} {docMasked}" · แบบฟอร์ม · ลงนาม · สุขภาพ · ไฟล์ "{live} ไฟล์" (+ "รอลบ {pendingDeletion}" — หนี้ T0.8 ข้อ 5: ไฟล์ที่ทำเครื่องหมายลบแล้ว **ไม่นับ** เป็นไฟล์ที่มี))
- ไม่มีแถว ⇒ `trips-mf-empty` "ยังไม่มีการจองที่ยืนยันในรอบนี้"
- **390**: ไม่แสดงตาราง → การ์ดต่อการจอง `trips-mf-cards` / `trips-mf-card-<bookingId>` (เวลา+จุดรับ · ผู้จอง+เลขจอง · คน · ป้ายเอกสาร · ติดต่อ · ขยายรายคน) · การ์ดสรุป 2 คอลัมน์ · **ห้ามล้นแนวนอน** · ห้าม `sr-only` ในไฟล์ที่มี `<table`
- ข้อความทุกคำจาก messages · **ห้ามรหัสดิบ** (`CONFIRMED` `SUBMITTED` `NOT_COLLECTED` `MISSING_NAMES` `PASSPORT` `UNASSIGNED` `VIA_AGENT` camelCase · รหัสใบงาน) — ชื่อสถานะผ่าน `manifest.*` (สถานะรอบ/ช่องทางใช้คีย์ T1.2 เดิม) · `data-*` เป็นแอตทริบิวต์ได้ · เงิน = `formatBaht` ของ `trips-shared` เท่านั้น · คอมโพเนนต์ไม่คิดเลข (ไม่บวกจำนวนคน/ยอด) — ทุกตัวเลขมาจาก VM · ชื่อสินค้า/ประเภทคน/รายการเสริม: จออังกฤษใช้อังกฤษเมื่อมี

### 5.2 เปิดดูข้อมูลสุขภาพของรอบ (`trips-mf-health` → `trips-health-dialog`)
- ปุ่มแสดงเฉพาะ `flags.canSeeHealth` · กดแล้วเปิดกล่อง (`Dialog` ของ T1.1): ข้อความเตือน `trips-health-warning` "ข้อมูลสุขภาพเป็นข้อมูลอ่อนไหว — การเปิดดูถูกบันทึกรายคน · เปิดเท่าที่จำเป็นต่อความปลอดภัยของทริป" + เลือกวัตถุประสงค์ `trips-health-purpose` (3 ค่าของ `MANIFEST_HEALTH_PURPOSES` · ปริยาย `SAFETY`) + ยืนยัน `trips-health-confirm` ⇒ `revealManifestHealthAction` ⇒ รายการ `trips-health-list` (ชื่อ · แพ้ · โรค/ข้อควรระวัง) · ว่าง ⇒ `trips-health-empty`
- ผลอยู่ใน state ของกล่องเท่านั้น: **ไม่ใส่ URL · ไม่ใส่ localStorage/sessionStorage · ปิดกล่อง = ทิ้ง** · กล่องทั้งใบ `print:hidden` · ผิดพลาด = ข้อความในกล่อง สีอันตราย + `role="alert"`
### 5.3 ส่งออก CSV (`trips-mf-export`)
- กด ⇒ `exportManifestCsvAction({ departureId })` ⇒ ไคลเอนต์สร้าง `Blob` (`text/csv;charset=utf-8`) แล้วดาวน์โหลดด้วยชื่อ `filename` ที่บริการคืน (ไม่ต่อข้อความเอง) · ปุ่ม disabled ระหว่างรอ · ถูกตัด ⇒ ข้อความ `trips-mf-export-truncated` · ผิดพลาด `trips-mf-export-error` (สีอันตราย + `role="alert"`) · **ไม่มี route ใต้ `src/app/api`** · ไม่มีลิงก์ดาวน์โหลดที่ใช้ซ้ำได้
### 5.4 พิมพ์ (`trips-mf-print`)
- กด ⇒ `recordManifestPrintAction({ departureId })` สำเร็จ **แล้วจึง** `window.print()` (บันทึกไม่สำเร็จ ⇒ ไม่พิมพ์ + ข้อความผิดพลาด) · ผู้ใช้กดพิมพ์จากเมนูเบราว์เซอร์เองไม่ถูกบันทึก (ข้อจำกัดที่รับ — Q4)
- **ผังพิมพ์** อยู่ในคอมโพเนนต์ของใบ (ห้ามแก้เปลือกแอป): องค์ประกอบราก `data-print-root="trips-manifest"` + กฎ `@media print` ที่ซ่อนทุกอย่างนอกรากนี้ (เช่น `body * { visibility: hidden }` + ราก `visibility: visible; position: absolute; inset: 0`) · ปุ่ม/ตัวสลับ/แถบแจ้งที่ไม่ใช่เนื้อหา = `print:hidden` · พิมพ์: หัว (ชื่อร้าน/หน่วย · สินค้า · วันที่เวลา · เรือ/ไกด์ · "พิมพ์เมื่อ {nowLocal} โดย {ชื่อผู้พิมพ์จาก VM/ctx}") · การ์ดสรุปเป็นบรรทัด · ทุกกลุ่ม + **รายชื่อรายคนเปิดทั้งหมด** · ท้ายกระดาษ `trips-mf-print-footer` "เอกสารมีข้อมูลส่วนบุคคล — ใช้เฉพาะการดูแลทริปนี้ ทำลายหลังจบทริป" · ตัวอักษรดำบนขาว ≥ 10pt · `break-inside: avoid` ต่อการจอง
- **ผังพิมพ์ไม่มี**: เนื้อหาสุขภาพ (สถานะเท่านั้น) · เลขเอกสารเต็ม · เบอร์เต็ม · ยอดเงิน (ไกด์/คนขับไม่ต้องเห็น — ภาพ :88) · ผู้เดินทางที่ถูกลบ (แสดงเป็น "ลบตามนโยบายแล้ว" ไม่มีชื่อ)
- ผู้คุมตรวจ: ฉาก `manifest-print` (§12) ถ่ายด้วย `page.emulateMedia({ media: "print" })` + `page.pdf()` — เห็นเฉพาะใบรายชื่อ ไม่มีแถบซ้าย/แถบ trips/ปุ่ม · ไม่ล้นขอบ A4 แนวตั้ง

## 6. การเขียน — แถว `AuditLog` เท่านั้น (ไม่มีการเขียนตาราง `Trip*` · ไม่มี outbox/event ใหม่)
| ปุ่ม | action (`manifest-actions.ts`) → บริการ (`manifest.ts`) | สิทธิ์ | สิ่งที่เขียน |
|---|---|---|---|
| ส่งออก CSV | `exportManifestCsvAction` → `exportManifestCsv(ctx, { unitId, departureId, locale? }, opts)` | `trips.departure.view` ∧ `trips.passenger.view` | 1 แถว `trips.manifest.exported` |
| ยืนยันดูข้อมูลสุขภาพ | `revealManifestHealthAction` → `revealManifestHealth(ctx, { unitId, departureId, purpose }, opts)` | + `canSeeSensitive(…, "trips.passenger.health", unitId)` (แคบ — `trips.*`/MANAGER ไม่พอ · แบบ T0.8) | 1 แถว `trips.passenger.revealed` **ต่อผู้เดินทางที่ถูกเปิด** |
| พิมพ์ | `recordManifestPrintAction` → `recordManifestPrint(ctx, { unitId, departureId }, opts)` | เท่าส่งออก | 1 แถว `trips.manifest.printed` |
- ทั้งสามคืน `{ ok: true, value } | { ok: false, code, message }` ไม่ throw · ด่าน/รูป input/รหัสผิดพลาดเหมือน §4 (ขาดสิทธิ์สุขภาพ ⇒ `FORBIDDEN`) · `opts.now` สำหรับข้อสอบเท่านั้น — action **ไม่รับเวลาจากผู้เรียก**
- **`exportManifestCsv`** ⇒ `value { filename /* manifestFileName */; csv /* manifestCsv */; rows: number; truncated: boolean; purgedSkipped: number }` · หัวคอลัมน์ = `manifest.csv.<คอลัมน์>` ตาม `locale` (ปริยาย `"th"`) ลำดับ = `MANIFEST_CSV_COLUMNS` · **หนึ่งแถวต่อผู้เดินทางที่ยังไม่ถูกลบ** ของการจองใน M (เรียง กลุ่มตามมุมมอง `pickup` → ลำดับแถว → `no`) · การจองที่ไม่มีแถวผู้เดินทางเหลือเลย ⇒ 1 แถว (ช่องรายคนทั้งหมดว่าง: `paxNo` `traveller` `paxType` `nationality` `docType` `docMasked` `formStatus` `waiver` `health` `finSize`) เพื่อให้การจองยังอยู่ในไฟล์ · ผู้จองที่ถูกลบ (`bookerPurged`) ⇒ ช่อง `booker` ว่าง · คนที่ยังไม่กรอกชื่อ ⇒ `traveller` ว่าง (ยังมีแถว) · ช่อง `group` = ชื่อรถ หรือข้อความ `manifest.group.unassigned` · ผู้เดินทางที่ถูกลบ **ไม่ออกในไฟล์** (นับ `purgedSkipped`) · เพดานแถว = `TRIPS_MANIFEST_PAX_CAP` (+ การจองตาม `TRIPS_MANIFEST_BOOKING_CAP`) เกิน ⇒ `truncated: true` · เซลล์สถานะ (`channel` `paxType` `docType` `formStatus` `waiver` `health`) = **ข้อความตามภาษา ไม่ใช่รหัสดิบ** · `docMasked` = `maskDoc` · **ไฟล์ไม่มี**: เลขเอกสารเต็ม · เนื้อหาสุขภาพ · วันเกิด · เบอร์ (แม้ปิดบัง) · อีเมล · ยอดเงิน · id ภายใน · ทุกเซลล์ผ่าน `csvCell` (กันสูตร `= + - @`)
  - audit ใน tx **ก่อนคืนไฟล์** (บันทึกไม่ได้ ⇒ ไม่คืนข้อมูล): `action "trips.manifest.exported"` · `actorType USER` · `actorId` = ผู้เรียก · `unitId` · `targetType "TripDeparture"` · `targetId` = departureId · `after { departureId, format: "CSV", purpose: "MANIFEST", rows, truncated, purgedSkipped }` (id · enum · จำนวน เท่านั้น)
  - เรียกซ้ำ = ไฟล์เดิมทุกไบต์ (ข้อมูลเดิม) + แถว audit ใหม่ (การนำออกแต่ละครั้งคือเหตุการณ์จริง — ไม่มีคีย์กันซ้ำ)
- **`revealManifestHealth`** · `purpose ∈ MANIFEST_HEALTH_PURPOSES` (อื่น ⇒ `INVALID_INPUT`) ⇒ `value { purpose; count; items: { passengerId; bookingId; code; fullName: string | null; allergies: string | null; conditions: string | null }[] }` — เฉพาะผู้เดินทางของการจองใน M (ทั้งชุดจนถึง `TRIPS_MANIFEST_PAX_CAP`) ที่สุขภาพ `PROVIDED` ∧ ไม่ถูกลบ (`DECLINED/WITHDRAWN/GUARDIAN_REQUIRED/PURGED/MISSING` ไม่อยู่ในผล) · เปิดด้วย `openHealth` ของ T0.8 (AAD เดิม) · กล่องใดเปิดไม่ได้ (`LOCKED`/ไม่มีกุญแจ) ⇒ `BUSY` **ทั้งคำขอ ไม่คืนบางส่วน ไม่เขียน audit**
  - audit ใน tx เดียว (คำสั่งเดียว `createMany`/`INSERT … SELECT`) **commit ก่อนคืนค่า**: ต่อผู้เดินทางที่อยู่ใน `items` 1 แถว `action "trips.passenger.revealed"` (ชื่อเดียวกับ T0.8 เพื่อให้บันทึกการเข้าถึงรายบุคคลครบที่เดียว) · `targetType "TripPassenger"` · `targetId` = passengerId · `after { passengerId, what: "HEALTH", purpose, via: "MANIFEST", departureId }` — **ไม่มีเนื้อหา** · `items` ว่าง ⇒ ไม่เขียน
- **`recordManifestPrint`** ⇒ `value { passengers: number }` · audit `trips.manifest.printed` · `targetType "TripDeparture"` · `after { departureId, purpose: "MANIFEST", passengers /* ผู้เดินทางที่ยังไม่ถูกลบใน M */ }`
- **ไม่มีข้อมูลส่วนบุคคลใน**: `AuditLog.before/after` · `OutboxEvent` (ใบนี้ไม่ส่ง event เลย) · `OpsEvent`/`console.*`/ข้อความ error (ชื่อ · เบอร์ · เลขเอกสาร · เนื้อหาสุขภาพ) — ข้อสอบปลูกตัวบ่งชี้แล้วสแกน
- กติกาการเขียนพร้อมกัน (CAS · ล็อก · คีย์กันซ้ำ) **ไม่มีเป้าในใบนี้** เพราะไม่มีแถวที่ถูกแก้ — เป็นข้อบังคับของ T1.4b (ตาราง §0) · สิ่งที่ข้อสอบใบนี้ตรึง: คำขอพร้อมกันหลายตัวไม่ค้าง/ไม่ชนกัน และ audit ครบทุกคำขอ
