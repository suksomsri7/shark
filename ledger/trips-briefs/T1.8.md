## 4. พฤติกรรม
### 4.1 ประตู platform (เพิ่มอย่างเดียว)
- `domain: "booking" | "rooms" | "trips"` ⇒ คีย์แม่แบบ `trips.msg.<messageKey>` (มีอยู่แล้ว)
- `scope?: { productId?: string }` ⇒ ส่งเข้า `resolveSettings(..., { unitId, productId })` (แม่แบบชั้น PRODUCT ชนะ · `messaging.*` ไม่มีชั้นนี้ จึงไม่กระทบ)
- `localized?: { en?: { vars: Record<string,string>; flex?: Record<string,unknown> } }` ⇒ ใน `deliver` เมื่อ locale = en ใช้ `vars/flex` ของ en (ตรวจรูปเหมือนของหลัก) · ไม่ส่ง = เดิม
- ไม่เปลี่ยนลำดับขั้น ไม่เปลี่ยนจำนวน SQL ของผู้เรียกเดิม · ข้อสอบ regression: `qc-svc-r0.7` `qc-svc-b.9` `qc-svc-d.9`

5. การจองเอเจนซี่: ผู้รับคือ **ลูกค้า** ตาม A32 เท่านั้น · การแจ้ง**เอเจนซี่** = A2.2 (ไม่อยู่ในใบนี้)

## 7. ข้อมูลส่วนบุคคล · ต้นทุน · การใช้ในทางผิด
