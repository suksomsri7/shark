## 4. ลำดับด่าน (ทุกตัว)
1. `clientKey` ไม่ตรง `pc_[0-9a-f]{40}` ⇒ RATE_LIMITED NO_CLIENT **ไม่ถามฐาน**
2. ร้าน: `resolveBookShop` + `findPublicProduct` (TOUR · ACTIVE) — ไม่พบ ⇒ ถังเดา W1.1 แล้ว NOT_FOUND รูปเดียว
3. ด่านอัตรา **คำสั่ง SQL เดียว** (`rateBucketCte` · `opts.deps.query`) ปิดเมื่อพัง (LIMITER_DOWN): อ่าน = ถัง W1.1 `trips:book:<tenant>:<ck>` (BOOK_READ_LIMIT) · ถือ = `trips:hold:<tenant>:<ck>` เพดาน X8 `holdPerHourPerContact` ต่อเครื่อง/ชม. (ค่าตั้งอ่านไม่ได้ ⇒ ปิด) · token ผิด = ถัง `trips:token:<tenant>:<ck>` เพดาน X8 `tokenPerHourPerDevice` (อ่านค่าในคำสั่งเดียวกับถังอ่าน · ค่า ≥ เพดาน ⇒ ปิดแม้ token จริง · +1 เมื่อค้นไม่เจอ) — ห้าม `checkRateLimitDb*`
4. ฟอร์ม: nonce ลายเซ็นถูก · อายุ ≥ BOOK_FORM_MIN_SEC (TOO_FAST) ≤ MAX (STALE_FORM) · `seen` = ยอดที่จอแสดง (เทียบเท่านั้น ไม่ใช้คิดเงิน)
5. แปลง ref → id ในโมดูล (ของร้าน/หน่วย/สินค้านี้เท่านั้น · โซน/รายการเสริมปิด ⇒ INVALID — ปิดหนี้ `pricing.ts:184`)
6. บริการ: `quoteTrips` (ctx `{tenantId, unitId, channel:"WEB", actor:{kind:"PUBLIC", clientKey}, now, locale}`) → `totalSatang ≠ seen` ⇒ PRICE_CHANGED → `holdTrips` (basketToken) · ยืนยัน: `confirmTrips` (`pay.method PAY_NOW` · booker `{name, phone, email?}` เท่านั้น — **ห้ามส่ง partyId/lineUserId จากฟอร์ม**)
7. หน้าการจอง: ค้น `sha256(token)` ผูก tenant ของ `[shop]` + หน่วย TRIPS ACTIVE · HOLD ⇒ `tripPaymentIntent({publicToken})` (ตัด `bookingId` `dueId` `payload` ทิ้ง) · สถานะจาก `reservationStateOf` (ถือหมดตามนาฬิกา ⇒ EXPIRED แม้ตัวกวาดยังไม่วิ่ง)
