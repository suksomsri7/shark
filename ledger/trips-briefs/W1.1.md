- `bookLocaleOf`: `lang` เป็น `"th"`/`"en"` ตรงตัว ⇒ ค่านั้น · ไม่งั้นอ่าน Accept-Language (แยก `,` · `;q=` · เรียง q มาก→น้อย คงลำดับเดิมเมื่อเท่ากัน · q=0 ทิ้ง): แท็กแรกที่ภาษาหลักเป็น `th`/`en` ⇒ ภาษานั้น · มีหัวแต่ไม่มีทั้งคู่ (เช่น `de-DE`) ⇒ `"en"` · ไม่มีหัว/ไม่ใช่สตริง/ว่าง ⇒ `"th"`

- `clientIpFromHeaders`: ลำดับหัว `x-real-ip` → `x-vercel-forwarded-for` → `x-forwarded-for` (ลำดับเดียวกับ `hotelWebClientKey` :218) · หัวแรกที่มีค่า (ตัวแรกก่อน `,`) เป็นตัวตัดสิน: ผ่าน `canonicalClientIp` ⇒ ค่านั้น · ไม่ผ่าน ⇒ `null` (ไม่ไล่ต่อ) · ไม่มีหัวใดเลย ⇒ `null` — **ไม่มีถัง "unknown"**
- `parseBookQuery`: รับ object ของ `searchParams` · ค่าต้องเป็นสตริงเดี่ยว (array/ชนิดอื่น ⇒ null) · `lang` th|en · `a` `s` ตรง `BOOK_CODE_RE` · `d` วันที่มีจริง `YYYY-MM-DD` · `m` `YYYY-MM` เดือน 01–12 · คีย์อื่นทิ้ง · ไม่ throw ไม่ว่ารับอะไร
- `bookHref`: `/book/<shop>` หรือ `/book/<shop>/t/<slug>` (ส่วน path ผ่าน `encodeURIComponent`) + query ลำดับตายตัว `lang` `a` `m` `d` (ค่าว่าง/null ไม่ใส่ · ไม่มีค่าเลย ⇒ ไม่มี `?`) — ทุกลิงก์ในหน้าใช้ตัวนี้ (พาภาษาและลิงก์ผู้แนะนำไปด้วย)
- `monthGrid`: แถวสัปดาห์ **อาทิตย์ก่อน** 7 ช่อง · ช่องนอกเดือน = null · เดือนผิดรูป ⇒ null (`2026-11` = 5 แถว ช่องแรก `2026-11-01` · `2026-02` = 4 แถว · `2026-08` = 6 แถว) · คิดด้วย UTC ล้วน
- `clampMonth`: `YYYY-MM` ที่อยู่ในช่วง [เดือนของ `today`, +`BOOK_MONTHS_AHEAD` เดือน] ⇒ ค่านั้น · นอกช่วง/ผิดรูป ⇒ เดือนของ `today` (กันไล่สแกนไม่จำกัด)
- `dayCellOf` (ตัวตัดสินสภาพวัน — คอมโพเนนต์ห้ามตัดสินเอง): `ymd < today` ⇒ `PAST` · ไม่มีรอบ ⇒ `NONE` · มีรอบที่ `saleBlock === null` และ `publicLeft > 0` ⇒ เลือกรอบที่ว่างมากสุด: `showLeft` ⇒ `LOW` ไม่งั้น `OPEN` · `left` = ที่ว่างของรอบนั้น (เลขจริงของรอบจริง ไม่รวมข้ามรอบ) · ไม่งั้นมีรอบ `saleBlock === null` ⇒ `FULL` (left 0) · ไม่งั้นทุกรอบ `status === "CANCELLED"` ⇒ `NOT_RUNNING` · ที่เหลือ ⇒ `CLOSED` · `left` เป็น null ในสภาพ PAST/NONE/NOT_RUNNING/CLOSED · `publicLeft` ติดลบถือเป็น 0
- `frameAncestorsOf`: รายการโดเมนที่ผ่าน regex เดียวกับค่าตั้ง (`defs/trips.ts:502` — เขียนซ้ำ ห้าม import ค่า) ตัวเล็ก ตัดซ้ำ ไม่เกิน 20 ⇒ `"frame-ancestors https://a https://b"` · ว่าง/ไม่ใช่ array/ไม่มีตัวที่ผ่าน ⇒ `"frame-ancestors 'none'"` · ไม่มี `*` `http:` `'self'` ช่องว่างในโดเมน `;` หลุดออกมาได้เลย
- `embedOriginAllowed`: `origin` ต้องเป็นสตริงที่ `new URL(origin).origin === origin.toLowerCase()` · scheme `https:` · ไม่มีพอร์ต · host เท่ากับโดเมนในรายการ **ตรงตัว** (โดเมนย่อย/คล้าย/ต่อท้าย = ไม่ผ่าน) · `"null"`/ว่าง/ไม่ใช่สตริง ⇒ false
- ไฟล์นี้ไม่มี I/O · ไม่อ่าน `process.env` · ไม่อ่านนาฬิกา (`Date.now` / `new Date()` ไม่มีอาร์กิวเมนต์ ห้าม) · ไม่ใช้ `getDay/getDate/getHours/getMonth/getFullYear` (ใช้ตัว UTC)

## 5. ด่านอัตรา + ตัวนับเปิดดู (ทางเขียนเดียวของใบนี้)
### 5.1 กุญแจเครื่อง `bookClientKey(ip)`
`"pc_" + HMAC-SHA256("trips.public.client.v1:" + SESSION_SECRET, canonicalClientIp(ip)).hex.slice(0, 40)` · `SESSION_SECRET` ไม่มี/สั้นกว่า 32 ⇒ **`null`** (ไม่มีกุญแจสำรอง ไม่ถอยไป sha256 เปล่า) · ip ที่ canonical ไม่ได้ ⇒ `null` · ใช้ IP อย่างเดียว ไม่รวม User-Agent (เปลี่ยน UA แล้วได้ถังใหม่ไม่จำกัด — Q8) · กุญแจนี้ใช้กับด่านอัตรา/กันนับซ้ำเท่านั้น ไม่ใช่ตัวตน · ไม่ส่งออกไปที่ไคลเอนต์ · ไม่ลง log

### 5.2 `bookPageGate(input, opts?)`
```ts
input: { tenantId: string | null /* null = คำขอที่หาร้าน/สินค้าไม่เจอ */; unit: { id: string; tz: string } | null /* null = หน้ารายการ */; productId: string | null; clientKey: string | null; channel: "WEB" | "LIFF" | "EMBED"; linkCode: string | null }
opts?: { now?: Date; deps?: { query?: (sql: unknown) => Promise<unknown[]> } }     // deps.query = ตัวรันคำสั่งของด่าน (ปริยาย = prisma.$queryRaw) — ข้อสอบใช้จำลองฐานล่ม/นับจำนวนคำสั่ง
→ { ok: true; counted: boolean; linkId: string | null } | { ok: false; code: "RATE_LIMITED"; reason: "LIMIT" | "NO_CLIENT" | "LIMITER_DOWN"; retryAfterSec: number }
```
- `clientKey === null` ⇒ `RATE_LIMITED NO_CLIENT` **โดยไม่ถามฐาน** (ปิดเมื่อไม่รู้ว่าใคร — ไม่มีถังรวม "unknown")
- **คำสั่ง SQL เดียวต่อการเรียก** ผ่าน `deps.query` (ประกอบด้วย `rateBucketCte` ของ `core/rate-limit-db.ts:100` — ห้ามใช้ `checkRateLimitDb`/`checkRateLimitDbMany` เพราะสองตัวนั้นปล่อยผ่านเมื่อฐานล่ม):
  1. `tenantId === null` ⇒ ถัง `trips:book:none:<clientKey>` เพดาน `BOOK_MISS_LIMIT` อย่างเดียว (ถังเดียวต่อเครื่อง ไม่มีแถวใหม่ต่อ slug ที่เดา)
  2. มีร้าน ⇒ ถังอ่าน `trips:book:<tenantId>:<clientKey>` เพดาน `BOOK_READ_LIMIT`
  3. มี `unit` ⇒ ต่อท้ายในคำสั่งเดียวกัน: ถังกันนับซ้ำ `trips:view:<unitId>:<วันของร้าน>:<channel>:<linkId หรือ ->:<clientKey>` (หน้าต่าง 24 ชม. · นับเฉพาะเมื่อถังอ่านผ่าน) → `INSERT INTO "TripLinkStat" … SELECT … WHERE <ถังกันซ้ำ>.count <= BOOK_VIEW_PER_CLIENT_DAY ∧ หน่วยนั้นเป็นของ tenantId นี้ · type TRIPS · status ACTIVE` `ON CONFLICT ("unitId","day","channel","linkId") DO UPDATE SET "views" = LEAST("TripLinkStat"."views" + 1, BOOK_STAT_ROW_CAP)` (ดัชนี NULLS NOT DISTINCT ⇒ `linkId` null ชนกันได้) · `id` = `gen_random_uuid()::text` · `day` = `utcToLocal(unit.tz, now).ymd` · `starts`/`paid` ไม่แตะ
- ตัดสินจากแถวที่คำสั่งคืน: นับของถังอ่าน ≤ เพดาน ⇒ ผ่าน · เกิน ⇒ `LIMIT` + `retryAfterSec` (1..วินาทีของหน้าต่าง) · **คำสั่ง throw / ไม่คืนแถว / ค่านับไม่ใช่จำนวนเต็ม ⇒ `LIMITER_DOWN`** (`retryAfterSec` 60) — ปิดเมื่อพัง ไม่มีทางผ่านโดยไม่มีเลขนับ · จด `logOps("WARN", "trips.public", …)` ได้ แต่ detail ห้ามมี IP/กุญแจเครื่อง/UA/รหัสลิงก์
- `counted` ⇔ คำขอนี้ผ่านถังกันนับซ้ำ (เพิ่ม views จริง หรือชนเพดานแถว) · `unit` null หรือ `tenantId` null ⇒ `counted: false` ไม่มีแถว `TripLinkStat`
- ไม่เปิดธุรกรรม · ไม่มีคำสั่งที่สอง · ไม่มี read-then-write

### 5.3 `?a` — ช่องเสียบตัวแก้ลิงก์ (แบบ `registerAgencyPricingPort` ของ T0.5)
`registerBookLinkResolver(fn | null)` · `fn(q: { tenantId: string; code: string }) => Promise<{ linkId: string; agentAccountId: string; productId: string | null; active: boolean } | null>` — **ยังไม่มีใครลงทะเบียนในโค้ดจริง** (บริการลิงก์เอเจนซี่ = A1.8) ⇒ วันนี้ `?a` ทุกค่า = ไม่ผูก (นับใต้ `linkId` null)
- ด่านเรียกตัวแก้เฉพาะเมื่อ `linkCode` ตรง `BOOK_CODE_RE` ∧ มีร้าน ∧ มี `unit` · ส่ง `tenantId` ของร้านที่ resolve แล้วเสมอ (ค้นข้ามร้านไม่ได้โดยรูปของสัญญา)
- ใช้ผลเมื่อ `active` ∧ (`productId` null ∨ `productId` = สินค้าของหน้านี้) ⇒ แถวสถิติ `(unitId, day, channel, linkId)` + `agentAccountId` ของผล · ไม่งั้น/ตัวแก้คืน null/ตัวแก้ throw ⇒ ไม่ผูก (ยังนับใต้ null · หน้าไม่ล้ม)
- `?s` อ่านรูปแล้ว **ทิ้ง** (ไม่มีที่ตรวจ ไม่เก็บ ไม่พาต่อ — Q4) · `?a` ที่ไม่ผูก ⇒ ไม่พาต่อในลิงก์ของหน้า (`open*` คืน `carry.a = null`)

### 5.4 `openBookShop` / `openBookProduct` — ทางเข้าเดียวของหน้า
`openBookProduct({ shop, productSlug, query, acceptLanguage, clientKey }, opts?)` → `{ ok: true; vm: BookProductVM; carry: { lang: "th" | "en" | null; a: string | null } } | { ok: false; code: "NOT_FOUND" } | { ok: false; code: "RATE_LIMITED"; reason; retryAfterSec }` (`openBookShop` เหมือนกันไม่มี `productSlug` · `query` = ผลของ `parseBookQuery` หรือ object ดิบ — ตัวนี้ parse ซ้ำเอง)
ลำดับบังคับ: (1) `clientKey` null ⇒ `RATE_LIMITED NO_CLIENT` ไม่แตะฐาน (2) `resolveBookShop` (+ หาสินค้าที่มองเห็น) (3) ไม่เจอ ⇒ `bookPageGate({ tenantId: null … })` ⇒ ผ่าน = `NOT_FOUND` · ไม่ผ่าน = `RATE_LIMITED` (4) เจอ ⇒ `bookPageGate` ของจริง (หน้าสินค้ามี `unit` + `productId` + `linkCode = query.a`) ⇒ ไม่ผ่าน = `RATE_LIMITED` **ไม่มี vm** (5) ผ่าน ⇒ ตัวโหลด §4.2 (`month = query.m` · `date = query.d` · `lang = query.lang`) · `opts.deps` ส่งต่อถึงด่าน · หน้ารายการไม่นับ views (Q2)

### 5.5 `bookFramePolicy({ tenantId, unitId })` → `{ frameAncestors: string; domains: string[] }`
อ่าน `trips.public.embedDomains` ของหน่วยด้วย `resolveSettings` (นอกธุรกรรม) → `frameAncestorsOf` · หน่วยไม่ใช่ของร้านนั้น/ไม่ใช่ TRIPS/ไม่ ACTIVE/อ่านค่าตั้งไม่ได้ ⇒ `{ frameAncestors: "frame-ancestors 'none'", domains: [] }` (ปิดเมื่อพัง) — **ใบนี้ยังไม่ต่อเข้าหัว HTTP** (`src/proxy.ts` ส่ง `X-Frame-Options: DENY` ทุกเส้นยกเว้น `/f` และห้ามแตะฐาน ⇒ หน้า `/book` วันนี้ฝังไม่ได้เลย = ปลอดภัยไว้ก่อน · W3.1 ใช้ตัวนี้ — Q5)
