### 3.1 เงินต่อการจอง `bookingMoneyOf` (สตางค์จำนวนเต็มทุกตัว) — ให้ `P` payable · `T` เก็บแทน · `V` VAT · `C` คอมฯ · `Cv` VAT ของคอมฯ · `R` = min(max(0, paid − refunded), P)
**ลำดับตัดสิน counted:** `pendingRefund` ⇒ `PENDING_REFUND` · สถานะ ∈ LIVE ⇒ `LIVE` · `CANCELLED` ⇒ `CANCELLED` · อื่น (HOLD PENDING EXPIRED) ⇒ `EXCLUDED`
| counted | ยอดขาย `salesSatang` | `passThroughSatang` | `vatSatang` | `commissionCostSatang` (N3) | `collectedSatang` | `outstandingSatang` | `heldSatang` | `seats` |
|---|---|---|---|---|---|---|---|---|
| LIVE (ไม่ใช่ NO_SHOW) | `P − T` | `T` | `V` | `C + (vatRegistered ? 0 : Cv)` | `paid − refunded` | `agentCollect ? 0 : outstandingOf({status, payable: P, paid})` | 0 | `seats` |
| LIVE · NO_SHOW (N6) | `s = min(R, P − T)` (เงินที่รับลงส่วนไม่ใช่เก็บแทนก่อน — แบบ `trips.pay.depositBase TRIP_ONLY`) | `R − s` | `s = P − T ? V : mulDivHalfUp(V, s, P − T)` (P − T = 0 ⇒ 0) | เหมือน LIVE | `paid − refunded` | `outstandingOf(...)` (= 0 · NO_SHOW ไม่อยู่ในชุดค้าง) | 0 | `seats` |
| CANCELLED | Σ_RETAINED(`amount − passThrough`) | Σ_RETAINED `passThrough` | Σ_RETAINED `vat` | 0 (OQ48 · A1.7) | `paid − refunded` | 0 | 0 | 0 |
| PENDING_REFUND (N5) | 0 | 0 | 0 | 0 | 0 | 0 | `paid − refunded` | `seats` (ยังกันที่ไว้จนคืนเสร็จ · OQ22) |
| EXCLUDED | 0 | 0 | 0 | 0 | 0 | 0 | 0 | 0 |
- `revenueExVatSatang = salesSatang − vatSatang` ทุกแถว · `agentCollect` = `collectMode === "AGENT" ∨ agentAccountId !== null` (กติกาเดียวกับ `moneyStateOf` · N4) — เฉพาะ LIVE (อื่น false) · `noShowUnpaid` = NO_SHOW ∧ `R < P`
- **เงินเก็บแทนไม่ใช่รายได้และไม่ใช่ต้นทุน** · แถวต้นทุน `PARK_FEE` = ค่าอุทยานที่ร้านจ่ายเองโดยไม่ได้เก็บแทน · ภาษีหัก ณ ที่จ่ายไม่ใช่ต้นทุน (N3)
- `sumMoney`: บวกทีละช่อง · `bookings` = จำนวน LIVE · `cancelledBookings` · `pendingRefundBookings` · `retainedSatang` = Σ `collectedSatang` ของ CANCELLED · `agentCollectBookings` · `noShowUnpaid` = จำนวน · EXCLUDED ไม่นับ
- **กระทบยอด (ข้อสอบ RC):** การจอง LIVE ที่ร้านเก็บเงิน ไม่มีคืน/จ่ายเกิน ⇒ `collected + outstanding = P` · CANCELLED ⇒ `paid − refunded = Σ RETAINED.amount` ⇒ `sales + passThrough = collected`
- `profitOf`: `grossProfitSatang = revenueExVat − commissionCost − cost` (ติดลบได้) · `marginBp = revenueExVat > 0 ? mulDivHalfUp(gp, 10000, revenueExVat) : null` (ปัดครึ่งออกจากศูนย์)
- `loadFactorBp(sold, cap) = cap > 0 ? mulDivHalfUp(sold, 10000, cap) : null` · ระดับรอบ: รอบ `CANCELLED` ⇒ `null` · `sold` = `TripDeparture.sold` · ต้องเท่ากับ Σ `seats` ของ LIVE + PENDING_REFUND (ฐานเดียวกัน · ข้อสอบตรวจ)
- `departureReportStateOf`: `CANCELLED` ⇒ `CANCELLED` · `now < endsAt` ⇒ `UPCOMING` · อื่น ⇒ `ENDED` ("เดินทางแล้ว") · **`estimate = true` ทุกรอบ** จนมีการปิดทริป (T1.5) (N7)
- `charterLikeOf` = `capacity > 0 ∧ liveBookings === 1 ∧ liveSeats >= capacity` — **ตัวบ่งชี้ชั่วคราว** (ระบบยังไม่มีช่องเหมาลำ · L1.11/S1.6) ⇒ ป้าย "รอบเหมาลำ — อัตราเต็มไม่สะท้อนการขายรายที่นั่ง" (N11)
- `costAccessOf` (N9 · แคบแบบ `canSeeSensitive`): ไม่มีสมาชิก ⇒ ทั้งคู่ false · OWNER ⇒ ทั้งคู่ true · เข้าหน่วยไม่ได้ (`unitAccess` ไม่มี `*`/unitId) ⇒ false · MANAGER ⇒ true · STAFF: `edit = permissions["trips.cost.edit"] === true` · `view = edit ∨ permissions["trips.cost.view"] === true` — **`trips.*` ไม่นับ**
- `parseCostRows` (ลำดับตัดสิน): ไม่ใช่อาร์เรย์ ⇒ `INVALID_INPUT` · ยาว > 30 ⇒ `COST_ROWS_LIMIT` · แถว strict `{ id?: string(1..100), kind, amountSatang, note?: string | null }` (คีย์เกิน/ชนิดผิด/kind นอกชุด ⇒ `INVALID_INPUT`) · amount ไม่ใช่จำนวนเต็มปลอดภัย ⇒ `INVALID_INPUT` · `< 1` หรือ `> TRIP_COST_AMOUNT_MAX` ⇒ `COST_AMOUNT_INVALID` · note: อักขระควบคุม U+0000–U+001F/U+007F ⇒ `INVALID_INPUT` · trim · > 200 ⇒ `INVALID_INPUT` · ว่าง ⇒ `null` · id ซ้ำ ⇒ `INVALID_INPUT` · Σ > 2,147,483,647 ⇒ `COST_AMOUNT_INVALID`
- `costRowsFromForm` (N11): แถว strict `{ id?, kind, amountText: string, note? }` (amountText ไม่ใช่สตริง หรือส่ง `amountSatang` มาแทน ⇒ `INVALID_INPUT`) · `amountText` ผ่าน `amountProblemOf`/`parseAmountSatang` ของ `booking-view-core` — `"format"` ⇒ **`COST_AMOUNT_FORMAT`** · `"zero"`/`"tooHigh"` ⇒ `COST_AMOUNT_INVALID` · ได้ตัวเลข ⇒ ส่งต่อ `parseCostRows` (`"1,200.50"` ⇒ 120050 · `"12.345"` ⇒ FORMAT · `"10000000.01"` ⇒ INVALID)
- `costContentKey` = JSON ของ `[kind, amountSatang, note]` เรียงไม่ขึ้นกับลำดับแถว (นับซ้ำ · `null` ≡ ไม่มีหมายเหตุ)
