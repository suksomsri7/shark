# แบบ: ตราสินค้าและธีมกิจการ (Tenant Branding & Theme) — 6 ก.ย. 2569

> สถานะ: **แบบเสนอ รอเจ้าของเคาะ — ยังไม่เริ่มเขียนโค้ด**
> ภาพประกอบ: `ledger/design-branding/01-settings.png` · `02-shell-brand.png` · `03-rail-dark-mobile.png` (HTML ต้นฉบับอยู่ข้าง ๆ แก้แล้วเรนเดอร์ใหม่ได้ด้วยคำสั่งท้ายไฟล์)

## 1. โจทย์จากเจ้าของ (6 ก.ย. จาก iPad)
1. ชอบแถบเมนูซ้ายที่ **ย่อแล้วยังเป็นไอคอน** (รางไอคอน 56px ที่ใช้ในบอร์ดงาน) → อยากให้เป็นพฤติกรรมทั่วไป
2. ผู้ใช้ตั้งค่าได้ว่า **สีหลักของกิจการ** สีอะไร
3. **แถบด้านซ้าย** สีอะไร
4. **ใส่โลโก้กิจการ** ให้แสดงมุมบนซ้าย

## 2. ของที่มีอยู่แล้ว (ไม่สร้างซ้ำ)
- ตาราง `TenantBranding { displayName, logoUrl, brandColor }` + หน้า `/app/settings/branding` + ฟอร์ม `branding-form.tsx` — ตอนนี้ใช้เฉพาะ **หน้าร้านสาธารณะ** (`/s/…/shop`, `/f/…`) ผ่าน CSS var `--color-accent`
- โครงแอปมี `--color-accent` / `--color-accent-soft` ใน `globals.css` อยู่แล้ว → ทุกปุ่ม/ลิงก์/สถานะ active อ่านจากตัวแปรนี้ ⇒ **เปลี่ยนสีทั้งระบบได้ด้วยการตั้งตัวแปรเดียวที่ราก**
- รางไอคอน `NavRail` (56px) ใช้เฉพาะเส้นทางบอร์ดงาน (`isRailPath`) · แถบเมนูปักซ้าย `NavDrawer variant="pinned"` (288px) ใช้ที่อื่น
- แอป SHARK HUB ดึง `/api/mobile/me` ตอนล็อกอิน — เพิ่มฟิลด์ branding ในคำตอบได้โดยไม่ต้องบิลด์ใหม่ (OTA)

## 3. หลักการออกแบบ
- **ตั้งครั้งเดียว ใช้ทุกที่**: หน้าเดียว (ตั้งค่า › ตราสินค้าและธีม) ครอบระบบ SHARK · แอปมือถือ · หน้าร้าน · เอกสาร/อีเมล — ยุบหน้า White label เดิมเข้ามา
- **ปลอดภัยเรื่องอ่านง่าย**: ระบบคำนวณสีตัวอักษรบนสีแบรนด์เอง (ขาว/เข้ม) ด้วย WCAG contrast ≥ 4.5 · สีอ่อนเกินจะเตือนและสลับให้ ไม่ปล่อยให้ตัวอักษรขาวบนเหลือง
- **ธีมเป็นของร้าน สถานะแถบเป็นของคน**: สี/โลโก้/โทนแถบ = ระดับกิจการ (เจ้าของ/ผู้ดูแลตั้ง) · ย่อ/ขยายแถบเมนู = ระดับผู้ใช้ (จำต่อบัญชี)
- **ไม่แตะจานสีของเนื้อหา**: ป้ายกำกับ/สถานะ/กราฟยังใช้สีความหมายเดิม (แดง=เลยกำหนด ฯลฯ) — สีแบรนด์ใช้กับ "โครง" และ "จุดเน้น" เท่านั้น กันหน้าจอเลอะ

## 4. หน้าตั้งค่า (ภาพ 01)
เส้นทาง `/app/settings/branding` (แทนหน้า White label เดิม) · สิทธิ์ OWNER/ADMIN
| ส่วน | รายละเอียด |
|---|---|
| โลโก้กิจการ | อัปโหลด PNG/SVG/JPG ≤ 2MB (ใช้ storage เดิม `uploadFile kind LOGO`) · ระบบสร้าง 3 ขนาด: แถบบน 34px · รางไอคอน 24px · favicon/PWA 192/512 · แสดงตัวอย่างทั้ง 3 ขนาดทันที · ไม่มีโลโก้ = ตัวย่อ 2 ตัวอักษรบนพื้นสีแบรนด์ (เหมือนปัจจุบัน) |
| ชื่อที่แสดง | ว่าง = ชื่อกิจการ · ใช้ข้างโลโก้และในอีเมล/เอกสาร |
| สีหลักของกิจการ | 8 สีมาตรฐาน (เทียล น้ำเงิน ม่วง ชมพู แดง ส้ม เขียว ดำ) + กรอก hex + ตัวเลือกสีของเบราว์เซอร์ · กล่องผลตรวจความคมชัด: "ตัวอักษรบนสีนี้ใช้ ขาว · 5.9:1 ผ่าน AA" |
| แถบเมนูซ้าย | 3 โทน: **สว่าง** (ปริยาย = ปัจจุบัน) · **สีหลักของกิจการ** · **เข้ม** (เทา #111827) · แต่ละโทนมีภาพย่อให้เห็นก่อนเลือก |
| สวิตช์ | จำสถานะย่อ/ขยายของแต่ละคน (เปิดปริยาย) · ใช้กับหน้าร้าน/ใบเสนอราคา/อีเมล · ใช้กับแอปมือถือ |
| ตัวอย่างสด | โครงแอปย่อขวามือ อัปเดตทันทีทุกการเปลี่ยน ยังไม่บันทึกจนกด "บันทึกและใช้กับทั้งร้าน" · ปุ่ม "ดูตัวอย่างเต็มจอ" เปิดแอปจริงพร้อม `?theme=preview` (เห็นเฉพาะคนกด) |

## 5. การนำไปใช้ในโครงแอป (ภาพ 02, 03)
- **แถบบน**: โลโก้ 34px + ชื่อที่แสดง ที่มุมซ้าย (ตำแหน่งเดิมของชื่อกิจการ) · avatar ผู้ใช้ใช้สีแบรนด์
- **แถบเมนูปักซ้าย (288px)**: พื้นตามโทนที่เลือก · หัวแถบ = โลโก้+ชื่อกิจการ+▾ สลับกิจการ · รายการที่เลือกเป็นพื้นโปร่งขาว 16% (โทนสี/เข้ม) หรือกรอบขาว (โทนสว่าง) · ปุ่ม "+ เพิ่มระบบ" กลับสี (ขาวบนแบรนด์ / แบรนด์บนสว่าง)
- **รางไอคอน (56px) ใช้ได้ทุกหน้า**: ปุ่ม ‹ ท้ายแถบ = ย่อ · › บนราง = ขยาย · โลโก้ย่อ 24px บนสุด · ชี้ไอคอน 300ms ขึ้น tooltip ชื่อเมนู · จุดแดง = มีแจ้งเตือน (เช่น แชท 5) · หน้าบอร์ดงานยังบังคับรางเหมือนเดิม (K1.5) · จำสถานะต่อผู้ใช้ (`preferences.navCollapsed`)
- **สีหลัก**: ตั้ง `--color-accent` (+ `-soft`, `-fg`) ที่ `<html>` ผ่าน `AppShell` จากข้อมูล tenant ⇒ ปุ่มหลัก ลิงก์ แท็บ active ชิปที่เลือก แถบเน้นของบอร์ด ใช้สีเดียวกันทั้งระบบโดยไม่ต้องไล่แก้ทีละหน้า
- **มือถือ/แอป (ภาพ 04)**: แถบบนของเว็บบนจอแคบใช้โทนเดียวกับแถบเมนู + โลโก้ · แอป SHARK HUB รับ `{ logoUrl, brandColor, navTone }` จาก `/api/mobile/me` → จอล็อกอิน (โลโก้แทน orb ถ้ามี) · ปุ่มหลัก · หัวรายการแชท/ห้องแชท · ไอคอนแท็บ · แคชไว้ในเครื่องเพื่อไม่กะพริบตอนเปิด

## 6. ข้อมูลและสัญญา
```
TenantBranding (ขยาย)
  displayName  String?
  logoUrl      String?      // ต้นฉบับ
  logoSmallUrl String?      // 24/34px ที่ resize แล้ว (ใหม่)
  brandColor   String?      // #RRGGBB (เดิม)
  brandFg      String?      // "#ffffff" | "#0a0a0a" คำนวณตอนบันทึก (ใหม่)
  navTone      NavTone @default(LIGHT)   // LIGHT | BRAND | DARK (ใหม่)
  applyStorefront Boolean @default(true) // เดิม = ใช้กับหน้าร้านเสมอ (ใหม่)
  applyMobile     Boolean @default(true) (ใหม่)
UserPreference.navCollapsed Boolean (ใหม่ · ต่อผู้ใช้)
```
- service `branding.ts`: `getBrandingTokens(tenantId) → { accent, accentSoft, accentFg, navBg, navFg, logoUrl, logoSmallUrl, displayName }` (แคช 60 วิ) · `saveBranding` ตรวจ hex + คำนวณ contrast + resize โลโก้ (sharp) + ลง AuditLog
- Outbox event `tenant.branding.updated` → invalidate แคช + แจ้งแอป (push เงียบ) ให้ดึงธีมใหม่
- API: เพิ่ม `branding` ในคำตอบ `/api/mobile/me` และ `/api/v1/tenant` (ไม่ต้องสร้าง endpoint ใหม่)

## 8. คำถามให้เจ้าของเคาะ
1. โทนแถบเมนูปริยายของร้านใหม่ = สว่าง (เสนอ) หรือสีแบรนด์?
2. ให้พนักงานเลือกโทนเองได้ไหม (เช่น บางคนชอบเข้ม) — เสนอ **ไม่** ในรุ่นแรก ให้ธีมเป็นของร้านล้วน
3. โลโก้ในอีเมล/ใบเสนอราคา ใช้ตัวเดียวกับแถบบน หรือให้อัปโหลดแยก (โลโก้แนวนอน)? — เสนอ: ตัวเดียว + ช่อง "โลโก้แนวนอน (ไม่บังคับ)" เพิ่มทีหลัง
4. ต้องการ "ธีมมืดทั้งระบบ" ด้วยไหม — เสนอ ยังไม่ทำ (คนละเรื่องกับสีแบรนด์ ใหญ่กว่ามาก)
