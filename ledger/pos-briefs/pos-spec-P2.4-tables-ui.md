# POS P2.4U — spec: โหมดโต๊ะ (screen 03 · register table mode · bill-type chip)

Builder U · 10 Oct 2026 · base `session/pos` 7365d4db (+ merge `origin/session/pos` 1c613e52 = P2.8 S) · prompt `pos-prompt-accountB-P2.4U.filled.md` rulings 1–13 · S contract `wo-notes/pos-P2.4.md` §"P2.4U contract" + additions + fix-round-3 rule.
Money is never computed in the UI: card/summary numbers come from `registerTablesAction`, panel/checkout totals from `quoteRegisterCartAction({cart:{lines:[], tableSessionId}})`, line totals from `registerTableDetailAction` (server snapshots).

## 1. Routes and frame
| route | who | content |
|---|---|---|
| `/app/sys/[id]/pos/tables?unit=&open=&sent=` | POS of the tenant + register v2 on; no accessible linked unit = 404; `posRegisterView` refused (no `pos.sale.create` at the unit / other unit) = refusal card `pos-tables-refusal` (HTTP 200, before any table read) | `TablesScreen` |
| `/app/sys/[id]/pos/register?unit=&table=<TableSession.id>` | same as register | `RegisterScreen` in table mode (`tableSessionId` prop · key = unit + table) |
Frame = register frame: `RegisterTopContext` (unit switch links to the same page · no camera on the tables page) + `RegisterModeTabs` (`active="tables"`; register: "โต๊ะ" = link when `registerTableMode().visible`, else the "เร็ว ๆ นี้" chip) · icon rail (`NavRail.isRailPath` also matches `/pos/tables` for v2 systems).

## 2. TablesScreen (`src/components/pos/tables/TablesScreen.tsx`)
- Layout: D ≥1280 floor + right column 380 (panel or `page.pickHint` + alerts) · T/M 768–1279 floor (+ alerts strip above the grid) and the panel as a right sheet 420 when a table is selected · C <768 floor + full-screen panel (history entry: browser back closes it).
- Data: SSR `registerTables` for the first paint; `registerTablesAction` + `registerTableRequestsAction` every 20 s while `visibilityState === "visible"` (cleared on unmount) and on tab return; selected session: `registerTableDetailAction` on every poll; table quote re-run whenever `itemsHash` changes.
- Time: minutes/clock texts only after mount (HF-418) from `serverTime` + elapsed local time; all clock texts are Bangkok time.
- Toast `pos-tbl-toast`; dialogs share the register dialog frame (`RegisterDialog`); Esc closes the top layer, then the non-column panel.
- Empty (`pos-tbl-empty`): `tableCount 0` + `canCreateTables` ⇒ CTA `pos-tbl-empty-setup` → `/app/u/<unit slug>/restaurant/setup`; otherwise muted `pos-tbl-empty-muted`.

## 3. Floor (`TableFloor` · `TableCardView`)
Zone tabs `pos-tbl-zone-all` / `pos-tbl-zone-<zoneId>` ("ในร้าน (12)") · queue chip `pos-tbl-queue-planned` (PLANNED, no data) · `pos-tbl-reservations` "จองโต๊ะวันนี้ N" · summary `pos-tbl-summary` (used/total · guests · avg minutes · unpaid ฿) + "แตะโต๊ะเพื่อเปิด" · grid 2/3/4/5/6 columns · zone note `pos-tbl-zone-note` (static) · legend `pos-tbl-legend` with counts + selected + unsent.
Card `pos-tbl-card-<name>` (`data-state`): name + state label (`tables.state.*`); sub-line FREE/INACTIVE "N ที่นั่ง" · DINING "N คน · member · เรียกพนักงาน|พร้อมเสิร์ฟ N" + red "ยังไม่ส่งครัว N รายการ" · BILL_REQUESTED "N คน · ขอผ่าน QR|เรียกที่โต๊ะ|แจ้งจ่ายพร้อมเพย์แล้ว" (accent tint) · NEEDS_CLEARING (dashed) "ยังไม่เก็บ · N นาที" + `pos-tbl-card-clear-*` · RESERVED "จอง hh:mm · ชื่อ N คน · กันโต๊ะ hh:mm" + `pos-tbl-card-booking-*`; bottom minutes + `unpaidSatang`; FREE quick action `pos-tbl-card-open-*`; selected = 2.5 px accent outline.

## 4. Panel (`TablePanel` · `pos-tbl-panel`)
Header "โต๊ะ X" + state pill + "⋯" (`pos-tbl-panel-more` → `pos-tbl-menu-close` / `-member` / `-unlink`) + close (non-column). Session line `pos-tbl-panel-opened` ("เปิด hh:mm · N นาที · N คน · พนักงาน X" — name from `listStaffForDeviceAction`, else without staff; guest-opened = "· ลูกค้าเปิดเองผ่าน QR") + member line.
Rounds `pos-tbl-round-<dailyNo>`: "ออเดอร์ #N (hh:mm) · พนักงานรับที่โต๊ะ|สั่งเองผ่าน QR"; items ×qty · name · options/note · KDS chip (`tables.panel.kds.*` / "จ่ายแล้ว") · ฿lineTotal; > 3 served in a round ⇒ show 2 + `pos-tbl-served-more-<orderId>` ("เสิร์ฟแล้วอีก N รายการ · names · ฿"); unpaid, not served, not cancelled items are buttons `pos-tbl-item-<id>` → cancel dialog (reason required ≤ 200) → `registerCancelTableItemAction` (VALIDATION shows the server's Thai reason, other codes = `refusalMessageKey`). Quote lines with `stockCut:false` ⇒ badge `pos-tbl-stock-not-cut` "ไม่ได้ตัดวัตถุดิบตามสูตร".
Draft `pos-tbl-draft` "มีรายการยังไม่ส่งครัว N" + link `pos-tbl-draft-open`. Totals `pos-tbl-totals` (รวม · ส่วนลดระดับ · ค่าบริการ N% · ยอดสุทธิ `pos-tbl-net`) + `pos-tbl-sc-differs` when `serviceCharge.differs`. Buttons: `pos-tbl-order-more` (link to table mode) · `pos-tbl-planned-{moveTable,mergeTable,splitBill,printList}` (disabled + "เร็ว ๆ นี้") · primary `pos-tbl-checkout-open` "เช็คบิล ฿x" (disabled with a reason line: no `pos.sale.create` · offline · device revoked · shift required + `pos-tbl-shift-open` · PIN device without staff token + `pos-tbl-unlock-register`).
No-session panel: FREE "N ที่นั่ง · พร้อมรับลูกค้า" + `pos-tbl-panel-open` · RESERVED reservation box + `pos-tbl-panel-seat` + open (override) + `pos-tbl-panel-bookings` · NEEDS_CLEARING `pos-tbl-panel-clear` · INACTIVE text.
Open dialog `pos-tbl-open-dialog` (guests −/+ · `pos-tbl-open-confirm` → `registerOpenTableAction` · toast `tables.reservation.overridden` when overridden). Close dialog `pos-tbl-close-dialog` (`TABLE_HAS_UNPAID` / `BUSY` stay in the dialog).

## 5. Checkout (`TableCheckout` · `pos-tbl-checkout`)
Existing `PayDialog` + `PayDone`. Quote `{lines:[], tableSessionId, billDiscount?, couponCode?}` (member = the session's, server side); extras row in the pay dialog: `pos-tbl-checkout-discount` (BillDiscountDialog) · `pos-tbl-checkout-coupon` (CouponDialog; invalid ⇒ removed + toast) · over cap ⇒ `pos-tbl-checkout-discount-over` → manager PIN only (`DiscountOverSheet canRequest=false` → `quoteRegisterCartOverrideAction` + `managerPin/managerUserId` on submit).
Submit `{lines:[], tableSessionId, expectedTableItemsHash: quote.table.itemsHash, idempotencyKey, expectedGrandTotalSatang, payMethods, cashReceivedSatang?, tipSatang?, billDiscount?, couponCode?, staffToken?, managerPin?}`. Key = one per checkout opening (`tbl-<uuid>`); refusals that prove no sale keep the key; UNKNOWN/INTERNAL/BUSY/network ⇒ "unknown" + retry with the same payload; pending payload in sessionStorage `pos-tbl-pending:<system>:<unit>:<user>` (no manager PIN) ⇒ restored on reload in the "unknown" phase; `beforeunload` guard while sending/unknown.
`TABLE_ITEMS_CHANGED` ⇒ re-quote + toast `tables.checkout.itemsChanged` (dialog stays, new total) · `TABLE_EMPTY` / `TABLE_SESSION_CLOSED` / `TABLE_NOT_FOUND` ⇒ close + reload + toast · `PRICE_CHANGED` / `PAYMENT_MISMATCH` ⇒ re-quote · `IDEMPOTENCY_CONFLICT` ⇒ conflict phase. Done ⇒ PayDone (print as the register) → "ขายบิลถัดไป" closes and reloads floor + panel.
PAY_PROMPTPAY alert "ยืนยันรับเงิน" ⇒ same checkout with `initialMethod="PROMPTPAY"` and no payment intent (guest already paid the static QR — manual confirm as P1.6).

## 6. Reservations sheet (`ReservationsDialog` · `pos-tbl-reservations-sheet`)
List = `registerReservationsTodayAction` (thin wrapper · BOOKED, today Bangkok) rows `pos-tbl-reservation-<id>` "hh:mm · ชื่อ · N คน" + table/hold-from/phone; seat `pos-tbl-reservation-seat-<id>` (no table ⇒ pick `pos-tbl-reservation-seat-table-<id>` + confirm) → `registerSeatReservationAction` (occupied ⇒ `tables.errors.occupied`) · cancel → confirm → `registerCancelReservationAction` · form `pos-tbl-reservation-form` (name, phone, party, datetime-local Bangkok, hold minutes default 15, table optional) → `registerCreateReservationAction`.

## 7. Alerts (`TableAlerts` · `pos-tbl-alerts`)
`pos-tbl-alert-<id>` rows: CALL_STAFF PENDING → `pos-tbl-alert-ack-*` · ACKED → `pos-tbl-alert-done-*` · REQUEST_BILL → `pos-tbl-alert-open-*` (select table) · PAY_PROMPTPAY → `pos-tbl-alert-pay-*` (select + checkout PROMPTPAY).

## 8. Register table mode (`RegisterScreen` hunks · `CartPanel tableMode`)
Load: `registerTableDetailAction` → `detail.draft.cart` → cart (+ `registerProductsByIdsAction` for names) · header chip `pos-tbl-order-chip` "โต๊ะ X · สั่งเพิ่ม" + `pos-tbl-order-back`; hidden: bill discount line/button, note, tax invoice, member chip/scan, coupon, hold/recall (F8 no-op), bill-type chip, line discount (`LineEditor noDiscount`); weighed products refused (`tables.order.noWeighed`); price note `pos-tbl-order-price-note`.
Save: `holdTableDraftAction` — first `newDraft:true`, later `heldCartId + expectedVersion` (`draftVersion` of the last result / `detail.draft.version`). `pos-tbl-order-save` = hold only (toast `tables.toast.draftSaved`); `pos-tbl-order-send` "ส่งครัว N รายการ" = hold then `registerSendTableRoundAction` → `/pos/tables?unit=&open=<session>&sent=<dailyNo>` (toast "ส่งครัวแล้ว · ออเดอร์ #N"). `VERSION_CHANGED` / `ALREADY_RECALLED` ⇒ reload the latest draft and append the cashier's own new lines (lines not in the last loaded/saved draft) + toast `errors.versionChanged` / `errors.alreadyRecalled` (never a blind overwrite) · `PRODUCT_UNAVAILABLE` / `OPTIONS_INVALID` + `lineIndex` ⇒ line error `tables.order.lineRefused` (draft kept) · `BUSY` ⇒ `pos-tbl-send-retry` · closed/missing ⇒ banner `pos-tbl-order-state` + `pos-tbl-order-closed-back`. Mobile bar primary = "ส่งครัว ›".

## 9. Bill-type chip (`CartPanel` `BillTypeChip` · wrapper `pos-reg-billtype`)
Live when the unit has table mode with ≥ 1 table: `pos-reg-bill-type` (P1.3 testid kept) → menu `pos-reg-billtype-takeaway` (default) / `pos-reg-billtype-dinein` ⇒ cart has discount/member/coupon/channel/weighed/bill note ⇒ `pos-tbl-billtype-strip` ("รายการเหล่านี้จะถูกตัดออก — ใส่ตอนเช็คบิลได้") ⇒ `pos-tbl-pick` (cards `pos-tbl-pick-<name>`): free/reserved/dirty ⇒ `registerOpenTableAction` then `holdTableDraftAction({newDraft:true, cart})`; seated table ⇒ `newDraft:true`, and on `VERSION_CHANGED` append onto the latest draft with `heldCartId + expectedVersion` ⇒ register table mode. Units without tables keep the P1.3 "เร็ว ๆ นี้" chip; table mode hides it.

## 10. Q10 info + legacy pages
`OpenTablesInfo` (`pos-tbl-open-info`): "โต๊ะยังไม่ปิด N · ฿x" per unit with tables — shifts X card (current unit) and close-day (today, units in scope); display only. Legacy restaurant floor/session pages on table-mode units (`posTableModeForUnit`: POS v2 linked + `registerTableMode().visible`, users without POS rights ⇒ table count): note `rest-pos-tables-note` + link "จัดการที่ POS › โต๊ะ"; เช็คบิล links, item ยกเลิก and the PromptPay "ยืนยันรับเงิน" (legacy checkout) hidden.
