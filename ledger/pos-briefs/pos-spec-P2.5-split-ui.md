## 3. Split modal `pos-tbl-split-modal` (rulings 2–6)
Frame: 1440 = centred 1180 × 760 (items 470 | bill cards 2 columns) · 1024 = full width, bill cards under the item list · 390 = full-screen sheet, cards scroll horizontally, footer (pay bar) always visible. Header "แยกบิล · โต๊ะ X · ฿total" + chip `pos-tbl-split-chip` "N คน · member · tier"; close `pos-tbl-split-close` (Esc; the scrim does not close — unsaved drafts). Tabs `pos-tbl-split-tab-items|equal|seat` (`data-mode` ITEM|EQUAL|SEAT on the modal).
- **รายรายการ (15B)**: rows `pos-tbl-split-row-<itemId>` (name ×qty · ฿line) with segmented `pos-tbl-split-line-<itemId>-part-<n>` (one tap = whole line); qty > 1 ⇒ `pos-tbl-split-qty-<itemId>` (chevron, or chip "บิล 1 x3 · บิล 2 x1" when spread) → `pos-tbl-split-qty-dialog` with `-less-<n>` / `-more-<n>` steppers (Σ ≤ qty) + `pos-tbl-split-qty-done`. Unassigned rows `data-unassigned` (danger tint) block save. Cards `pos-tbl-split-card-<n>` (`data-status` PAID|SELECTED|OPEN): select `pos-tbl-split-select-<n>` (title "บิล n · member", ฿total, "รวมค่าบริการ 10%"), member chip `pos-tbl-split-member-<n>` ("สะสมแต้ม" / "+ สมาชิก"), per-bill pre-bill `pos-tbl-split-prebill-<n>` (saved, unpaid), lines (shares "<item> (u/N)"), รวม/ค่าบริการ/สุทธิ; empty card ⇒ `pos-tbl-split-removePart-<n>`; `pos-tbl-split-addPart` (≤ 20). Default member: the session member on bill 1.
- **หารเท่า (15C left)**: stepper `pos-tbl-split-stepper` (`-less` / `-value` / `-more`, 2..20, default = guests) · `pos-tbl-split-equal-big` "N คน × ฿q" · sub "ลงตัว" or "บิล 1–r +฿0.01" (r = parts above the minimum — EQUAL totals-first, ruling §11.1) · cards with status "✓ <method>" (bills drawer `billDetailAction(saleId).bill.payments[].type` → `pos.register.pay.*`) / "กำลังชำระ" / "รอชำระ" · footer progress.
- **ตามที่นั่ง (15C right)**: seat chips `pos-tbl-split-seat-<n>` + `pos-tbl-split-seat-shared` (tap a row via `pos-tbl-split-pick-<itemId>`, then a chip; or the row segmented incl. `part-0` = กลางโต๊ะ) · rows `pos-tbl-split-seatrow-<n>` "ที่นั่ง n · items ฿x" + `pos-tbl-split-seatrow-shared` "กลางโต๊ะ · item ฿x หารทุกที่นั่ง ที่นั่งละ ฿y · รวมในยอดแล้ว" · seat footer · stepper also here (N = parts).
- Footer: note (15B proportional / equal progress / seat footer) + unassigned count + error + pay-block reason; `pos-tbl-split-cancel` (OPEN, not locked) → `pos-tbl-split-cancel-dialog` (`-back` / `-confirm` → `registerCancelSplitAction`); `pos-tbl-split-save` "ชำระทีละใบ" = save, keep modal (disabled when clean/incomplete); primary `pos-tbl-split-payPart-<selected>` "ชำระบิล n ฿x" = save if needed, then part pay.
- Save = `registerSplitTableAction` create (`expectedItemsHash` = whole-table quote `table.itemsHash`, fallback detail hash) or replace (`splitId` + `expectedVersion`, hash = plan's); parts sent explicitly with `memberId` (null = none). Refusals: `TABLE_SPLIT_EXISTS` / `TABLE_SPLIT_LOCKED` / `TABLE_SPLIT_PART_PAID` / `VERSION_CHANGED` / `TABLE_ITEMS_CHANGED` / `TABLE_SPLIT_NOT_FOUND` ⇒ toast + reload detail + show the latest plan (locked if paid); `TOO_MANY_LINES` ⇒ "แยกเป็นรายรายการแทน"; `TABLE_SESSION_CLOSED|NOT_FOUND|EMPTY` ⇒ toast + close; `PERMISSION_DENIED` ⇒ toast; `VALIDATION` ⇒ unassigned text or the refusal key.
- Locked (`parts.some(PAID)`): `data-locked`, tabs/rows/stepper/member chips disabled, cancel hidden, `pos-tbl-split-locked` "แผนล็อกแล้ว — ยกเลิกได้โดยยกเลิกบิลที่ชำระแล้ว". New items (`outsideItemIds`) ⇒ `pos-tbl-split-newitems` "รายการใหม่หลังแยกบิล N — ชำระหลังครบทุกใบ".
- Member chooser `pos-tbl-split-member-dialog`: `-table` (session member) · form `-form` + `-q` + `-search` (`registerMemberLookupAction`) · `-pick-<id>` · `-none` · `-close`.

## 4. Part pay (ruling 7)
`TableCheckout` with `split` = the existing PayDialog/PayDone: cart `{lines: [], tableSplitPartId, memberId (when the part has one), couponCode? (member parts only)}` · no bill-discount button · header chip `pos-reg-paydlg-splitchip` "บิล n จาก N · โต๊ะ X" (from `quote.split`) · submit `expectedSplitVersion = quote.split.version` (no `expectedTableItemsHash`) · `TABLE_SPLIT_PART_PAID` / `VERSION_CHANGED` / `TABLE_SPLIT_NOT_FOUND` / `TABLE_ITEMS_CHANGED` ⇒ toast + back to the modal; `STORE_CREDIT_NOT_OWNER` / `VALIDATION` ⇒ error card in the dialog · pending-retry storage keeps `split`. PayDone → "ถัดไป" ⇒ toast "ชำระบิล n แล้ว" → detail reload: plan still OPEN ⇒ modal re-opens with the next unpaid part selected; session CLOSED (S closes on the last part — `register.ts regSubmitSplitPart` → `settleTableItemsInTx closeWhenPaid`) ⇒ modal closed + toast "ชำระครบทุกใบ · โต๊ะ X ปิดแล้ว"; plan DONE but new items remain ⇒ toast "ชำระครบทุกใบแล้ว — ยังมีรายการใหม่ค้างจ่าย".

## 5. Move / merge (ruling 8)
- Move: `pos-tbl-moveTable` → `pos-tbl-move-sheet` (TablePickDialog: free tables only, not the current) → reserved target ⇒ `pos-tbl-move-confirm` ("จองไว้ hh:mm — ย้ายทับการจอง?") · else immediate `registerMoveTableAction` · success toast `tables.move.kitchenNote` + the panel follows the session · `TABLE_BUSY` ⇒ toast + `pos-tbl-toast-action` "ใช้รวมโต๊ะแทน" (merge chooser with that table preselected; needs the merge key) · other codes ⇒ toast.
- Merge: `pos-tbl-mergeTable` → `pos-tbl-merge-sheet` (dining tables except this one, toggles `pos-tbl-merge-pick-<name>` 1..5) → summary `pos-tbl-merge-summary` "รวม A2 + B1 เข้า A1 · N คน · ฿x" → `pos-tbl-merge-confirm` → `registerMergeTablesAction` · `TABLE_HAS_DRAFT` / `TABLE_SPLIT_OPEN` ⇒ toast.
- Floor drag: HTML5 drag on seated cards (`pointer: fine` only — touch never starts a drag) with a move or merge key; drop on a free card ⇒ `pos-tbl-move-confirm`; drop on a dining card ⇒ `pos-tbl-merge-confirm-dialog` (into = drop target). Hint "แตะโต๊ะเพื่อเปิด · ลากโต๊ะเพื่อย้าย/รวม".
