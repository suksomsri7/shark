## 2. Anomaly rows (CD-P38U-7)
- Page passes `boardOn = posBoardSettings(sys.settings).enabled`; off ⇒ no button/chip.
- Row date = `r.businessDate ?? (from === to ? from : null)`; null ⇒ button disabled + `pos-reports-anomaly-card-reason-<n>` `toCard.oneDay`.
- On load (kind anomalies ∧ boardOn): one `posBoardCardsAction({systemId, keys})` with `posBoardKeys.anomaly(rule, unitId, date, refId ?? userId ?? "unit")` ⇒ rows with a card show chip `pos-reports-anomaly-card-chip-<n>` (`toCard.chip`/`chipDone`, link `href`) instead of the button.

- `AnomalyBody` is keyed by `generatedAt` (a new report = fresh row states).
