# S3a.5 — ลิงก์สาธารณะใบเสนอราคา: ลูกค้าเปิดดู + ดาวน์โหลด (มติเจ้าของ 7 พ.ย. 2569 แทน R-Z48) · เลน b · ต่อจากทิปผู้คุมล่าสุด
Read COMMON · RESOLUTIONS §Z.6 R-Z45/R-Z48 · `src/app/(store)/r/[token]/page.tsx` (แบบหน้าสาธารณะ: token = capability · rate limit ตาม IP · noindex · no-referrer) · `src/app/app/sys/[id]/account/print/[docId]/page.tsx` + `print-options.ts` (เทมเพลตพิมพ์เอกสาร · ป้ายไทย/อังกฤษตามตั้งค่า) · `proposals.ts` dispatchChatSend/latestQuoteLine · `account/service.ts` ensurePublicTaxInvoiceLink + issue document

## ส่วน A (ทำเลย · ไม่มีแพ็กเกจใหม่)
1. **ออกเอกสารก่อนส่ง**: `chat.send` kind=quote ที่อ้างใบ DRAFT ⇒ ตอนลงมือ (ผู้อนุมัติ) ออกเอกสาร (ISSUED · ได้เลขที่) ด้วยทางเดียวกับปุ่ม "ออกเอกสาร" ในบัญชี ภายใต้สิทธิ์ของผู้กด (ไม่มีสิทธิ์ออกเอกสาร ⇒ ล้มด้วยข้อความไทย ใบคง PENDING) · ใบที่ ISSUED แล้วไม่แตะ
2. **token ลิงก์สาธารณะของ QUOTATION**: ฟังก์ชันใหม่ `ensurePublicDocumentLink(tenantId, systemId, docId)` (idempotent · ใช้ `publicToken` คอลัมน์เดิม · อนุญาต QUOTATION ที่ ISSUED/ACCEPTED เท่านั้น · DRAFT/CANCELLED/VOIDED ⇒ reason ไทย) — ไม่แตะ `ensurePublicTaxInvoiceLink` เดิม
3. **หน้า `/doc/<token>`** (route group `(store)` · server component · ไม่มี session): แสดงใบเสนอราคาเต็มแบบเทมเพลตพิมพ์เดิม (ป้ายภาษาตามตั้งค่าร้าน · โลโก้/ชื่อร้าน · รายการ · VAT · ยอด · เงื่อนไข · ช่องทางชำระ) อ่านอย่างเดียว · มือถือก่อน · ปุ่ม "ดาวน์โหลด PDF" (ส่วน B — ตอนนี้ลิงก์ไป `/doc/<token>/pdf` ซึ่งตอบ 501 + ข้อความไทย "กำลังเปิดให้ดาวน์โหลดเร็ว ๆ นี้" ถ้ายังไม่มีไลบรารี) + ปุ่ม "พิมพ์/บันทึกเป็น PDF" (window.print · CSS @media print ซ่อนปุ่ม) · ด่านเหมือน `/r/`: rate limit ต่อ IP + ต่อ token · token ผิด = notFound · robots noindex · referrer no-referrer · ไม่โชว์เลขผู้เสียภาษีของลูกค้าเต็ม (mask เหมือนใบเสร็จ) · ปิดลิงก์ได้ด้วยตั้งค่าเดียวกับ §9.2 (ถ้าร้านปิด ⇒ 404)
4. **ข้อความถึงลูกค้า (R-Z45)**: ต่อท้าย "เลขที่ <docNo> · ยอด <บาท> · ดูใบ: <origin>/doc/<token>" ทุกครั้ง (ไม่ใช่เฉพาะเมื่อมี token อยู่แล้ว) · ตัวขับ `qc-sec-real.mts` เกณฑ์เส้น 1 เปลี่ยนเป็น ต้องมีเลขที่ + ยอด + ลิงก์ (ผู้คุมแก้ตัวขับเอง — ห้ามแตะ)
5. **หน้าแอป**: ไม่แตะ (ลิงก์อยู่ในข้อความ)
## ส่วน B (รอเจ้าของอนุมัติแพ็กเกจ `@react-pdf/renderer` + ฟอนต์ Sarabun OFL ใน `public/fonts`) — ห้ามเริ่มจนกว่าผู้คุมสั่ง
