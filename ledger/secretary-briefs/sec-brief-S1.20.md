## กติกา API (จาก skill claude-api 4 พ.ย. 2026 — ใช้ raw fetch เพราะไม่มี `@anthropic-ai/sdk` ใน node_modules และห้ามติดตั้ง)
- `POST https://api.anthropic.com/v1/messages` · headers `x-api-key: <key>` · `anthropic-version: 2023-06-01` · `content-type: application/json`
- body: `{ model, max_tokens, system?: [{ type: "text", text, cache_control: { type: "ephemeral" } }], messages: [{ role: "user"|"assistant", content: string | Block[] }], tools?: [{ name, description, input_schema, cache_control? }] }` — **ไม่ส่ง** `temperature/top_p/top_k` (ตั้งแต่ API 2026-10-21 = 400) · ไม่ส่ง `thinking` (ค่าเริ่มต้นของโมเดลรุ่นปัจจุบัน = adaptive) · ไม่ใช้ prefill · ไม่ใช้ `tool_choice` บังคับ
- Block: `{type:"text", text}` · `{type:"image", source: {type:"base64", media_type, data} | {type:"url", url}}` · `{type:"tool_use", id, name, input}` (assistant) · `{type:"tool_result", tool_use_id, content}` (user)
- ผลลัพธ์: `{ id, model, stop_reason: "end_turn"|"tool_use"|"max_tokens"|"refusal"|…, content: [{type:"text", text} | {type:"tool_use", id, name, input} | {type:"thinking", …}], usage: { input_tokens, output_tokens, cache_creation_input_tokens?, cache_read_input_tokens? } }`
- model id ตรง: `claude-haiku-4-5` (= FAST) · `claude-sonnet-5` (= SMART) · รุ่นใหม่กว่า (`claude-haiku-5-5` · `claude-sonnet-5-5`) ตั้งผ่าน `SHARK_AI_MODEL` ได้ภายหลัง · ราคา: haiku 4.5 $1/$5 · sonnet 5 $2/$10 ต่อ 1M (pricing.ts ของเรา sonnet=3/15 ยังใช้ค่าเดิม — จดเป็นหนี้ ไม่แก้ในใบนี้)
