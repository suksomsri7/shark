## สร้างภาพใหม่
ตัวสร้างเป็น Python ล้วน (ไม่มี dependency) เขียน HTML แล้วถ่ายด้วย chromium headless:
```bash
python3 gen_airy_full.py   # ชุด ก ข ค (exec CSS + 8 หน้าแรกจาก gen_glass_airy.py)
python3 gen_airy_d.py      # ชุด ง
python3 gen_airy_e.py      # ชุด จ
python3 gen_airy_dark.py   # โหมดมืด: อ่าน html สว่าง a–e แล้วทับ CSS + สลับสี inline
./render_airy.sh a         # → shark-ai-team-airy-a.png   (b c d เหมือนกัน · e ใช้ ./render_airy.sh e 1620)
./render_airy.sh dark-a    # โหมดมืด (dark-e ใช้ 1620)
```
- `render_airy.sh` ฮาร์ดโค้ดโฟลเดอร์ `/root/design/chat-glass` (ที่ทำงานเดิมบน VPS) — ย้ายเครื่องแล้วแก้ path 2 จุดในไฟล์
- snap chromium มองไม่เห็น `/tmp` จริง → ไฟล์ html/png ต้องอยู่ใต้ home · ลบ user-data-dir หลังถ่ายทุกครั้ง (สคริปต์ทำให้แล้ว)
- ฟอนต์: Inter + IBM Plex Sans Thai (ต้องติดตั้งในเครื่อง)
- แก้หน้าไหน = แก้ตัวสร้างชุดสว่าง แล้วรัน `gen_airy_dark.py` ซ้ำ โหมดมืดตามเอง
- ก่อนส่งเจ้าของ: ครอปดูทุกจอว่าไม่มีอะไรล้น/ทับ/ชิดขอบ
