- เพิ่มระยะห่างคอลัมน์/แถว/การ์ดทุกจอ: ค่า `gap` ในทุกไฟล์ ×1.6 · `margin-top` ×1.4 · ทับด้วย `_airy.part` (padding การ์ด/ตาราง/ตะกร้า/ตั๋วครัว/แป้นตัวเลข · ตะกร้ากว้าง 460) · ความสูงกรอบเป็นไปตามเนื้อหา (`.frame{height:auto}`)
- เรนเดอร์แบบ full-page ด้วย `node render.mjs [NN …]` (puppeteer-core จาก /root/dive3d) — ไม่ต้องเดาความสูงอีก
- ภาพชุดก่อนหน้า (แน่นกว่า) อยู่ใน git ที่ commit `eb9aac8b`

## ไฟล์ในโฟลเดอร์

- `NN-*.png` — ภาพที่เรนเดอร์แล้ว (Fable ตรวจด้วยตาทุกใบ 30 ก.ย.)
- `NN-*.html` — เปิดดูได้จริงในเบราว์เซอร์ (self-contained)
- `NN-*.body.html` — เนื้อหาเฉพาะส่วน body (ไฟล์ต้นทางที่แก้) · CSS เฉพาะจออยู่ใน `<style>` หัวไฟล์
- `_base.part` — CSS + ชุดไอคอน SVG จาก `docs/design/account-v2/mockup.html` (ผ่าน design-kanban) — ห้ามคิดจานสีใหม่
- `_pos.part` — CSS เพิ่มเฉพาะ POS (กริดสินค้า/ตะกร้า/numpad/วิธีชำระ/QR/โต๊ะ/ตั๋วครัว/ใบเสร็จ/มือถือ/การ์ดเชื่อมระบบ/กราฟ)
- `_airy.part` — CSS รอบ "โปร่งขึ้น" ต่อท้ายทุกจอ (ทับด้วย !important)
- `render.mjs` — เรนเดอร์ full-page ทุกจอ
- `mk.sh` — ประกอบ: `./mk.sh 01-register.body.html "SHARK · POS · หน้าขาย"` → `01-register.html`
