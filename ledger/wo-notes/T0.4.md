## 1. ทะเบียนคำเตือนที่เดียว
- ไฟล์ `src/lib/core/settings/legal/warnings.ts` (pure · ใช้ได้ทั้ง server/client · อยู่ข้างตารางค่ากฎหมาย T0.2)
- แถวละรหัส: `code` · `titleTh` · `messageTh(params)` · `citation` (ไฟล์ references + § ของ skill + มาตรา) · `tag` V/V2/S/U · `checkedAt` (วันที่ skill ตรวจ) · `ack` (ต้องกดยืนยันก่อนทำต่อไหม)
- `LegalWarningCode` / `LegalWarning` ของ T0.2 **ย้ายมาอยู่ที่นี่** — th-tax-2569.ts / legal-values.ts import จากทะเบียน (re-export ชื่อเดิม) · ข้อความเดิมสร้างผ่าน `legalWarning(code, params)` ตัวเดียว
- ข้อความ: ห้ามคำว่า "ถูกกฎหมาย/ตามกฎหมายแล้ว" · ป้าย [U]/[S] ต่อท้าย "เป็นค่าเริ่มต้นของระบบ — โปรดตรวจกับนักบัญชีของร้าน" อัตโนมัติ · อ้างมาตราเมื่อ skill ให้
- รูปที่ส่งออก (REST / AI / จอ) = `LegalWarning { code, messageTh, citation, tag, checkedAt, ack }` ชุดเดียว

## 2. รูปเมื่อยังไม่กดยืนยัน
- service: `{ ok:false, reason, legal: { code:"LEGAL_ACK_REQUIRED", warnings } }` (ไม่ throw ขึ้นไปถึงผู้ใช้) · ข้าม: ส่ง `ack: { codes, actorId, actorType }`
- REST: 409 `legal_ack_required` + `error.warnings[]` + hint "ส่ง `acknowledge: [code…]` ซ้ำ" (รหัสใหม่ใน `API_ERROR_CODES` · ซองเพิ่มช่อง `warnings` เฉพาะรหัสนี้)
- AI tool: ข้อความไทยของ error รวมคำเตือน + รหัส ให้เลขาเสนอผู้ใช้กดยืนยัน (T7 ใช้รูปเดียวกัน)
- จอ: คอมโพเนนต์เดียว `src/components/legal/LegalWarningList.tsx` (ไอคอน `warn` ของ AccountIcon · ไม่มี emoji) + ช่องติ๊ก "รับทราบและทำต่อ" ส่ง `ackCodes` กลับไปที่ action เดิม

## 3. บันทึกการกดยืนยัน
- ใช้ `AuditLog` เดิม (ไม่เพิ่ม schema · ไม่มี migration): action `legal.warning.ack` · targetType/targetId = เอกสาร/ค่าตั้งที่ทำ · after `{ codes, op, warnings:[{code,citation,tag,checkedAt}] }` · actorType/actorId ของผู้กด (USER / API_KEY / AI ผ่านข้อเสนอ)
