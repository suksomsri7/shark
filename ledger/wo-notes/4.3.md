## ค้าง / ส่งต่อ
- ใบเบิก/ใบส่งคืน/ใบปรับต้นทุน **ยังไม่มีหน้ารายละเอียด** (คลิกเลขที่ในตารางยังวนกลับหน้ารายการ) · แก้ร่างที่บันทึกไว้ยังทำไม่ได้ (อนุมัติได้อย่างเดียวจากเมนูทำรายการ) → เฟส 9/5.x
- แนบไฟล์บนฟอร์ม "สร้างใหม่" ยังต้องบันทึกร่างก่อน (DocAttachments ต้องมี documentId) — ทางแก้คือ `onNeedDraft` เหมือน DocEditorV2
- "พิมพ์รายงาน" ของหน้าสินค้าใช้ `window.print()` (ยังไม่มีเทมเพลตรายงานสินค้า)
- `costMethod = FIFO` ยังปิดอยู่ (🕓) ตามขอบเขต BLUEPRINT §0.4
- ยอดยกมาลบ/แก้ไม่ได้ (เพิ่มได้อย่างเดียว) — ถ้าจะแก้ต้องมีตัวกลับรายการ
- รายการจัดชุด: ตัดสต็อกเมื่อออก INVOICE / RECEIPT(ที่ไม่ได้แปลงจาก IV) และบิล POS เท่านั้น — ใบกำกับภาษีที่ออกตาม IV ไม่ตัดซ้ำ (ตั้งใจ) · ยังไม่รองรับ "คืนของ/void แล้วคืนสต็อกส่วนประกอบ" → เฟส 5.x
- ยังไม่ backfill `AccountProduct.code` บน prod (แถวเก่า code = null → หน้ารายการถอยไปใช้ sku)
