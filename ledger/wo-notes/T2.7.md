# T2.7 — ต้นฉบับ / สำเนา / ใบแทน ของใบกำกับภาษี (ปิด B5 B6) · design note

ใบงาน: ledger/ACCOUNT-TAX-PLAN.md T2.7 · เช็กลิสต์ B5 B6 (ledger/ACCOUNT-AUDIT-CHECKLIST-127.md · ACCOUNT-AUDIT-SCREEN-PASS.md) + จอนอกข้อ 1–4, 7
กฎ (skill shark-thai-law `common-vat-invoice.md` §14 [V]):
- ฉ.39 ข้อ 1: ใบกำกับที่ไม่ใช่ฉบับแรกของชุดต้องมี "เอกสารออกเป็นชุด" และสำเนามีคำว่า "สำเนาใบกำกับภาษี" — ตีพิมพ์/ทำด้วยคอมพิวเตอร์ (ห้ามตรายาง) [V]
- ป.86/2542 ข้อ 4: ต้นฉบับให้ผู้ซื้อ สำเนาเก็บ [V] · "พิมพ์ซ้ำต้องไม่ได้ 'ต้นฉบับ' ใบที่สอง" (§14 ท้าย) · checklist B6 "ไม่ได้ต้นฉบับใบที่สอง · มี log การพิมพ์ซ้ำ"
- ใบแทน (ม.86/12 + ฉ.36) [V]: สำเนาใบเดิม + (1) ใบแทนออกให้ครั้งที่ (2) วันเดือนปีที่ออก (3) สาเหตุย่อ (4) ลายมือชื่อ + บันทึกในรายงานภาษีขายเดือนที่ออก
- ร้านไม่จด VAT ออกใบกำกับไม่ได้ (ม.86/13) — ด่านเดิม TAX_INVOICE_NOT_VAT_REGISTERED (ไม่แตะ)

## 1. ข้อมูล (schema เพิ่มอย่างเดียว · migration `20261231000000_acc_t27_print_log`)
- enum `AccountPrintKind` = ORIGINAL | COPY | SET (ต้นฉบับ+สำเนาพิมพ์พร้อมกัน) | SUBSTITUTE | ORIGINAL_REPRINT (ร้านยืนยันคำเตือนพิมพ์ต้นฉบับซ้ำ)
- enum `AccountPrintChannel` = SCREEN | PDF | EMAIL | PUBLIC_LINK
- ตาราง `AccountDocumentPrint` { id · tenantId · systemId · documentId · kind · channel · substituteSeq? · substituteReason? · substituteDate? · actorId? · actorType · createdAt }
  · unique (documentId, substituteSeq) · unique บางส่วน (documentId) WHERE kind IN ('ORIGINAL','SET') ⇒ "ต้นฉบับครั้งแรก" ได้แถวเดียวแม้กดพร้อมกันสองเครื่อง (แข่งกัน = ตัวที่แพ้กลายเป็น COPY)
- ทุกแถว = AuditLog `account.doc.print` (เป้า AccountDocument) ด้วย ⇒ ขึ้นในแท็บ "ประวัติ" ของเอกสาร (ใคร · เมื่อไร · ชนิด · ช่องทาง)

## 2. กติกาการพิมพ์ (ตัวคิดเดียว `print-log.ts` · pure ส่วนตัดสิน + ส่วนเขียน)
- ใช้กับ TAX_INVOICE ที่ออกแล้ว (ไม่ใช่ DRAFT) — รวมใบกำกับเต็มรูปที่มาจาก POS/โรงแรม/หอพักในสมุด (ใช้หน้าพิมพ์เดียวกัน) · เอกสารชนิดอื่นบันทึก log เหมือนกันแต่ไม่มีป้ายต้นฉบับ/สำเนา (skill พูดถึงใบกำกับ — ชนิดอื่นเงียบ ⇒ ไม่ใส่ป้าย)
- กด "พิมพ์" ครั้งแรก = ORIGINAL ("ต้นฉบับ") · ครั้งต่อไป = COPY: หัวใบ "สำเนาใบกำกับภาษี" + "เอกสารออกเป็นชุด" (ข้อความตรงตาม §14)
- "พิมพ์ชุด (ต้นฉบับ + สำเนา)" = SET: สองหน้าในงานพิมพ์เดียว — หน้า 1 ต้นฉบับ · หน้า 2 สำเนา (มี "เอกสารออกเป็นชุด") · ต้นฉบับพิมพ์ไปแล้ว ⇒ ชุดนี้เป็นสำเนาอย่างเดียว
- "พิมพ์ต้นฉบับซ้ำ" = คำเตือน `TAX_INVOICE_ORIGINAL_REPRINT` [V] ack → ยืนยันแล้วพิมพ์ "ต้นฉบับ (พิมพ์ซ้ำครั้งที่ n)" + บันทึกผู้ยืนยัน (หลัก SHARK: ไม่บล็อก — เตือน อ้าง ยืนยัน)
- "ออกใบแทน" = กล่อง: สาเหตุย่อ (บังคับ — ข้อมูลที่ใบแทนต้องมี = ความถูกต้องของเอกสาร) · วันที่ออก (ปริยายวันนี้) ⇒ ครั้งที่ = ลำดับถัดไปของใบนี้ · พิมพ์: หัว "ใบแทน" + กล่อง "ใบแทนออกให้ครั้งที่ n · วันที่ออก · สาเหตุ · แทนใบกำกับภาษีเลขที่ X ลงวันที่ Y" + ช่องลายมือชื่อผู้ออกใบแทน
- ร่าง (DRAFT): ลายน้ำ "ร่าง" + หัว "ร่าง — ยังไม่ใช่ใบกำกับภาษี" · ไม่มีป้ายต้นฉบับ/สำเนา · เลขที่ "(ร่าง)" · ไม่บันทึก log
- ยกเลิกแล้ว (VOIDED/CANCELLED): ป้าย "ยกเลิก" ทุกหน้า (ไม่มีป้ายต้นฉบับ)

## 3. หน้าจอ / เส้นทาง
- หน้ารายละเอียดเอกสาร: ปุ่ม "PDF" เดิม → เมนู "พิมพ์" (พิมพ์ · ดาวน์โหลด PDF · พิมพ์ชุดต้นฉบับ+สำเนา · ออกใบแทน · พิมพ์ต้นฉบับซ้ำ) — server action สร้างแถว log แล้วเปิด `/print/<docId>?p=<logId>` (หน้าพิมพ์อ่านชนิดจากแถว ⇒ รีเฟรชไม่สร้างต้นฉบับใหม่) · PDF = หน้าเดียวกัน + เปิดกล่องพิมพ์อัตโนมัติ (บันทึกเป็น PDF ในเบราว์เซอร์) ช่องทาง PDF
- เปิด `/print/<docId>` ตรง (ลิงก์เก่า/พิมพ์ด้วย URL): ใบกำกับที่ออกแล้ว ⇒ สร้างแถว (ช่องทาง SCREEN) แล้ว redirect ไป `?p=` — ลิงก์ตรงไม่ได้ต้นฉบับใบที่สองอีกต่อไป
- ลบข้อความ "พิมพ์ชุดสำเนาได้โดยเติม ?copy=1 ท้าย URL" · `?copy=1` เดิม = ขอสำเนา (บันทึก COPY)
- อีเมล (ปุ่มยังปิด "เร็ว ๆ นี้") / ลิงก์สาธารณะ (เปิดเฉพาะใบเสนอราคา) — enum มีช่องทางไว้ ไม่มีจุดเรียกในงานนี้
- REST: op อ่านประวัติการพิมพ์อยู่ในประวัติเอกสาร (AuditLog) — ไม่เพิ่ม op ใหม่ในงานนี้

## 4. ปัญหาพิมพ์ร่วม (จอนอก)
- ข้อ 1–2 โครงแอป/เบรดครัมบ์ติดบนกระดาษ: ซ่อนตอนพิมพ์ (print:hidden ที่ layout ของหน้าพิมพ์) — ถ้าอยู่ใน layout ร่วมทั้งแอป ใช้ CSS @media print ที่หน้าพิมพ์
- ข้อ 3 เงื่อนไขชำระเงิน: ข้อความของร้านมีจำนวนวันไม่ตรงกับ (ครบกำหนด − วันที่ออก) ⇒ พิมพ์เงื่อนไขจริงของเอกสาร "ชำระภายใน N วันนับจากวันที่ออกเอกสาร (ครบกำหนด <วันที่>)" แทน · ข้อความไม่มีจำนวนวัน/ตรงกัน = พิมพ์ของร้านตามเดิม
- ข้อ 4 หมายเหตุซ้ำ: หมายเหตุของเอกสาร = หมายเหตุท้ายเอกสารของร้าน (ตัดช่องว่างแล้วเท่ากัน) ⇒ พิมพ์ครั้งเดียว
- ข้อ 7 ใบรับมัดจำ "7%" แต่ VAT ฿0.00: คอลัมน์/แถว VAT ตามกลุ่มอัตราจริงของเอกสาร (ตัวเดียวกับ T1.8b §4) — เอกสาร VAT 0 ที่บรรทัดเป็นอัตราบวก (ภาษีเกิดเมื่ออื่น/ใบรับมัดจำไม่มี VAT) ⇒ คอลัมน์ VAT แสดง "—" และไม่มีแถว VAT 7%

## 5. คำเตือน / ค่าตั้ง
- `TAX_INVOICE_ORIGINAL_REPRINT` [V] ack — พิมพ์ต้นฉบับซ้ำ (อ้าง ฉ.39 ข้อ 1 · ป.86/2542 ข้อ 4 · §14)
- ไม่มีค่าตั้งใหม่ (กติกา [V] ทั้งหมด — ร้านทับได้ด้วยการยืนยันต่อครั้ง)

## 6. skill เงียบ → ค่าเริ่มต้นไม่แปลกใจ
- ป้ายต้นฉบับ/สำเนากับเอกสารชนิดอื่น (ใบลด/เพิ่มหนี้ ใบเสร็จ) — skill พูดถึงใบกำกับ ⇒ ไม่ใส่ป้าย แต่บันทึก log ทุกชนิด
- ใบแทนลงรายงานภาษีขายเดือนที่ออก: skill บอกให้ "บันทึกในรายงานภาษีขาย" — รายงานภาษีขาย (T1.1 เลน 1) ยังไม่มีแถวหมายเหตุของใบแทน ⇒ งานต่อ (เปิดคำถาม)
- "ลายมือชื่อ" บนใบแทน = ช่องเซ็นบนกระดาษ (ไม่ใช่ลายเซ็นภาพอัตโนมัติ)
