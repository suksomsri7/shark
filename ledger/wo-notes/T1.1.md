## 1. แหล่งความจริงของยอด = GL 2200 (ไม่เปลี่ยน)
- ยอดภาษีของทุกแถว = ผลรวมบรรทัด 2200 ของรายการบัญชีที่ผูกเอกสาร/บิลนั้นในเดือนภาษี (เดิมก็ทำแบบนี้ — กระทบ GL เป๊ะ)
- จัดกลุ่มรายการบัญชีตาม "ต้นทาง": `AccountDocument:<id>` หรือ `PosSale:<id>` (บิลขาย ใบคืน ใบรับมัดจำของ POS) · อื่น ๆ (JV มือ ฯลฯ) = แถวรายการบัญชี ติดป้าย "รายการบัญชี (ไม่มีเอกสาร)"
- ต้นทาง `PosSale:<id>` → หาเอกสารบัญชีที่ `refType=PosSale, refId=<id>` ที่ยังมีผล (ABB / TAX_INVOICE เต็มรูปที่ออกแทน / DEPOSIT_RECEIPT / CREDIT_NOTE / INVOICE วางบิล) · ABB ที่ถูกแทนด้วยใบเต็มรูป = นับที่ใบเต็มรูปแถวเดียว (ไม่นับซ้ำ §1.3) + หมายเหตุ "ออกแทนใบกำกับภาษีอย่างย่อเลขที่ …"
- ข้อมูลฝั่ง POS (เลขใบเสร็จ · เครื่อง · สาขา) อ่านตรงจาก `PosSale/PosShift/PosDevice/BusinessUnit` ในไฟล์เดียว `account/pos-bill-meta.ts` (ทางอ่าน POS→บัญชี · อ่านอย่างเดียว)

## 2. ฐานภาษีแยกกลุ่มอัตรา (ใช้ได้ทั้งเอกสารบัญชีและบิล POS)
ตัวคิดเดียว `rateGroupsOf(doc, lines, glVat)` (pure · ไฟล์ `account/sales-tax-shared.ts`):
1. บรรทัดของเอกสาร → `computeTotals` (สูตรเดียวกับตอนออกเอกสาร) → net/vat ต่อบรรทัด จัดกลุ่มตาม `vatRateBp` (>0 = อัตรานั้น · 0 = 0% · −1 = ยกเว้น)
2. กลุ่ม 0%/ยกเว้น: ฐาน = net ของบรรทัด (VAT 0)
3. กลุ่มมีภาษี: **VAT = ยอดจาก GL** (แหล่งความจริง) · **ฐาน = ยอดรวมหลังหักมัดจำของกลุ่ม − VAT** โดย ยอดรวมหลังหักมัดจำ = `grandTotal` ของเอกสาร − ยอดรวมของกลุ่ม 0%/ยกเว้น
   ⇒ ใบหักมัดจำ (RECEIPT/บิล POS ที่ใช้มัดจำ/ใบกำกับที่ออกจากใบแจ้งหนี้หักมัดจำ) ได้ฐานที่สอดคล้อง VAT เสมอ (แก้ข้อค้นพบ E6 "ใบหักมัดจำฐานไม่ตรง VAT")
   · หลายอัตราบวก: VAT ของ GL เกลี่ยตามสัดส่วน VAT ของบรรทัด (เศษไปกลุ่มใหญ่สุด)
4. เครื่องหมายตามทิศ VAT ของ GL (ใบลดหนี้/ใบคืน/รายการยกเลิก = ติดลบ)
5. เอกสารไม่มีบรรทัด/บิล POS ที่ไม่มีเอกสาร: ใช้ยอดรวมของบิล (`PosSale.grandTotalSatang` − VAT ของ GL) เป็นฐานกลุ่มอัตรามาตรฐาน
- T1.8 จะทำ VAT รายบรรทัดใน POS เอง — ตัวคิดนี้รับกลุ่มอัตราต่อบรรทัดอยู่แล้ว ไม่ต้องแก้ซ้ำ

## 3. ใบกำกับภาษีอย่างย่อ (ABB) — สรุปรายวัน
- ค่าตั้งใหม่ `account.report.salesTaxAbbMode` (ชั้น ACCOUNT_BOOK) = `DAILY_DEVICE` (ค่าเริ่ม: 1 แถว/วัน/เครื่อง) | `DAILY_BRANCH` (1 แถว/วัน/สาขา) | `PER_BILL` (ทุกใบ)
  · หน้ารายงานสลับดูชั่วคราวได้ด้วย `?abb=` (ไม่เปลี่ยนค่าตั้ง)
- แถวสรุป: วันที่ · "ใบกำกับภาษีอย่างย่อ เลขที่ <แรก> ถึง <สุดท้าย> (<n> ใบ)" · ชื่อ = เครื่อง (+เลขประจำเครื่อง POS ถ้ามี) / สาขา · ฐาน/VAT รวมแยกกลุ่มอัตรา · กดดูรายใบได้ (drill-down)
- เลขรันใบเสร็จของ POS นับต่อสาขาต่อเดือน ⇒ แถวต่อเครื่องอาจมีเลขข้าม (อีกเครื่องใช้) — แสดงจำนวนใบจริงคู่ช่วงเลข
- บิลไม่มีกะ/เครื่อง = กลุ่ม "ไม่ระบุเครื่อง" ของสาขานั้น
- บิลที่ยกเลิกในเดือนเดียวกัน: ไม่มียอด (GL กลับรายการแล้ว) แต่ยังอยู่ในช่วงเลข + หมายเหตุ "ยกเลิก n ใบ: เลขที่ …" ในแถวสรุป
- ใบที่ไม่ใช่ ABB (ใบเต็มรูปของ POS · ใบคืน/ใบลดหนี้ · มัดจำ · วางบิล) = แถวรายใบเสมอ

## 4. ใบที่ยกเลิก
- ยกเลิกในเดือนเดียวกับที่ออก: แถวรายใบยังอยู่ ฐาน/VAT 0 + หมายเหตุ "ยกเลิก" (เดิม: แถวหายไปเลย — เลขที่ขาดช่วง)
- ยกเลิกข้ามเดือน (GL กลับรายการในเดือนหลัง): เดือนเดิมแถวปกติ · เดือนที่กลับรายการ = แถวติดลบ + หมายเหตุ "ยกเลิกใบเลขที่ … ลงวันที่ …" (+ เหตุผล) — ไม่ย้ายยอดข้ามเดือน (ยอดต้องกระทบ GL ของเดือน · การปรับเดือนที่ยื่นแล้วเป็นงาน T1.7/T2.2)
- ใบเต็มรูปที่ออกแทนใบย่อ: หมายเหตุอ้างเลขใบย่อ (§1.5)

## 5. หัวรายงาน (จอ · พิมพ์ · CSV)
ชื่อกิจการ (`orgDisplayName`) · เลขประจำตัวผู้เสียภาษี 13 หลัก · สำนักงานใหญ่/สาขาที่ (รหัส 5 หลัก + ชื่อ) · เดือนภาษี (เดือน ปี พ.ศ.)
· ไม่มีเลขผู้เสียภาษีของร้าน = คำเตือนบนหัวรายงาน (ไม่บล็อก — คำเตือนท้องถิ่น ย้ายเข้าทะเบียนกลาง T0.4 ภายหลัง)

## 6. ตารางบนจอ/พิมพ์
คอลัมน์: ลำดับ · วันที่ · เลขที่ · ชื่อผู้ซื้อ · เลขผู้เสียภาษีผู้ซื้อ · สาขาผู้ซื้อ · มูลค่า (ฐาน) · ภาษี · หมายเหตุ
· จัดกลุ่มตามอัตรา: หัวกลุ่มอยู่เหนือแถวของกลุ่มเอง → แถวเรียงตามวันที่แล้วเลขที่ → รวมกลุ่ม → รวมทั้งสิ้นท้ายตาราง
· แถวที่มีหลายอัตรา (บิลมีสินค้าผสม) ขึ้นในแต่ละกลุ่มอัตราด้วยยอดส่วนของกลุ่มนั้น
· สาขาผู้ซื้อแสดงเฉพาะผู้ซื้อที่มีเลขผู้เสียภาษี ("สำนักงานใหญ่" เมื่อ 00000)

## 7. กระทบยอด (checks)
1. Σ ภาษีในรายงาน = ยอดภาษีขายของ ภ.พ.30 (ตัวเลขเดียวกันมาจากตัวคิดเดียว — ยังตรวจซ้ำเผื่ออนาคตแยก)
2. Σ ภาษีในรายงาน = ยอดเคลื่อนไหวสุทธิฝั่งเครดิตของบัญชี 2200 ในเดือน (คิวรีแยก ไม่ผ่านตัวจัดกลุ่ม)
3. Σ ฐาน + ภาษี ของแถว POS = Σ ยอดบิลของเดือน (ส่วนที่ไม่มีเอกสาร/หักมัดจำแสดงผลต่าง)
4. ทุกแถว: |ฐาน × อัตรา − ภาษี| ≤ 1 บาท (ฐานสอดคล้อง VAT) — ไม่ผ่าน = แถวติดธง
ผล checks แสดงบนจอใต้ตาราง + ใน CSV ท้ายไฟล์ · ไม่บล็อกอะไร
