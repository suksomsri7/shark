## 2. รายงาน `pnd(ctx, {type: 1|2|3|53|54, period})`
- แหล่ง 1: 50 ทวิ ฝั่งที่เราหัก (IN · ISSUED) ที่ออกในเดือน (วันที่ออก = วันจ่าย) และตัวจับแบบได้แบบนี้
- แหล่ง 2 (ใหม่): **การจ่ายที่หักภาษีแล้วแต่ยังไม่มีใบ** — payment ของเอกสาร IN · `whtAmountSatang > 0` · ไม่ถูกยกเลิก · `whtCertDocId` ว่าง · จ่ายในเดือน · ประเภทเงินได้จากบรรทัดของเอกสาร (บรรทัดแรกที่ระบุ) ไม่มี = ไม่ระบุ (แบบตามผู้รับ: บุคคล 3 / นิติ 53) · แถวติดป้าย "ยังไม่ออก 50 ทวิ" + คำเตือน `WHT_PAID_WITHOUT_CERT` [V] (ม.50 ทวิ ออกทันที)
- เรียง: วันที่จ่าย → เลข 50 ทวิ → id (นิ่ง) · ลำดับที่ = ลำดับในรายการ (ตัวเดียวกับที่พิมพ์บน 50 ทวิ)
- รายปี `pnd1kAnnual(ctx, year)`: รายการ ภ.ง.ด.1 ของทั้งปีรวมต่อผู้รับ (เลข 13 หลัก/ชื่อ) — ภ.ง.ด.1ก
- CSV: ชื่อคงเดิม "CSV ช่วยกรอกแบบ" (T2.10) · หัว = แบบ+งวด · คอลัมน์เดิม + "สถานะใบ" (ออกแล้ว / ยังไม่ออก 50 ทวิ) · ไฟล์ `pnd<form>-<period>.csv` · 1ก = `pnd1k-<year>.csv`

## 3. นำส่ง / แบบเพิ่มเติม / ยกเลิกหลังนำส่ง
- `markFiled` รับแบบ 1/2/3/53/54 (ตาราง AccountWhtFiling.form เป็น Int อยู่แล้ว) · ประทับเฉพาะ 50 ทวิ (แถวยังไม่มีใบไม่มีอะไรให้ประทับ แต่นับในยอดที่ยื่น)

  - ผลต่างหลังแบบเพิ่มเติมล่าสุดแยกให้เห็น (เหมือน ภ.พ.30)
- **ยกเลิกการจ่ายหลังนำส่ง**: ด่าน T1.7 เดิม (`FILED_PERIOD_PND_CHANGE` · ยืนยัน · ไม่บล็อก) + แถว "ยกเลิกหลังยื่น" ในรายการปรับของหน้า ภ.ง.ด. (เดิมเห็นผ่าน REST อย่างเดียว) → ปุ่มแบบเพิ่มเติม
