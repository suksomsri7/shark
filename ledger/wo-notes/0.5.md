## เหตุการณ์ทางเทคนิคที่ต้องรู้ (สำหรับ WO ถัดไปที่ต่อยอด component พวกนี้)

- **Server/Client boundary**: `DocTable.tsx` เป็น server component ที่ **เรียก `col.render(row)` เองฝั่ง server**
  แล้วส่ง ReactNode ที่ render แล้วเข้า `DocTableInteractive` (client, เฉพาะ checkbox/bulk bar) — ห้ามส่ง
  `render`/`onClick`/`search` เป็น function prop ข้าม server→client ตรง ๆ (Next โยน error) ดังนั้น
  `ContactPicker`/`ProductPicker`/`Modal`/`SlideOver` ที่ต้องมี function จริง (search/onClose) ต้องถูก "ประกอบ"
  จากภายในไฟล์ client เอง (ดู `GalleryClient.tsx` เป็นตัวอย่าง) — หน้า docs list จริงใน WO 1.1 ต้องทำแบบเดียวกัน
- `mode.ts` (server, ใช้ `next/headers`) กับ `EasyModeToggle.tsx` (client) แยก `ACC_MODE_COOKIE`/`AccMode` ไปไว้
  `mode-shared.ts` เพราะไฟล์ "use client" import โมดูลที่พึ่ง `next/headers` ไม่ได้
- `RowActions`/`DocTableInteractive`/`ContactPicker`/`ProductPicker` มี prop เสริม `defaultOpen`/`initialSelectedIds`/
  `initialResults` **เฉพาะให้หน้า gallery ถ่ายภาพสถานะที่เปิดอยู่แล้วได้โดยไม่ต้องใช้ puppeteer คลิก** — หน้าใช้งานจริงไม่ต้องส่ง prop พวกนี้
