## 4. บันทึกรับใบกำกับภาษีซื้อ (`receivePurchaseTaxInvoice(…, { vendorInvoiceDate, vendorInvoiceNo?, claimDate?, ack })`)
- ต้องมีวันที่ในใบกำกับ (ไม่ส่ง = วันที่รับ — ช่องทางเดิมที่ไม่ส่ง) · เลขที่ใบของผู้ขายเก็บที่ `reference`
- เดือนเคลม = เดือนของ `claimDate` (ไทย) · ห่างจากเดือนใบ `d` เดือน:
  - d = 0 ⇒ ปกติ ไม่มีข้อความ
  - 1 ≤ d ≤ ค่าในตาราง (6) ⇒ เก็บข้อความ "ถือเป็นภาษีซื้อในเดือนภาษี…" + แสดงคำเตือนแจ้ง `INPUT_VAT_LATE_CLAIM` (ack=false)
  - d > 6 ⇒ คำเตือน `INPUT_VAT_LATE_CLAIM_OUT_OF_WINDOW` (ack=true · บันทึกผู้ยืนยัน) แล้วทำต่อได้ + เก็บข้อความ
  - d < 0 (เดือนเคลมก่อนเดือนใบ) ⇒ `INPUT_VAT_CLAIM_BEFORE_INVOICE_MONTH` (ack=true · skill ไม่ได้บอก [S])
- JV: Dr 1150 / Cr 1155 **ลงวันที่ `claimDate`** (เดิม = วันที่สร้าง PTX) ⇒ ภ.พ.30 ของเดือนที่รับเห็นยอด · ล็อกวันที่ตรวจที่ `claimDate`
- ยอดที่ย้าย = ยอด 1155 คงเหลือของสายเอกสาร (ใบต้นทาง + ใบลด/เพิ่มหนี้ที่อ้าง + PTX) อ่านจาก GL ⇒ ใบลดหนี้ที่ลด 1155 ไปแล้วไม่ทำให้ติดลบ · ปรับ `vatAmount` ของ PTX ให้ตรงก่อนโพสต์
- รับซ้ำหลังยกเลิกการรับ ⇒ คีย์ idempotency ใหม่ (`RECEIVE<n>`)
- ข้อความแสดง: หน้าเอกสาร PTX (และใบต้นทาง) + แถวรายงานภาษีซื้อ — `Pp30Row.note` (**แตะ reports.ts pp30Side 2 จุด — เพิ่มฟิลด์ optional อย่างเดียว · แจ้งเลน 1**) + ตัวอ่านรายงานรายการรอ (§6)

## 5. ใบลด/เพิ่มหนี้ฝั่งซื้อ (CNR / DNR) ตามสถานะใบเดิม
- อ้างใบเดิม ⇒ แบ่ง VAT ของใบลด/เพิ่มหนี้ตามสัดส่วน VAT ต่อสถานะ "ปัจจุบัน" ของใบเดิม: CLAIM → 1150 · PENDING (ยังรอใบ) → 1155 · PENDING ที่ PTX รับแล้ว → 1150 · PENDING ที่ PTX เคลมไม่ได้ → ไม่ขอคืน · NO_CLAIM → 6950/6960 (หรือเข้าต้นทุนตามค่าตั้ง)
- ไม่อ้างใบเดิม ⇒ 1150 (เหมือนเดิม)
- ลงวันที่ใบลด/เพิ่มหนี้ (= เดือนที่ได้รับ §16)
