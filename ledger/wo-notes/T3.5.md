# T3.5 — ฝั่งถูกหัก: รายงานค้างรับ 50 ทวิ (ปิด F13) · design note

## 0. กฎ
- ภาษีที่ถูกหักเป็นเครดิตของผู้ต้องเสียภาษี (ม.60 · ม.3 เตรส) · ระบบมี "ทะเบียน 50 ทวิ ที่ได้รับ + รายงานค้างรับ" [V] — WHT §15 · §9 ("ติดตามการรับ 50 ทวิ จากลูกค้านิติบุคคล") · checklist F13 · test-rules T-WHT-10
- skill ไม่บอกระยะเวลาที่ต้องตาม ⇒ ค่าเริ่มต้นของระบบ: ค้างทุกใบที่ยังไม่ทำเครื่องหมายรับ · แสดงจำนวนวันนับจากวันรับเงิน (ไม่มีเส้นตาย)

## 1. ข้อมูล (migration เดียวกับ T3.3/T3.4 · เพิ่มล้วน)
`AccountDocument` (ใช้กับ WHT_CERT direction OUT = WTI): `whtCertReceivedAt DateTime?` · `whtCertReceivedById String?` · `whtCertReceivedNote String?` (เลขที่/เล่มที่บนใบที่ได้รับ ฯลฯ)
- "รับแล้ว" = ธงนี้เท่านั้น — **ไม่เดาจากไฟล์แนบ** (เดิม `hasCertCopy` = มีไฟล์แนบที่เอกสารต้นทาง) · ไฟล์แนบยังแสดงเป็นข้อมูลประกอบ
- ทำเครื่องหมาย/ยกเลิกเครื่องหมาย = AuditLog `account.wht.credit.received` / `.unreceived` (ใคร เมื่อไร หมายเหตุ)

## 2. รายงานค้างรับ `whtCreditsOwed(ctx, {asOf?, contactId?})`
- WTI (OUT · ISSUED) ที่ยังไม่มี `whtCertReceivedAt` · คอลัมน์: วันที่รับเงิน · ลูกค้า (ผู้หัก) · เลขภาษี · เอกสารต้นทาง · ฐาน · อัตรา · ภาษี · ค้างมา N วัน · รวมต่อลูกค้า · ยอดรวม
- หน้าจอ: แท็บใหม่ในหน้า WHT ฝั่งถูกหัก "ค้างรับ 50 ทวิ" (`/account/wht?tab=credit&owed=1`) + คอลัมน์ "50 ทวิ" (รับแล้ว ว.ด.ป / ยังไม่ได้รับ) + ปุ่ม "ทำเครื่องหมายรับแล้ว" ต่อแถว (กล่องหมายเหตุ) + เลือกหลายแถว
- CSV เครดิตภาษี: คอลัมน์ "มีสำเนา 50 ทวิ" → "ได้รับ 50 ทวิ แล้ว" (ธงจริง) + "วันที่ได้รับ"

## 3. ช่องทาง
- REST: `GET /wht/credits/owed` (+CSV) · `POST /wht/credits/{certId}/received` {note?} · `DELETE /wht/credits/{certId}/received` {reason}
- AI: `account_wht_credits_owed` (อ่าน) · `account_wht_mark_received` (เขียน = ข้อเสนอ)
- สิทธิ์: อ่าน `account.tax.view` · เขียน `account.wht.manage`

## 4. ข้อสอบ `scripts/qc-acc-v2-wht-credit.mts`
ร้านทดสอบแยก · รับชำระที่ลูกค้าหัก 3% → ค้างรับ 1 แถว · แนบไฟล์ = ยังค้าง (ไม่เดา) · ทำเครื่องหมายรับ → หาย · ซ้ำ = idempotent · ยกเลิกเครื่องหมาย → กลับมา · ใบที่ถูกยกเลิก (ยกเลิกรับชำระ) ไม่ขึ้น · ฝั่ง IN ทำเครื่องหมายไม่ได้ (422)

## 5. สิ่งที่สร้างจริง (13–14 พ.ย. 2569 · เลน 2)
- schema `whtCertReceivedAt/ById/Note` (+ ดัชนี) · `wht-cert.ts` `markWhtCreditReceived` `whtCreditsOwed` · `listWhtCredits` คืน `certId` `certReceivedAt` (ฟิลด์ `hasCertCopy` คงความหมาย "มีไฟล์แนบ")
- หน้า WHT ฝั่งถูกหัก: ตัวกรอง "ค้างรับ 50 ทวิ (n) · ยอด" · รวมต่อลูกค้า · คอลัมน์ "50 ทวิ จากลูกค้า" + ปุ่มได้รับแล้ว/ยกเลิก · หน้า ภ.ง.ด. ส่วนเครดิต: สถานะรับจริง + ลิงก์ค้างรับ
- REST `GET /wht/credits/owed` (+CSV) · `POST|DELETE /wht/credits/{id}/received` · เครื่องมือ `account_wht_credits_owed` `account_wht_mark_received` `account_wht_unmark_received`
- ข้อสอบ `qc-acc-v2-wht-credit` 13/13 · REST ใน `qc-account-api-wht-t3`
