## 2. ที่มาของแถว — GL ตาม mapping (เหมือน T1.1)
- **ส่วนที่หักได้ (ตัวรายงาน)**: บรรทัดของบัญชี VAT_INPUT (mapping · ไม่มีแถว = 1150) ในเดือน → รวมต่อเอกสารต้นทาง (refType AccountDocument)
  - ภาษีของแถว = Σ(Dr−Cr) ของบัญชีนั้น (กระทบ GL เป๊ะ) · ใบที่เคลมบางส่วน (บรรทัดเคลม/ไม่เคลมปนกัน) ได้เฉพาะส่วนที่เคลม
  - ฐาน = ฐานของเอกสาร × (ภาษีที่เคลม ÷ ภาษีทั้งใบ) (อัตราเดียว = ฐานของบรรทัดที่เคลมพอดี) · ทิศตามภาษี (ใบลดหนี้ติดลบ)
  - วันที่ได้รับ = วันที่ลงบัญชีของรายการ (ใบกำกับภาษีซื้อ T1.5: วันที่ลงภาษีซื้อ ค่าเริ่ม = วันที่รับ · ใบซื้อ/ค่าใช้จ่ายที่ได้ใบกำกับพร้อมกัน: วันที่เอกสาร)
  - วันที่ใบกำกับ = `vendorInvoiceDate` (T1.5) ไม่มี = วันที่เอกสาร · เลขที่ใบกำกับ = เลขของผู้ขาย (`reference`) ไม่มี = เลขเอกสารของเรา (+ หมายเหตุ)
  - ผู้ขาย: ชื่อ เลขผู้เสียภาษี สาขา (ภาพคู่ค้าบนเอกสาร → คู่ค้า) · ผู้ขายมีเลขภาษีแต่ไม่มีสาขา = "00000" สำนักงานใหญ่ (เหมือนฝั่งขาย)
  - เรียง วันที่ได้รับ → เลขที่ใบกำกับ → เลขเอกสาร · ลำดับที่ 1…n ต่อเดือน
  - หมายเหตุ: ข้อความเคลมข้ามเดือน (T1.5) · ใบลดหนี้/เพิ่มหนี้อ้างใบเดิม · ยกเลิกในเดือน (ยอด 0) · ยกเลิกใบที่ลงเดือนก่อน (ติดลบ) — แบบเดียวกับ T1.1
- **รายการปรับปรุงมือ (T1.9)**: รายการบัญชีที่ไม่มีเอกสารบนบัญชีเดียวกัน (JV มือ = source MANUAL · อื่น ๆ) — ส่วนแยกท้ายรายงาน · ฐาน 0 · นับในยอดรวมภาษีซื้อของเดือน (ภ.พ.30 อ่าน GL)
- **ส่วนที่หักไม่ได้ (ไม่อยู่ในยอดรายงาน)**: บรรทัดของบัญชีภาษีซื้อไม่ขอคืน (VAT_INPUT_NONCLAIM 6950 · VAT_INPUT_NONCLAIM_DISALLOWED 6960) ในเดือน รวมต่อเอกสาร · จัดกลุ่มตามเหตุ (T1.4 `INPUT_VAT_NONCLAIM_REASONS` — เหตุของบรรทัดที่เคลมไม่ได้ / ของใบกำกับภาษีซื้อที่บันทึกว่าเคลมไม่ได้ · ไม่มีเหตุ = กลุ่ม "ไม่ระบุเหตุ")
  - ค่าตั้ง `nonClaimPosting = INTO_COST`: ภาษีซื้อเคลมไม่ได้รวมเข้าบัญชีค่าใช้จ่าย ไม่มีบัญชีแยกให้อ่าน ⇒ ส่วนนี้แสดงข้อความบอกเหตุแทน (ข้อจำกัด จดในข้อ 7)
- **รอใบกำกับ (ไม่อยู่ในยอด)**: `pendingInputVat(ctx, { asOf: สิ้นเดือน })` (T1.5) — ใบต้นทาง ผู้ขาย ยอดพัก อายุ เดือนสุดท้ายที่ยังเคลมได้ + ลิงก์หน้ารายการรอใบกำกับ
- **ใบลด/เพิ่มหนี้ฝั่งซื้อ**: ไม่ต้องจัดการแยก — T1.5 ลง VAT ตามสถานะของใบเดิมแล้ว ⇒ ขึ้นส่วนที่ตรงกับบัญชีที่ลง (เคลม → ตัวรายงาน · ไม่เคลม → ส่วนหักไม่ได้ · รอ → อยู่ในยอดพัก)

## 3. ข้อตรวจกระทบยอด (ไม่บล็อก — รูปเดียวกับ T1.1)
① ยอดภาษีซื้อในรายงาน (รายใบ + ปรับปรุงมือ) = ยอดเคลื่อนไหวบัญชีภาษีซื้อตาม mapping ของเดือน ② = ภาษีซื้อของ ภ.พ.30 ③ ฐาน × อัตรา ≈ ภาษี ทุกแถว (ค่าคลาดเดียวกับ T1.1)

## 4. ที่แสดง
- จอ ภ.พ.30 (`reports/pp30`): แทนตาราง "รายงานภาษีซื้อ" เดิม (เลขที่/คู่ค้า/ฐาน/ภาษี) ด้วยหัวรายงาน + ตาราง (ลำดับ · วันที่ได้รับ · วันที่ใบกำกับ · เลขที่ใบกำกับ · ผู้ขาย · เลขผู้เสียภาษี · สาขา · มูลค่า · ภาษี · หมายเหตุ) + ส่วนปรับปรุงมือ + ข้อตรวจ + ส่วนหักไม่ได้ + รอใบกำกับ — พิมพ์จากหน้าเดียวกัน (ไม่มี tfoot)
- CSV ภ.พ.30 (`tax/export?kind=pp30` + REST `reports.vat-pp30` CSV): บล็อกภาษีซื้อเดิม → บล็อกเดียวกับจอ (หัว · แถว · ปรับปรุงมือ · รวม · ข้อตรวจ · หักไม่ได้ · รอใบกำกับ)
- REST `GET /reports/purchase-tax?period=` + เครื่องมือ AI `account_purchase_tax_report` (ผ่าน op เดียวกัน = โครงสร้างเดียวกัน) · `reports.vat-pp30` เดิมไม่เปลี่ยนรูป
- ไม่แตะรูป `Pp30.input` (pp30Side) ที่ผู้เรียกเดิมใช้

## 5. ค่าตั้ง
- ไม่เพิ่มค่าตั้งใหม่: เรื่องที่ skill เงียบเลือกค่าที่ไม่แปลกใจที่สุด (ข้อ 7) — ส่วนหักไม่ได้/รอใบกำกับเป็นข้อมูลประกอบที่แยกจากยอดอยู่แล้ว ไม่กระทบตัวเลขรายงาน จึงไม่ต้องให้ปิด
  (ถ้าเจ้าของต้องการใบพิมพ์ที่มีแต่ตัวรายงาน → เพิ่มสวิตช์ได้ภายหลัง · จดเป็นคำถามเปิด)

## 6. ข้อสอบ `scripts/qc-acc-v2-purchasetax.mts` (ร้านทดสอบของตัวเอง · เฉลยคิดมือ)
เดือนทดสอบ M (+ M−1): ① ค่าใช้จ่ายเคลมในเดือน (ผู้ขายมีเลขภาษี+สาขา) ② ใบซื้อเดือน M−1 รอใบกำกับ → รับในเดือน M (ข้อความเคลมข้ามเดือน · วันที่ใบกำกับ M−1 · ลำดับตามวันที่รับ) ③ ใบลดหนี้รับอ้างใบ ① (ติดลบ + หมายเหตุอ้างใบเดิม) ④ ค่าใช้จ่ายค่ารับรองเคลมไม่ได้ (ส่วนหักไม่ได้ กลุ่มค่ารับรอง ไม่อยู่ในยอด) ⑤ ใบซื้อรอใบกำกับ (ส่วนรอ) ⑥ ใบกำกับภาษีซื้อที่รับแล้วยกเลิกการรับในเดือนเดียวกัน (ยอด 0 + หมายเหตุยกเลิก) ⑦ JV มือ Dr 1150 (ส่วนปรับปรุงมือ ฐาน 0 · นับในยอด) · ข้อตรวจ 3 ข้อผ่าน · ลำดับที่ 1…n · CSV มีแถวเดียวกัน · REST = ตัวอ่าน

## 7. skill เงียบ → เลือกเอง (ป้าย S)
- วันที่ได้รับของใบที่ได้ใบกำกับพร้อมเอกสาร = วันที่เอกสาร (ไม่มีช่องวันที่รับแยก) · ของใบกำกับภาษีซื้อที่รับภายหลัง = วันที่ลงภาษีซื้อ (T1.5 ค่าเริ่ม = วันที่รับ)
- ฐานของใบที่เคลมบางส่วน = ตามสัดส่วนภาษี
- ส่วนหักไม่ได้/รอใบกำกับแสดงต่อท้าย (ไม่รวมยอด) ทั้งจอ ใบพิมพ์ CSV REST
- ใบที่มีหลายเหตุเคลมไม่ได้: แบ่งภาษีของใบตามบรรทัด (น้ำหนักฐาน × อัตรา) ลงกลุ่มเหตุของแต่ละบรรทัด
- ค่าตั้ง INTO_COST: ไม่มีส่วนหักไม่ได้ให้แสดง (บอกเหตุ)
