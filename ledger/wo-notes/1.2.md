## 1. 🐞 บั๊กที่เจอระหว่างทาง (แก้แล้ว — สำคัญที่สุดในใบนี้)

**ใบจ่ายเงินมัดจำ (DP) ลงบัญชีผิดตั้งแต่ก่อนมี WO นี้** (ไม่มีใครเจอเพราะยังไม่มีหน้าให้สร้าง):

- `issueExpenseDoc` เรียก `postDocument` กับทุกชนิด · posting rule ของ DP คือ `Dr 1130 มัดจำจ่าย + Dr 1150 / Cr เงิน`
  ⇒ ตอน "ออกเอกสาร" (เงินยังไม่ออก) ระบบ **ตัดเงินในบัญชีทันที**
- แล้วตอนบันทึกจ่ายจริง `recordVendorPayment` → `postPayment` ลง `Dr 2100 เจ้าหนี้ / Cr เงิน` อีกรอบ
  ⇒ เงินถูก Cr **2 รอบ** และ `Dr 2100` ลอย ทั้งที่ไม่เคยมี `Cr 2100` (เจ้าหนี้ติดลบ)

แก้แบบเดียวกับฝั่งขาย (`service.ts` ใบรับมัดจำ DEPOSIT_RECEIPT ไม่โพสต์ตอน issue):
- `issueExpenseDoc`: `if (doc.docType !== "DEPOSIT_PAYMENT") await postDocument(...)`
- `recordVendorPayment`: DP → จ่ายครบเมื่อไร ค่อย `postDocument` (อ่านช่องทางเงินจาก payment แรก) · ไม่เรียก `postPayment`
- สถานะยังเป็น `AWAITING_PAYMENT → (จ่ายครบ) AWAITING_DEDUCT` ตาม §3 เหมือนเดิม

ข้อสอบ R2 ในชุดใหม่ล็อกพฤติกรรมนี้ไว้ (ออกแล้วต้อง **ไม่มี** JV · จ่ายครบแล้วต้องมี JV เดียวที่ยอดตรงเป๊ะ)

## 3. หักเงินมัดจำจ่าย (§5.2 D) — service + GL

- `expense.ts`
  - `listDeductiblePaidDeposits(tenantId, systemId, contactId?)` — กระจกของ `service.listDeductibleDeposits`
    (DP สถานะ `AWAITING_DEDUCT` · คงเหลือ = `grandTotal − Σ relation DEPOSIT_APPLY ที่ยังไม่ถูกยกเลิก`)
  - `createExpenseDoc({ depositPaymentId })` — เฉพาะ `PURCHASE`/`EXPENSE` + ผู้ขายรายเดียวกัน → ตั้ง `depositDeducted` + สร้าง relation `DEPOSIT_APPLY`
  - `issueExpenseDoc` — ล็อกตอนออก: ใบมัดจำต้องยัง `AWAITING_DEDUCT` · ยอดไม่เกินคงเหลือ · หักครบ → ใบมัดจำเป็น `DEDUCTED`
  - `updateExpenseDoc` — ใส่ `depositDeducted` ในสูตรคำนวณใหม่ (+ clamp ถ้าแก้บรรทัดจนยอดเล็กกว่ามัดจำ) ไม่งั้นแก้ร่างแล้วยอดเด้งกลับ
- `gl.ts` (case `PURCHASE`/`EXPENSE`) — กระจกของฝั่งขาย (INVOICE `Dr 2110`):
  `Dr ต้นทุน subTotal` · `Dr 1150 (vatAmount − VAT ของมัดจำ)` · `Cr 1130 ฐานมัดจำ` · `Cr 2100 grandTotal (สุทธิหลังหัก)`
  (VAT ของมัดจำเคลมไปแล้วตอนออกใบมัดจำ — เคลมซ้ำ = ภาษีซื้อเกิน)
- UI: `ExpenseEditor` มี select "เลือกเงินมัดจำ" (กรองตามผู้ขายที่เลือก) + บรรทัด "หักเงินมัดจำ −฿…" + ยอดสุทธิ
  · หน้าเอกสารโชว์บรรทัด "หักเงินมัดจำ" ด้วย
  · **ยังไม่ทำ (ยกให้ WO 1.4)**: modal เลือกหลายใบ/กรอกยอดหักบางส่วน (ตอนนี้หัก "เต็มยอดคงเหลือของใบที่เลือก" 1 ใบ)

## 8. ความเสี่ยง / หนี้ที่เหลือ

1. **ยกเลิกการจ่ายใบมัดจำ (DP)**: `voidVendorPayment` กลับรายการเฉพาะ JV ของ payment — แต่ JV ของ DP ผูกกับ *เอกสาร*
   ⇒ void การจ่าย DP แล้ว JV `Dr 1130 / Cr เงิน` ยังค้าง · **ฝั่งขาย (DEPOSIT_RECEIPT) มีรูเดียวกันอยู่ก่อนแล้ว**
   จึงไม่แก้ข้างเดียวในใบนี้ (แก้ต้องคุม idempotencyKey ของ `AccountDocument#…#ISSUE` ให้โพสต์ใหม่ได้) → เสนอเป็น WO แยก/1.4
2. หน้ารายการ PTX ยังโชว์ฟอร์ม "สร้างใบกำกับภาษีซื้อ" (ของเดิมจาก `/asset-buy?docType=PTX`) ทั้งที่ PTX ควรเกิดอัตโนมัติจากบันทึกซื้อโหมด "ยังไม่รับใบกำกับ" — ให้ WO 1.1/1.5 ซ่อนปุ่มสร้างของชนิดนี้
3. หักมัดจำได้ครั้งละ 1 ใบ เต็มยอดคงเหลือ (ยังไม่มีหักบางส่วน/หลายใบ) → WO 1.4
4. DP/CNR/DNR ยังไม่มีแท็บสถานะจริงในหน้ารายการ V2 (รอ WO 1.1 ข้อ 5.1) — ตอนนี้ใช้แท็บชุดเดิมจาก `tabsFor()`
