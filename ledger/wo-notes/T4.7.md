## ออกแบบ
1. **บิลที่ยังไม่ลงบัญชี** (`pos-link.ts posUnpostedBills`): บิลขาย (docType SALE · PAID/REFUNDED) ของจุดขายที่ผูกและเปิดลงบัญชีกับสมุดนี้ ที่ไม่มี JV `PosSale#<id>#PAID` ในสมุดนี้และไม่มีเครื่องหมาย zero entry · อายุวัน · ธง "ก่อนเชื่อมสมุด"
2. **กระทบยอดรายวัน** (`posDailyRecon`): ต่อวันไทยของเวลาชำระ — POS = Σ(ยอดบิล + ทิป) · บัญชี = Σ เดบิตของ JV ขาย (= เงินที่รับตามช่องทาง) · บิลค้าง · ผลต่าง (POS − บัญชี) · ผลต่างที่ไม่ใช่บิลค้าง = มัดจำหัก VAT/ทิปพนักงานรับตรง/ต้องตรวจ
3. **เงินขาด/เกิน → GL** (`gl.postCashVariance` + `postPosShiftVariances`): กะ CLOSED ที่ `overShortSatang ≠ 0` + การนับย้อนหลังของกะที่ระบบบังคับปิด (`PosShiftRecount.varianceSatang`) · เกิน = Dr เงินสด / Cr 4920 "เงินเกินจากการนับเงินสด" (CASH_OVER) · ขาด = Dr 6920 "เงินขาดจากการนับเงินสด" (CASH_SHORT) / Cr เงินสด · 1 กะ = 1 ใบสำคัญ (idempotency `PosShift#<id>#VARIANCE`) · คำอธิบาย = จุดขาย Z เครื่อง ผู้นับ หมายเหตุ · **ลงเมื่อกดเท่านั้น** (จอ/REST/เลขา) — ไม่ลงอัตโนมัติ เพราะ (ก) ต้องแก้คิว POS (นอกเลน) (ข) ลงเองในฐานทดสอบร่วมจะเปลี่ยนเฉลย · งวดปิด = ล้มทีละกะ บอกเหตุผล
4. **ทิป 3 ทาง** ค่าตั้งสมุด `account.pos.tipTreatment`: `LIABILITY` (ค่าเริ่ม = ทางเดิม P2.9 ทุกไบต์ · Cr บัญชีพักทิปของ POS) · `REVENUE_VAT` (Cr 4040 รายได้ทิป + ภาษีขาย ถอดจากทิปตามอัตราของสมุด — สมุดไม่จด VAT = รายได้ทั้งก้อน) · `STAFF_DIRECT` (ทิปส่วนที่เป็นเงินสดไม่ผ่านบัญชีร้าน: ลดขา Dr เงินสด · ส่วนที่เข้าบัญชีร้านยังเป็นบัญชีพักทิป) — มีผลกับบิลที่ลงบัญชีหลังเปลี่ยน
   - **ค่าเริ่มคง LIABILITY** (skill เสนอ REVENUE_VAT): เปลี่ยนค่าเริ่ม = เปลี่ยน GL ของบิล POS ทุกร้าน + เฉลยชุด POS (นอกเลน) ⇒ ให้เจ้าของตัดสิน · คำเตือน `POS_TIP_LIABILITY_REVIEW` แสดงทุกจอที่เกี่ยว
   - ข้อจำกัด: ภาษีขายของทิป (REVENUE_VAT) อยู่ใน GL (ภ.พ.30 อ่าน GL) แต่ไม่อยู่ในชั้นเอกสาร/รายงานภาษีขายรายใบ
5. **คำเตือนเครื่องบันทึกการเก็บเงิน** (J2): สมุดจด VAT + เปิดใบย่อ POS + มีจุดขายผูก ⇒ `POS_CASH_REGISTER_APPROVAL` พร้อมชื่อเครื่องที่ยังไม่มี "เลขรหัสประจำเครื่อง" (`PosDevice.posRegNo`)
- ผัง (เพิ่ม · skipDuplicates): 4040 รายได้ทิป · 4920 เงินเกิน · 6920 เงินขาด · mapping TIP_REVENUE CASH_OVER CASH_SHORT
- จอ `/account/reports/pos-link` (กระทบยอด · บิลค้าง · เงินขาด/เกิน + ปุ่มลงบัญชี · ตัวเลือกทิป) + ส่วนทิปบน "ตั้งค่า › อัตราภาษีฯ" · REST `GET /pos/unposted-bills` `GET /pos/daily-reconciliation` `GET /pos/shift-variances` `POST /pos/shift-variances/post` · เลขา `account_pos_unposted` `account_pos_daily_recon` `account_pos_shift_variances` `account_post_shift_variances`
