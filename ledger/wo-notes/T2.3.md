# T2.3 — เนื้อหาใบลดหนี้ / ใบเพิ่มหนี้ (ปิด B10 B11) · design note

กฎ (skill `common-vat-invoice.md`):
- §16 [V] (ม.82/9, 82/10, 86/9, 86/10 · ป.80/2542): เหตุเพิ่มหนี้ "ส่งของเกิน/ให้บริการเกิน/คำนวณราคาต่ำกว่าจริง" · รายการ ม.86/10 ของใบลดหนี้: คำว่า "ใบลดหนี้" · ผู้ออก · ผู้ซื้อ · วันที่ · **เลขใบกำกับเดิม + มูลค่าเดิม มูลค่าที่ถูกต้อง ผลต่าง และภาษีที่ใช้คืน** · สาเหตุย่อ · 1 ฉบับอ้างหลายใบได้
- §7 [V] เหตุลดหนี้ตามประกาศ VAT ฉ.82 ข้อ 2 ที่ skill ยกมา: (2) คืนเงินจ่ายล่วงหน้า/เงินประกัน/มัดจำ/เงินจองตามข้อตกลง · (5) บริการบกพร่อง/ผิดข้อกำหนด · (6) "ไม่มีการให้บริการตามสัญญา"
- checklist B10 (ใบลดหนี้) · B11 (ใบเพิ่มหนี้ "เหตุตาม ม.82/9")
- มาตราบนใบ: §16 วางคู่ ม.86/9 กับ 86/10 และระบุ "รายการ ม.86/10: คำว่า 'ใบลดหนี้'" ⇒ ใบลดหนี้ = ม.86/10 · ใบเพิ่มหนี้ = ม.86/9 (คู่กัน) [V ตามหัว §16] — ใส่ไว้ในตารางค่ากฎหมาย ไม่ฝังในหน้าพิมพ์

## 1. ตารางค่ากฎหมาย (th-tax-2569.ts · แถวระบบ [V] · ร้านไม่ทับ)
- `ADJUST_NOTE_SECTIONS` { CREDIT_NOTE: "มาตรา 86/10", DEBIT_NOTE: "มาตรา 86/9" } + ที่มา/ป้าย/วันที่ตรวจ
- `ADJUST_NOTE_REASONS` (รหัส · ป้าย · กลุ่ม CREDIT|DEBIT|ANY · ที่มา · ป้าย):
  - ลดหนี้: `CN_DEPOSIT_REFUND` (ฉ.82 ข้อ 2(2)) · `CN_SERVICE_DEFECT` (ข้อ 2(5)) · `CN_SERVICE_NOT_PROVIDED` (ข้อ 2(6))
  - เพิ่มหนี้: `DN_GOODS_OVER` ส่งของเกิน · `DN_SERVICE_OVER` ให้บริการเกิน · `DN_PRICE_UNDER` คำนวณราคาต่ำกว่าจริง (ม.82/9 · §16)
  - `OTHER` อื่น ๆ (ทั้งสองชนิด · บังคับข้อความ)
- skill เงียบ: ข้อ 2 ที่เหลือของ ฉ.82 (1)(3)(4) ไม่ได้ยกมาใน skill ⇒ **ไม่ใส่เอง** — ร้านเลือก "อื่น ๆ" + พิมพ์สาเหตุ · เปิดคำถามให้เติม skill
- เหตุเดิม (DAMAGED/PRICE_ERROR/EXTRA_DISCOUNT/SERVICE_CANCELLED) ของเอกสารเก่า: อ่านได้ต่อ (ป้ายเดิม · จัดเป็น "อื่น ๆ (รายการเดิม)") — ไม่เสนอในฟอร์มใหม่

## 2. ข้อมูล (schema เพิ่มอย่างเดียว · migration `20261231000100_acc_t23_adjust_reason_code`)
- `AccountDocument.adjustReasonCode String?` — รหัสจากตารางข้างบน · `adjustReason` = ข้อความ (สาเหตุย่อที่พิมพ์บนใบ) เหมือนเดิม
- ฝั่งซื้อ CNR/DNR: เลขที่เอกสารของผู้ขาย = `reference` · วันที่เอกสารของผู้ขาย = `vendorInvoiceDate` (คอลัมน์ T1.5) · รหัสเหตุ = `adjustReasonCode` — ทางเดียวกับใบกำกับภาษีซื้อ (T1.5)

## 3. คำเตือน (ทะเบียนกลาง · ต่อท้ายเท่านั้น)
- `ADJUST_NOTE_ORIGINAL_MISSING` [V] ack — ใบลด/เพิ่มหนี้ไม่อ้างใบกำกับเดิม (ม.86/10 ต้องมีเลขใบกำกับเดิม · B10) · กดยืนยันแล้วออกได้ (ไม่บล็อก)
- `ADJUST_NOTE_REASON_GROUP_MISMATCH` [V] ack — รหัสเหตุผลเป็นของอีกชนิด (เช่น ใบเพิ่มหนี้ใช้เหตุลดหนี้) — ผ่านทาง REST/AI ที่ส่งรหัสเองได้ · ฟอร์มกรองให้แล้ว
- `ADJUST_NOTE_REASON_MISSING` เดิม: ตรวจทั้งรหัสและข้อความ (มีรหัสไม่ใช่ OTHER = มีเหตุ · OTHER ต้องมีข้อความ)
- ฝั่งซื้อ (CNR/DNR) ไม่มีเลขเอกสารของผู้ขาย ⇒ `ADJUST_NOTE_ORIGINAL_MISSING` ข้อความฝั่งซื้อ (ไม่บล็อก)

## 4. ใบพิมพ์ CN/DN
- กล่องอ้างอิง: "อ้างอิงเอกสารเดิม (ตาม<มาตราจากตาราง>)" · "เลขที่<ชื่อชนิดจริงของใบเดิม>เดิม" (ใบกำกับภาษี/ใบแจ้งหนี้/ใบเสร็จ… จาก DOC_LABEL) + วันที่ · เหตุผล: ป้ายรหัส + ข้อความ
- กล่องมูลค่า (สตางค์ · ก่อน VAT):
  - มูลค่าตามเอกสารเดิม = ฐานของใบเดิม (หลังส่วนลด ก่อน VAT) ปรับด้วยใบลด/เพิ่มหนี้ที่ออกก่อนใบนี้ (มีผล · อ้างใบเดิมเดียวกัน) — ถ้ามี พิมพ์ "(รวมการปรับปรุงก่อนหน้า n ฉบับ)"
  - ผลต่าง = ฐานของใบนี้ · มูลค่าที่ถูกต้อง = เดิม − ผลต่าง (ลดหนี้) / เดิม + ผลต่าง (เพิ่มหนี้)
  - ภาษีมูลค่าเพิ่มของผลต่าง = VAT ของใบนี้ (ลดหนี้: "ภาษีที่ใช้คืน" ตามถ้อยคำ §16)
  - ไม่อ้างอิงใบเดิม ⇒ กล่องแสดง "ไม่ได้อ้างอิงเอกสารเดิม" + ผลต่าง/VAT เท่านั้น
- ไม่พิมพ์ "ครบกำหนด" และ "ช่องทางการชำระเงิน" บนใบลด/เพิ่มหนี้ (และฝั่งซื้อ)
- คอลัมน์ "ก่อนภาษี" ในหน้ารายละเอียดใบลดหนี้ = มูลค่าก่อน VAT ของบรรทัด (net จากตัวคิด) ไม่ใช่ยอดรวม VAT

## 5. ฟอร์ม
- ขั้นเหตุผล: รายการตามชนิดเอกสาร (ลดหนี้ / เพิ่มหนี้) + อื่น ๆ · เลือก → เก็บรหัส + ข้อความ (ข้อความเสริมไม่บังคับ ยกเว้น OTHER)
- REST/AI: `adjustReasonCode` (enum จากตาราง) + `adjustReason` ข้อความ · ไม่ส่งรหัส = ทางเดิม (ข้อความล้วน)

## 6. ข้อสอบ `scripts/qc-acc-v2-adjust-content.mts`
- ตาราง: ใบลดหนี้ได้เฉพาะเหตุลดหนี้+อื่น ๆ · ใบเพิ่มหนี้เฉพาะเหตุเพิ่มหนี้+อื่น ๆ · มาตรา CN 86/10 · DN 86/9
- เฉลยมือ: TX ฐาน 10,000.00 VAT 700 → CN 2,000 รวม VAT (ฐาน 1,869.16 VAT 130.84) → มูลค่าเดิม 10,000.00 · ที่ถูก 8,130.84 · ผลต่าง 1,869.16 · VAT 130.84 · CN ใบที่ 2 = เดิม 8,130.84 "(รวมการปรับปรุงก่อนหน้า 1 ฉบับ)"
- HTML หน้าพิมพ์: CN มี "มาตรา 86/10" ไม่มี "86/9" · DN กลับกัน · ป้าย "เลขที่ใบแจ้งหนี้เดิม" เมื่ออ้างใบแจ้งหนี้ · ไม่มี "ครบกำหนด" / ช่องทางชำระ
- คำเตือนไม่อ้างอิง: ไม่ยืนยัน = LEGAL_ACK_REQUIRED · ยืนยัน = ออกได้ + AuditLog
- CNR: รหัสเหตุ + เลข/วันที่เอกสารผู้ขายเก็บและอ่านกลับได้
