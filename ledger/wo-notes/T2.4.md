## ทำ (ยกแบบ POS: `applyExternalDepositRefund` = ใบลดหนี้อ้างใบรับมัดจำ + JV Dr 2110 / Dr 2200 / Cr เงิน)
- **คืน** (`refundDeposit`) ใบรับมัดจำฝั่งขายที่รับครบและมีใบกำกับของมัดจำที่ยังมีผล ⇒ ใบลดหนี้ ISSUED อ้าง **ใบกำกับของมัดจำ** (sourceDocId = ใบกำกับ · reference = เลขใบกำกับ) เหตุผล `CN_DEPOSIT_REFUND` · `refType DepositRefund`
  - ยอด = ส่วนที่ยังไม่ถูกหัก (คืนบางส่วนได้ — มัดจำที่ถูกหักไปบางส่วนแล้ว) · ทั้งใบ = ยกบรรทัดใบกำกับ · บางส่วน = 1 บรรทัด VAT ตามสัดส่วน
  - JV ของใบลดหนี้ (`gl.postDepositSettlement` REFUND): Dr 2110 ฐาน · Dr 2200 VAT / Cr เงินตามรายการรับมัดจำ (สัดส่วน · รับเป็นเช็ค = คืนจากธนาคาร) · **ลงวันที่ที่เลือก** (ปริยายวันนี้) ⇒ ด่านงวดปิด/เดือนที่ยื่นแล้ว (T1.7) ใน commitEntry ทำงานเอง (REST `acknowledge` · จอยืนยันผ่าน withScreenLegal)
  - ใบรับมัดจำ + ใบกำกับเดิม **คงอยู่** (ไม่ยกเลิก — เดิมยกเลิกใบกำกับ) · ผูก DEPOSIT_APPLY (มัดจำ → ใบลดหนี้) ⇒ ยอดหักได้ลด · หมด = DEDUCTED · `postDocument` ข้ามใบลดหนี้ชนิดนี้ (ไม่ลง Dr รายได้/Cr ลูกหนี้)
  - คำเตือน `DEPOSIT_REFUND_CREDIT_NOTE` [V] (แจ้งให้ทราบ) — แสดงในกล่องยืนยันบนจอ · คืนใน `warnings[]` ของ REST
  - ยกเลิกใบลดหนี้ ⇒ กลับ JV + มัดจำกลับเป็นรอหัก (`releaseDepositDeductionsInTx`)
- ไม่มีใบกำกับ (ร้านไม่จด VAT · ปิดใบกำกับมัดจำ · รับยังไม่ครบ · ใบมัดจำจ่าย) ⇒ ทางเดิม (ยกเลิกใบ + กลับรายการ JV + ยกเลิกใบกำกับที่ค้าง)
- **ริบ** (`forfeitDeposit`, ใหม่) ค่าตั้ง `docConfig.deposit.forfeit` [U]:
  - `KEEP_VAT` (ค่าเริ่ม) ไม่ออกใบลดหนี้: JV Dr 2110 ฐาน / Cr 4900 รายได้อื่น (event FORFEIT ของใบรับมัดจำ) — VAT คงอยู่ · หมายเหตุภายในบนใบ
  - `CREDIT_NOTE`: ใบลดหนี้อ้างใบกำกับ (refType DepositForfeit) + JV Dr 2110 + Dr 2200 / Cr 4900 ยอดเต็ม
  - ทั้งสองแบบ: คำเตือน `DEPOSIT_FORFEIT_VAT` [U] ไม่ต้องยืนยัน + ต่อท้าย "โปรดตรวจกับนักบัญชีของร้าน" · ริบแล้วคืนไม่ได้ · ใบรับมัดจำ → DEDUCTED
  - บัญชีรายได้ = mapping `ASSET_DISPOSAL_GAIN` (4900 "รายได้อื่น / กำไรจากการจำหน่ายสินทรัพย์") — **skill เงียบเรื่องบัญชี เลือกเอง** (ผังไม่มีบัญชีรายได้อื่นแยก)
- **ยกเลิกใบรับมัดจำ** (`voidDocument`) ⇒ ใบกำกับของมัดจำที่ยังค้างมีผล (ออกเอง/รับไม่ครบ) ยกเลิกตาม + กลับ JV (ใบที่รับครบต้องยกเลิกรายการรับก่อน — ทางนั้นยกเลิกใบกำกับตาม T2.6 อยู่แล้ว)
- **มัดจำรับบางส่วน**: JV/ใบกำกับของมัดจำยังเกิดเมื่อรับครบ (T2.6 คงเดิม) · คืนตอนรับไม่ครบ = ทางเดิม (ไม่มีภาษีให้ลด) — สอดคล้องกัน · ใบกำกับต่องวดของมัดจำ = ยังไม่ทำ (คำถามเปิด)

## จอ / REST / AI
- หน้าใบรับมัดจำ: "คืนมัดจำ" (กล่องยืนยัน: วันที่ · เหตุผล · คำเตือน · บอกเลขใบกำกับที่จะอ้าง) · "ริบมัดจำ" (ปุ่มรอง)
- ตั้งค่า › เอกสาร › ใบกำกับภาษีอัตโนมัติ: "เงินมัดจำที่ออกใบกำกับแล้วถูกริบ" + สวิตช์ใบกำกับมัดจำ
- REST: `POST /documents/{id}/refund-deposit` (+ `date` · ผล `creditNote` · `warnings`) · `POST /documents/{id}/forfeit-deposit` · `GET /documents/{id}/deposit-settlement` · settings `depositForfeit`
- AI: `account_refund_deposit` · `account_forfeit_deposit` (อันตราย ยืนยัน 2 ชั้น) · `account_deposit_settlement` (อ่าน)
