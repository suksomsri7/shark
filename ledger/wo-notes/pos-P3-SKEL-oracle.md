## CONTROLLER-DECISION
- **CD-S1** Skeleton inbound auth = header `x-shark-signature`: lowercase hex HMAC-SHA256(raw body, creds.`webhookSecret`); `webhookSecret` is a required secret field of LINEMAN and GRAB. Real adapters replace it per platform spec (P3.1/3.2-real).
- **CD-S2** Secret box API `(obj, deps?{key})` / `(box, deps?{key})`, open returns null-ish (never throws); **no fallback key anywhere** (SK3 pins the production case; a dev fallback outside production is not tested but not wanted either — ruling 8 "missing key ⇒ refuse to save").
- **CD-S3** Credential save = patch/merge; `testIntegrationConnection` DRAFT ⇒ `NOT_CONFIGURED`, COMPLETE ⇒ `NOT_CONFIGURED`/`ADAPTER_PENDING`.
- **CD-S4** 4-eyes refusal code `PERMISSION_DENIED` or a new `SLIP_SELF_CONFIRM` (both accepted; pick one and add the messageKey).
- **CD-S5** Slip target shape (exactly one of payment / intent; intent slips have no saleId) and the 24 h window measured from `PosSale.paidAt` against `deps.now`.
- **CD-S6** Retention reader clamps `slipRetentionDays` to ≥ 90 (30 ⇒ 90) — the writer may refuse < 90; `purgeExpiredSlips({tenantId?, now?, deps?})`.
- **CD-S7** Reconcile: unit-scoped ctx · Thai date of `createdAt` · rows PAID/CONSUMED only · flag precedence REFUND_NEEDED > LATE > NEEDS_CHECK > OK · CSV header above · money in satang.
- **CD-S8** e-Tax XML minimal ETDA profile (root/element local-names above, baht 2 decimals) — ⚠️ the chosen provider confirms the exact profile; ET1 then gets its hash pin.
- **CD-S9** Print-agent wire (`?wait=0`, `{jobs:[…]}`, `{ok, error?}` ack, 401 rules, loopback allowed as printer host, +10 min expiry, `pollOnce` export, no auto-run on import).
- **CD-S10** Ops dedupe key = (channelId, C-7 method) per hour; INFO rows carry `tenantId`.
- **CD-S11** The oracle sets `POS_CREDENTIALS_KEY` (random) and, only if absent, `SESSION_SECRET` in its own process — the route has no `deps`.
- **CD-S12** Static base = 72669941 **or** merge-base with (origin/)session/pos.
