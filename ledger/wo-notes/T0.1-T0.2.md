## 2. รูปแถว (JSON ล้วน)
```
ร่วม:  { id, value: number|null, from: "YYYY-MM-DD"|null, to: "YYYY-MM-DD"|null,
         source: string, tag: "V"|"V2"|"S"|"U"|"SHOP", checkedAt: "YYYY-MM-DD"|null, note?: string }
VAT:   value = rateBp (มิติไม่มี — อัตรามาตรฐานตามวันที่จุดรับผิด)
WHT:   + incomeType ("M40_2" … / "M40_8:ADVERTISING" แบบมีข้อย่อย) · payer JURISTIC|NON_JURISTIC|ANY
         · recipient JURISTIC_TH|INDIVIDUAL_TH|FOUNDATION|FOREIGN|ANY · channel NORMAL|EWHT · method RATE|NONE|PROGRESSIVE
DEADLINE: + form PP30|PND1|PND2|PND3|PND53|PND54 · channel PAPER|ONLINE · value = วันที่ของเดือนถัดจากเดือนภาษี
```
วันที่ = วันตามปฏิทินไทย (Asia/Bangkok) เทียบเป็นข้อความ YYYY-MM-DD · from/to = null คือไม่มีขอบ (แหล่งไม่ระบุ)

## 3. ตัวอ่านเดียว
`src/lib/modules/account/legal-values.ts` (server):
```ts
legalValueAt(key: "vat.rate" | "wht.rate" | "filing.deadline", date: Date, ctx: {tenantId, systemId}, query?)
  → { value: number|null, method?, row: LegalRow|null, origin: "SHOP"|"SYSTEM"|null, warnings: LegalWarning[] }
```
ลำดับ: แถวร้านที่มิติตรง + ครอบวันที่ → แถวระบบที่ครอบวันที่ (เจาะจงกว่าชนะ · from ล่าสุดชนะ)
→ (WHT ช่องทาง EWHT ไม่มีแถวครอบ ⇒ ถอยไป NORMAL + เตือน `EWHT_NOT_IN_EFFECT`)
→ ไม่มีแถวครอบวันที่ ⇒ ใช้แถวใกล้สุด + เตือน `NO_ROW_FOR_DATE` (ไม่บล็อก) → ไม่มีเลย ⇒ value null + `NO_ROW`
คำเตือน (ไม่บล็อกเด็ดขาด): `SHOP_DIFFERS_FROM_DEFAULT` (แถวร้านต่างจากแถวระบบป้าย [V]/[V2] ที่ครอบวันเดียวกัน — อ้างที่มา) ·
`UNVERIFIED_DEFAULT` (แถวป้าย [S]/[U] → "โปรดตรวจกับนักบัญชีของร้าน") · `ENTITY_KIND_UNSET` (ยังไม่ระบุประเภทผู้ประกอบการ ⇒ ถือว่าผู้จ่ายเป็นนิติบุคคลเพื่อคงค่าแนะนำเดิม)
ตัวช่วยบาง ๆ บนตัวอ่านเดียวกัน: `vatRateBpAt` · `vatRuleOf` (อัตราที่ยอมรับ = {0, −1} ∪ อัตราทุกแถวในตาราง) · `whtSuggestionsAt` · `filingDeadlineOf` · `bookLegalOf` (โหลดครั้งเดียวต่อคำขอ)
T0.1: `entityKindOf(settings)` · `isJuristicPayer(kind) → true|false|null` (pure, ใน th-tax-2569.ts re-export ทาง account)
