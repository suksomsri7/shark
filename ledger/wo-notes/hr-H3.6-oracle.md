## 6. Numbering (engine reuse)
`account/wht.ts#issueWhtCert` numbers vendor 50 ทวิ with `openDocNumbering → deferDocNo(series configured WHT_CERT) → finalizeDocNos` (stamps `AccountDocument.docNo`, LOCK ORDER step 7). HR certificates are not AccountDocuments, so H3.6 calls the engine's counter directly: `reserveSeq(tx, {…, systemId: HR system, docType: "WHT_CERT", prefix, periodKey: "HR50:<CE year>", startNo: 1})` — the same single-statement `INSERT … ON CONFLICT DO UPDATE … RETURNING lastNo` — as the last lock of the issue tx (only the tx's own new certificate row is written after it), then `formatDocNo`. Namespaced periodKey ("HR50:" like WTI's "WTI:") ⇒ never collides with a configured series. No second engine: no other `AccountDocSequence`/`lastNo` SQL under `hr/**` (static S1.4).
