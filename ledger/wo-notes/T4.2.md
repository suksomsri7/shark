## 1. ตัดสินใจ
- ตัวกลาง `books-report.ts`: `bookHeaderOf` (ชื่อกิจการ = คำนำหน้า + ชื่อ · เลขผู้เสียภาษี · สาขา) · `journalBookPage` (REST หน้าละ ≤500 ใบ · 3 คิวรี/หน้า + count + aggregate) · `journalBookAll` (ใบพิมพ์: ก้อนละ 500 ใบด้วย cursor — **ไม่ตัด 200 ใบ** · เพดานความปลอดภัย 20,000 ใบ → แจ้งให้แบ่งช่วง ไม่ตัดเงียบ) · `ledgerBookAll` (ทุกบัญชีที่มียอดยกมา/เคลื่อนไหว) · `subsidiaryLedger` (AR/AP ตาม mapping × contactId บนบรรทัด GL · ผลรวมทุกราย = ยอดบัญชีคุม) · `paginateBookRows` (pure: เลขหน้า · ยอดยกมา/รวมหน้า/ยอดยกไป)
- ใบพิมพ์ทุกเล่มใช้ `BookPrintPages` — หัวทุกหน้า: ชื่อกิจการ · เลขผู้เสียภาษี · สาขา · ชนิดบัญชี · ช่วงวันที่ · "หน้า i / N" · ขึ้นหน้ากระดาษใหม่ต่อหน้า (break-after) — แบ่งหน้าที่ server (จำนวนแถวคงที่ต่อหน้า) แทน CSS counter (Chromium พิมพ์ตัวเลขใน margin box ไม่แน่นอน)
- สมุดรายวัน: ทุกบรรทัดของทุกใบ (รหัส+ชื่อบัญชี · คำอธิบาย · อ้างอิงเอกสาร · เดบิต · เครดิต) · เล่มเดียวหรือทุกเล่ม · ใบที่ถูกกลับรายการพิมพ์ด้วย (ป้าย "กลับรายการแล้ว") — สมุดต้องครบ · คำค้นของหน้ารายการไม่ใช้กับใบพิมพ์ (ค่าเริ่มต้นของระบบ: สมุดบัญชีต้องครบทุกรายการของช่วง)
- ส่งออก: ปุ่ม Excel (CSV + BOM) ทุกใบพิมพ์ · บรรทัดแรก = ชื่อกิจการ + ชนิดบัญชี + ช่วง · REST `reports.journal-book` / `reports.subsidiary-ledger` / `reports.general-ledger` (เดิม) รองรับ CSV
- ไฟล์แนบทั้งชุด (K5): **ไม่ได้ทำ zip** ในรอบนี้ (ต้องดึงไฟล์จากที่เก็บทีละไฟล์ + ไม่มีไลบรารี zip ใน dependency — ห้ามเพิ่ม dep) — รายการไฟล์ทั้งชุดอ่านได้ทาง REST `files.list` เดิม · เปิดเป็นข้อค้าง

## 2. ช่องทาง
- จอ: `/account/journal/print` (เขียนใหม่) · `/account/ledger/print` (ใหม่ · บัญชีเดียวหรือทุกบัญชี) · `/account/ledger/subsidiary?side=AR|AP` (ใหม่ · สรุปรายตัว + กดดูรายการของรายนั้น) · ลิงก์จากหน้าแยกประเภท
- REST: ใหม่ `reports.journal-book` GET `/reports/journal-book` (paged · CSV) · `reports.subsidiary-ledger` GET `/reports/subsidiary-ledger` (CSV)
- AI: เครื่องมือเดิม `account_report` เพิ่ม kind `journal-book` · `subsidiary-ledger` (ไม่มีชื่อเครื่องมือใหม่ — สกิล account เดิม)
