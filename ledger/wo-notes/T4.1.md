## 1. ตัดสินใจ
- ค่าตัวเลข 15 / 15 / 3 อยู่ในตารางค่ากฎหมายแถวใหม่ (`th-tax-2569.ts` `SYSTEM_BOOK_ROWS`: JOURNAL_ENTRY_DAYS · LEDGER_POST_DAYS_AFTER_MONTH · CASH_REPORT_WORKING_DAYS ป้าย [V] ที่มา + วันที่ตรวจ) · ร้านทับได้ที่ ตั้งค่า › อัตราภาษีและกำหนดยื่น (การ์ด "สมุดบัญชี · ค่าเสื่อม · รอบบัญชี") หรือ REST `settings.tax.update.bookRows` · อ่านด้วย `legalValueAt("book.rule")` / `bookRuleFrom`
- กติกาไหนใช้กับใคร (`jv-rules.jvLateBasis`): บจ./หจก.-หสน. = 15 วัน + 15 วันหลังสิ้นเดือน · บุคคลธรรมดา/ห้างสามัญไม่จด VAT = 3 วันทำการ · บุคคลธรรมดา/ห้างสามัญจด VAT = **ไม่เตือน** (ไม่อยู่ใต้ พ.ร.บ.การบัญชี และไม่อยู่ใต้ ฉ.161) · ยังไม่ระบุ/อื่น ๆ = ใช้กติกานิติบุคคล + รหัส `JV_LATE_ENTRY_ASSUMED` [S]
- **ค่าเริ่มต้นที่ skill ไม่บอก** (บันทึกไว้): การนับวัน = ไม่นับวันแรก (วันที่รายการ + N) · "วันทำการ" = จันทร์–ศุกร์ ไม่หักวันหยุดราชการ (skill ไม่มีปฏิทินวันหยุด ⇒ เตือนเร็วกว่าจริงได้ ไม่ช้ากว่า) · "วันที่บันทึก" = `createdAt` ของใบสำคัญ (ตอนสร้าง = `accountNow()`) เทียบกับ `date`
- คำอธิบายว่าง = `JV_DESCRIPTION_MISSING` **ต้องกดยืนยัน** (ไม่บล็อก — ยืนยันแล้วบันทึกผู้ยืนยันใน AuditLog `legal.warning.ack`) · ไม่มีไฟล์แนบ = `JV_NO_SUPPORTING_DOC` แจ้ง · ยังไม่อนุมัติ = `JV_UNAPPROVED` แจ้ง · ลงช้า = `JV_LATE_ENTRY` แจ้ง (ack=false · ไม่มีอะไรให้แก้ — ระบบเก็บทั้งสองวันที่)
- ผู้อนุมัติ: คอลัมน์ใหม่ `AccountJournalEntry.approvedById` + `approvedAt` · ปุ่ม "อนุมัติ" ในฟอร์ม = ผู้กดเป็นผู้อนุมัติทันที · "บันทึกร่าง" = ไม่อนุมัติ + ธง ⚑ "ร่าง — รอตรวจสอบก่อนปิดงวด" (`JV_DRAFT_FLAG_NOTE`) · อนุมัติภายหลัง (`approveJournalEntry`) ปลดธงร่างให้ (ธงที่คนติดด้วยเหตุอื่นไม่แตะ) · อนุมัติได้เฉพาะ JV มือ (ใบที่ระบบลงจากเอกสาร = อนุมัติที่เอกสาร) · ใบกลับรายการแล้ว/อนุมัติแล้ว = ปฏิเสธ (สถานะข้อมูล ไม่ใช่เหตุผลกฎหมาย) · สิทธิ์ = `account.journal.adjust` (ไม่เพิ่มสิทธิ์ใหม่ — ไม่แตะเมทริกซ์สิทธิ์) · ผู้อนุมัติคนเดียวกับผู้บันทึกได้ (skill ไม่ห้าม)
- ไฟล์แนบ: ช่อง `files` ของฟอร์มเดิมไม่เคยถูกอ่าน (บั๊กเดิม) — server action อัปโหลดจริง (ตรวจไบต์ · sha256 ซ้ำใช้แถวเดิม) แล้วผูก `refType=AccountJournalEntry` · REST ใช้ `attachmentIds` เดิม

## 2. ช่องทาง
- จอ: ฟอร์ม "สร้างสมุดรายวัน" (คำอธิบาย · ไฟล์ · คำเตือนล่วงหน้าตัวเดียวกับ server + ช่องติ๊กยืนยัน) → บันทึกแล้วไปหน้ารายละเอียด · หน้ารายละเอียด: "บันทึกเมื่อ … · อนุมัติโดย …/ยังไม่อนุมัติ" + คำเตือน + ปุ่ม "อนุมัติ"
- REST: `journal.create` (+`approve`, memo ว่าง → 409 `legal_ack_required` JV_DESCRIPTION_MISSING, คำตอบมี `warnings`, `approval`, `recordedAt`) · ใหม่ `journal.approve` POST `/journal/{id}/approve` · `journal.get` มี `approval` + `recordedAt` (คิวรีเท่าเดิม: ผู้บันทึก+ผู้อนุมัติใน findMany เดียว)
- AI: `account_post_journal` (เดิม) · ใหม่ `account_approve_journal` (สกิล account · ข้อเสนอ)
