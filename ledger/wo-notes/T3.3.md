## 1. หน้าพิมพ์ `/account/wht/<certId>/print` (เขียนใหม่ทั้งหน้า · ส่วนประกอบ `WhtCertForm`)
- โครงตามแบบทางการ: หัว (ฉบับ · ชื่อแบบ · ตามมาตรา 50 ทวิ · เล่มที่/เลขที่) → กล่องผู้หัก → กล่องผู้ถูกหัก → ลำดับที่ในแบบ + 7 ช่องชนิดแบบ (ติ๊กช่องเดียว) → ตารางประเภทเงินได้ 6 ข้อ (กรอกแถวของใบ · แถวอื่นว่าง) → รวม → รวมภาษีตัวอักษร (`bahtText` ตัวเดียวกับใบกำกับ) → กองทุน (ว่าง — สมุดบัญชีไม่ได้จ่ายเงินเดือน) → เงื่อนไข 4 ช่อง → คำเตือนของแบบ + ลงชื่อ/วันที่/ตรา
- ตัวเลขทั้งหมดมาจากตัวคิดล้วน `wht-cert-print.ts` (pure) → ข้อสอบเรนเดอร์ HTML ได้โดยไม่ต้องมีเซิร์ฟเวอร์
- **ฉบับ**: `?part=1|2|file|set` · ค่าเริ่มต้น `set` = 3 หน้าในงานพิมพ์เดียว: ฉบับที่ 1 · ฉบับที่ 2 · "สำเนาคู่ฉบับ (สำหรับผู้มีหน้าที่หักภาษี ณ ที่จ่าย เก็บไว้เป็นหลักฐาน)" — ข้อความ 2 ฉบับแรกตรงตามหัวแบบ [V] · ป้ายสำเนาคู่ฉบับ = ถ้อยคำของระบบ (แบบทางการพิมพ์แค่ 2 ฉบับ — skill บอกมีสำเนาคู่ฉบับแต่ไม่ให้ถ้อยคำ) [S]
- **ฝ่ายตามทิศของใบ**: IN (เราหักผู้ขาย) = ผู้หัก = ร้าน (ชื่อ ที่อยู่ เลข 13 หลัก สาขา จากสำเนาผู้ขายที่ตรึงไว้ T2.9 ถ้ามี ไม่งั้นค่าตั้งปัจจุบัน) · ผู้ถูกหัก = ผู้ติดต่อ (สำเนาที่ตรึงตอนออก)
  OUT (WTI — ลูกค้าหักเรา) = ผู้หัก = ลูกค้า · ผู้ถูกหัก = ร้าน · ไม่มีป้ายฉบับ · แถบบน "บันทึกของผู้ถูกหัก — หนังสือรับรองตัวจริงออกโดยผู้จ่ายเงิน" + สถานะรับแล้ว/ยังไม่ได้รับ (T3.5) — ค่าเริ่มต้นของระบบ (WTI ไม่ใช่หนังสือรับรองที่ร้านออก)
- ระบุ "บุคคล / นิติบุคคล" ตามที่แบบให้ระบุ (จาก legalType ของสำเนา · ร้าน = ประเภทผู้ประกอบการ T0.1)
- ชนิดแบบ + ลำดับที่: จากตัวจับแบบ T3.4 (`wht-forms.ts` + ตาราง `WHT_FORM_ROWS`) · ลำดับที่ = ลำดับของใบในรายการ ภ.ง.ด. เดือนนั้น (ตัวเดียวกับ CSV ช่วยกรอกแบบ ⇒ สอบยันได้) · ภ.ง.ด.1 → ติ๊ก (1) ภ.ง.ด.1ก และลำดับ = ลำดับผู้รับในรายการ 1ก ของปี · ภ.ง.ด.54 → ไม่ติ๊กช่องใด + หมายเหตุ "แบบไม่มีช่อง ภ.ง.ด.54" [U]
  - ลำดับที่คิดสด: ใบที่ยกเลิกออกจากรายการ ⇒ ลำดับใบหลังเลื่อน (ค่าเริ่มต้นของระบบ — เดือนที่ยื่นแล้วใช้ภาพใน AuditLog ของการยื่น)
- เล่มที่: skill/แบบไม่ได้บอกวิธีตั้ง ⇒ ค่าเริ่มต้นของระบบ = ปี พ.ศ. ที่ออก (เลขที่ = เลขเอกสารของระบบ ไม่ซ้ำ) [S]
- ประเภทเงินได้ → แถวของแบบ: M40_1 ข้อ 1 · M40_2 ข้อ 2 · M40_3 ข้อ 3 · M40_4 ข้อ 4(ก) · M40_5 M40_6 M40_7 M40_8 ข้อ 5 (ตามคำสั่ง ม.3 เตรส — ค่าเช่า ค่าวิชาชีพ จ้างทำของ บริการ) พร้อมระบุชื่อประเภทในวงเล็บ · ผู้รับบุคคลธรรมดาที่เป็น ม.50 (แบบ ภ.ง.ด.1/2) อยู่ข้อ 1–4 ตามมาตราอยู่แล้ว
- เงื่อนไข: ช่องใหม่ `AccountDocument.whtCondition` (1–4 · null = 1 หัก ณ ที่จ่าย) — ช่องร่วม: โหมดออกภาษีให้ (T3.6 เลน 1) เขียนช่องนี้ · ใบแทนแก้ได้
- **ใบยกเลิก**: สถานะ VOIDED/CANCELLED ⇒ ลายน้ำ "ยกเลิก" ทุกหน้า + บรรทัด "ยกเลิกเมื่อ … เหตุผล …" + ถ้ามีใบแทน "ออกใบแทนแล้ว เลขที่ …"
- **พิมพ์ครั้งต่อไป**: ใช้บันทึกการพิมพ์ของ T2.7 (`recordDocPrint` คำขอ SET) — ครั้งแรก = ชุด · ครั้งต่อไป = COPY ⇒ มุมบนแต่ละหน้า "พิมพ์ซ้ำครั้งที่ n" (ค่าเริ่มต้นของระบบ — ไม่ใช้คำว่า "สำเนา" เพราะชนกับ "สำเนาคู่ฉบับ") · เปิดตรงไม่มี `?p=` = บันทึกแล้ว redirect (ลิงก์ซ้ำไม่สร้างแถวใหม่ทุกครั้งที่รีเฟรช)

## 2. ยกเลิกแล้วออกใบแทน (F8)
- คำสั่งใหม่ `replaceWhtCert(ctx, certId, {reason, whtIncomeType?, whtCondition?, refreshPayee?})` (ใน `wht-cert.ts`):
  ใบเดิม (IN · ISSUED) → VOIDED + voidReason + `replacedById` · ใบใหม่: เลขใหม่ (ชุดเลข 50 ทวิ ตามเดือนของวันที่เดิม) · **วันที่เดิม** (= วันจ่าย) · ยอด/อัตรา/payment เดิม · ประเภทเงินได้/เงื่อนไขแก้ได้ · สำเนาผู้ถูกหักใหม่จากผู้ติดต่อปัจจุบันเมื่อ `refreshPayee` · หมายเหตุ "ออกแทนฉบับเลขที่ X ลงวันที่ Y (เหตุ …)" · `payment.whtCertDocId` ย้ายไปใบใหม่ · relation REPLACE
- คำเตือน `WHT_CERT_REPLACE` [U · ต้องยืนยัน] — "ใบเดิมเก็บไว้ประทับยกเลิก · เรียกฉบับที่ 1/2 คืนจากผู้ถูกหัก" · เดือนที่ยื่น ภ.ง.ด. แล้ว ⇒ ด่าน T1.7 `pndCertGuardInTx` (ยกเลิกใบเดิม + ออกใบใหม่ในเดือนเดียวกัน = `FILED_PERIOD_PND_CHANGE`)
- ช่องทาง: ปุ่ม "ยกเลิกและออกใบแทน" บนหน้าพิมพ์ (นอกกระดาษ) · REST `POST /wht/certs/{id}/replace` · เครื่องมือเลขา `account_wht_replace_cert`
