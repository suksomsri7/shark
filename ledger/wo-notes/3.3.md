## ความต่างจาก g5 (ตั้งใจ + เหตุผล)
1. **ปุ่ม "ค้นหา" ของกรมพัฒน์ฯ จาง + มีข้อความเหตุผลใต้ช่อง** แทนแถบผลสีฟ้าที่ g5 วาดไว้ —
   g5 วาดสถานะ "ยิงสำเร็จแล้ว" แต่ยังไม่มี `DBD_API_KEY` จริง (เจ้าของยังไม่สมัคร) · SPEC §7.2 สั่งไว้ตรง ๆ
   ว่า "ไม่ได้ = ปุ่มจาง+บอกเหตุ" · ตัวแถบผลสีฟ้า (`dbd-result` + ปุ่ม "ใช้ข้อมูลนี้") ทำครบแล้ว
   จะโผล่ทันทีที่ใส่กุญแจ (พิสูจน์ด้วย P4.1/P4.2 ที่ฉีด fetch ปลอม)
2. **ปุ่ม "ค้นหาด้วยชื่อ" จางถาวร** — DBD OpenAPI ไม่มี endpoint ค้นด้วยชื่อ (มีแต่เลขทะเบียน) ·
   ถ้าทำให้กดได้จะเป็นปุ่มหลอก (BLUEPRINT §0.3 ข้อ 9 ห้าม) · tooltip บอกเหตุ
3. **"ประเภทนิติบุคคล" กับ "คำนำหน้าบุคคล" เป็น 2 ช่องแยก** ตามที่ g5 วาด (ใบสั่งงานเขียนรวมเป็น
   `legalEntityType` ค่าเดียว) ⇒ schema มีทั้ง `legalEntityType` และ `personTitle` · ยึดภาพเป็นหลักตามด่าน parity
4. **"กลุ่มกำหนดเอง" เป็นชิปกดเลือก/ยกเลิก** (จากรายชื่อกลุ่มที่มีจริง) แทนชิป ✕ + ลิงก์ "+ เพิ่ม" ของ g5 —
   กลุ่มต้องมีอยู่ก่อน (สร้างจากแถบซ้ายของหน้าผู้ติดต่อ) การพิมพ์ชื่อกลุ่มใหม่ในโมดัลจะสร้างกลุ่มซ้ำได้ง่าย ·
   ส่วน "แท็ก" ทำเป็นชิป ✕ + "+ เพิ่ม" ตรงตาม g5 เป๊ะ (แท็กเป็นข้อความอิสระ)
5. **บล็อก "เชื่อมกับ" มีปุ่ม "ค้นหา" ข้างช่องสมาชิก** — g5 วาดสถานะที่ระบบเดาให้เสร็จแล้ว · ของจริงต้อง
   มีจังหวะสั่งค้น (ไม่ยิง DB ทุกตัวอักษร) · แถบผล + ปุ่ม "ใช่ คนเดียวกัน"/"ไม่ใช่" ตรงตามภาพ
6. **ช่อง "แชท" เป็น placeholder "ยังไม่เชื่อม"** ตรงตาม g5 — และเป็นสถานะจริง: ยังไม่มีเส้น `account→chat`
   ใน fitness allowlist + ใบสั่งงานห้ามแตะ `chat/**` (งานจริงคือให้ session แชทเซ็ต `ChatContact.partyId`)
7. **"รหัสไปรษณีย์" เป็นช่องพิมพ์ธรรมดา ไม่ auto จากตำบล** — รีโปไม่มีชุดข้อมูลตำบล/ไปรษณีย์ และห้ามเพิ่ม
   dependency ใหม่ · g5 เองก็เขียน placeholder "83000 (auto)" ไว้เฉย ๆ
8. **"เบอร์โทร" เป็นช่องบังคับ (`*`)** ตามที่ g5 วาด (g5 โชว์สถานะ error "จำเป็นต้องกรอก" ของช่องนี้) —
   SPEC §7.2 ตัวหนังสือไม่ได้ระบุว่าบังคับ · ยึดภาพ · ผลข้างเคียง: แก้ไขผู้ติดต่อเก่าที่ไม่มีเบอร์ ต้องเติมเบอร์ก่อนบันทึก
9. ภาพที่ถ่ายมี "ช่องว่างขาว" ใต้เนื้อหาหน้าหลัง + toast อยู่กลางจอ — เป็นผลของเทคนิคถ่ายภาพ
   (`expandModalForShot` เปลี่ยน overlay `fixed`→`absolute` เพื่อให้ fullPage เห็นโมดัลทั้งตัว) ไม่ใช่ของจริงบนจอ
