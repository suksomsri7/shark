## 2. Schema (เพิ่มอย่างเดียว · migration ใช้กับฐานของเลนนี้เท่านั้น)

## 3. ชนิดบรรทัด
ลำดับ: ค่าที่ผู้ใช้เลือกบนบรรทัด → ชนิดสินค้าในทะเบียน (`AccountProduct.type`: GOODS/BUNDLE → สินค้า · SERVICE → บริการ) → ชนิดเริ่มของใบ (`vatTiming` ON_PAYMENT → บริการ · อื่น → สินค้า)
- ทุกทางสร้างบรรทัด (createDocument · updateDocument · ฟอร์ม V2 · REST · แปลงเอกสาร · นำเข้า) เขียน `lineKind` ที่ resolve แล้ว · ฟอร์มมีตัวเลือกต่อบรรทัด "สินค้า/บริการ"

## 4. จุดรับผิดต่อบรรทัด (ใบแจ้งหนี้)
VAT ต่อบรรทัด = breakdown ของ `computeTotals` (รวมส่วนลดท้ายบิลแล้ว) → แบ่ง `ยอด VAT ที่พัก = vatAmount − VAT ส่วนมัดจำ` เป็น สินค้า/บริการ ตามน้ำหนัก (largest remainder · ผลรวม = ยอดพักเป๊ะ)
- ออกใบแจ้งหนี้: Cr 2205 (สินค้า) · Cr 2210 (บริการ) — แยกตามบรรทัด (เดิมก้อนเดียวตามทั้งใบ)
- **ใบกำกับพร้อมกัน** (ในธุรกรรมเดียวกับการออกใบแจ้งหนี้): ครอบคลุมชนิดที่ "ออกตอนออกใบ"
  - สวิตช์ต่อใบ `autoTaxInvoice = true` ⇒ ทุกบรรทัด (สินค้า + บริการ — บริการ = "ออกใบกำกับก่อน" ม.78/1(1)(ก))
  - `false` ⇒ ไม่ออกตอนนี้ (สินค้าพักค้าง + คำเตือนข้ามเดือน · บริการตามโหมดรับเงิน)
  - `null` (ตามค่าตั้ง) ⇒ สินค้า ถ้า `goodsOnIssue` (ค่าเริ่ม เปิด) · บริการ ถ้าโหมด = ON_INVOICE
  - ใบกำกับที่สร้าง: TAX_INVOICE ISSUED · sourceDocId = ใบแจ้งหนี้ · บรรทัด = สำเนาบรรทัดของชนิดที่ครอบ · VAT = ยอดพักที่ปล่อย · JV Dr 2205/2210 ตามชนิด · Cr 2200 ลงวันที่ใบแจ้งหนี้ (คีย์เดียวกับ postTaxInvoice — ไม่โพสต์ซ้ำ)
- **รับชำระ** (โหมด ON_PAYMENT ค่าเริ่ม): ใบกำกับต่องวด ปล่อยเฉพาะ VAT บริการ: `min(คงพักบริการ, round(VAT บริการทั้งใบ × ยอดตัดหนี้/ยอดใบ))` · งวดที่ชำระครบ = ปล่อยที่เหลือทั้งหมด (ผลรวม = VAT บริการเป๊ะ) · ใบบริการล้วนสูตรเดิม (ฐาน = ยอดตัดหนี้ − VAT) ต่างแค่ปัดเศษงวดสุดท้าย
- **ยอดคงพัก** อ่านจาก GL จริง: Σ(Cr−Dr) ของ 2205/2210 ใน JV ของใบแจ้งหนี้ + ใบกำกับที่อ้างใบนั้น (รวมรายการกลับ) — ใช้ทั้งการปล่อย คำเตือน และรายงาน ⇒ ข้อมูลเก่าก็ถูก
- ใบกำกับที่ร้านกดออกเอง (แปลง IV→TX): ร่าง = ยอดที่ยังพัก (ถ้ามีใบกำกับไปแล้วบางส่วน) · ด่านกันซ้ำของต้นทางใบแจ้งหนี้เปลี่ยนเป็น "ยังมี VAT พักเหลือไหม" (เดิม: มีใบกำกับแล้ว 1 ใบ = ห้าม) · ตอนลงบัญชีแบ่งตามยอดคงพักแต่ละชนิด
- ใบเสร็จขายสด: VAT เข้า 2200 ตอนออกอยู่แล้ว (ไม่พัก) — สวิตช์ `true` = ออกเอกสารใบกำกับจากใบเสร็จพร้อมกัน (ไม่มี JV เพิ่ม) · ค่าเริ่ม = ไม่ออก (คงเดิม)

## 5. ยกเลิก
- ยกเลิกใบแจ้งหนี้ที่มีใบกำกับ (ที่ไม่ได้มาจากงวดรับเงิน) ⇒ ยกเลิกใบกำกับเหล่านั้นในธุรกรรมเดียวกัน + กลับรายการ JV ⇒ 2205/2210/2200 กลับเป็นศูนย์ · ใบกำกับของงวดรับเงินถูกยกเลิกตามการยกเลิกรับชำระ (เดิม)
- ยกเลิกใบกำกับใบเดียว ⇒ VAT กลับไปพัก (และขึ้นในรายการค้างพัก)

## 7. คำเตือน + รายการ VAT ค้างพัก
- ทะเบียน: `OUTPUT_VAT_PARKED_PAST_MONTH` (ป้าย V · ม.78, ม.86 · ack=false — แจ้งให้ทราบ ไม่บล็อก) "ภาษีขายของสินค้า ฿X ในใบ … ยังพักอยู่ข้ามเดือน…"
  และ `TAX_INVOICE_BACKDATE_CHOICE` (ป้าย U · ack=true ตอนปล่อยแบบย้อนวันที่) อธิบายผลของ 2 ทางเลือก
- ตัวอ่าน `parkedOutputVat(ctx, { asOf })` (`account/tax-point.ts`): ต่อใบแจ้งหนี้ — คงพักสินค้า/บริการ · วันที่ · อายุ (วัน) · ข้ามเดือนไหม · คำเตือน · รวม
- จอ: หน้า "ภาษีขายค้างพัก" (`/account/tax/parked-vat`) + คำเตือนบนหน้าใบแจ้งหนี้ (LegalWarnings คอมโพเนนต์เดียว) · REST `GET /reports/parked-vat` · AI (op มี tool)
- **ปล่อยของเก่า** `releaseParkedVat(ctx, invoiceIds, { date: "TODAY" | "INVOICE_DATE", kinds?, ack })`: ออกใบกำกับของยอดที่ยังพัก (ทีละใบ/เป็นชุด) · วันที่ = ร้านเลือก ไม่มีค่าเริ่ม (skill เงียบ) · คำเตือนบอกผล: วันที่ใบแจ้งหนี้ = ภาษีเข้าเดือนเดิม (ถ้ายื่นแล้วอาจต้องยื่นเพิ่มเติม) · วันนี้ = เข้าเดือนนี้ แต่จุดรับผิดตาม ม.78 อยู่เดือนเดิม → โปรดตรวจกับนักบัญชี · REST `POST /documents/{id}/release-vat`
