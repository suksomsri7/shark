## ไฟล์ในโฟลเดอร์

- `NN-*.png` — ภาพที่เรนเดอร์แล้ว (ตรวจด้วยตาทุกใบ)
- `NN-*.html` — ไฟล์ที่เปิดดูได้จริงในเบราว์เซอร์ (self-contained ไม่ต้องต่อเน็ต)
- `NN-*.body.html` — เนื้อหาเฉพาะส่วน body (ไฟล์ต้นทางที่แก้)
- `_base.part` — CSS + ชุดไอคอน SVG ยกมาจาก `docs/design/account-v2/mockup.html` ที่เจ้าของเคาะแล้ว (ห้ามคิดจานสีใหม่)
- `_kb.part` — CSS เพิ่มเฉพาะบอร์ดงาน (คอลัมน์/การ์ด/ป้าย/หลังการ์ด/ปฏิทิน/ตัวสร้างกฎ)
- `mk.sh` — สคริปต์ประกอบ: `./mk.sh 02-board.body.html "ชื่อหน้า"` → ได้ `02-board.html`
