# ข้อสอบที่ "เขียนแล้วแต่ยังไม่เป็นด่าน CI"

ชุดในโฟลเดอร์นี้เขียนแบบ **contract-first** (เขียนก่อนโค้ด) ตาม `ledger/PLAN-CHAT-V2.md`
จึงยังแดงเป็นปกติจนกว่ารอบของมันจะเสร็จ

🔴 **ทำไมไม่วางไว้ใน `scripts/` ตรง ๆ**
`qc:all` ค้นโฟลเดอร์ `scripts/` เอง ⇒ วางไว้ที่นั่น = **CI แดงค้างหลายวันระหว่างทำ**
ซึ่งเป็นต้นเหตุของเหตุการณ์ 19 ส.ค. 2026 พอดี (ชุดแดงค้างเป็นสัปดาห์จนไม่มีใครดูอีก)
**ด่านที่แดงตลอดเวลา = ด่านที่ถูกเมิน = ไม่ต่างจากไม่มีด่าน**

⛔ **ทางที่ห้ามใช้เด็ดขาด**: ทำให้ชุดเหล่านี้ "ข้ามแล้วเขียว" ตอนโค้ดยังไม่มี
นั่นคือไม้บรรทัดที่โกหก ซึ่งแพงกว่าการไม่มีไม้บรรทัด

## วิธีใช้
- รันมือระหว่างพัฒนา: `pnpm tsx scripts/pending/qc-chat-v2-list.mts`
- **พอรอบไหนเสร็จและชุดนั้นเขียวครบ → `git mv` เข้า `scripts/` ทันที** (กลายเป็นด่าน CI ถาวร)
- คนที่ย้ายเข้าคือ Fable ตอนประกอบงาน ไม่ใช่สายงาน
