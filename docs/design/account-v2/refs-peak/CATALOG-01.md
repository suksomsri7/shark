- ปุ่ม/action: dropdown level1 (บนลงล่าง): ดูภาพรวม, ใบสั่งซื้อ›, ใบจ่ายเงินมัดจำ›, บันทึกซื้อสินค้า›, บันทึกค่าใช้จ่าย›, ใบสั่งซื้อสินทรัพย์›, ซื้อสินทรัพย์›, ใบกำกับภาษีซื้อ›, รับใบลดหนี้›, รับใบเพิ่มหนี้›, ใบรวมจ่าย›, นำเข้าเอกสาร (ไอคอนแยก) — ยังไม่ได้ hover เข้า submenu ใด (ไม่มี level2 เปิดในภาพนี้)
- ฟอร์ม: ไม่มี
- ตาราง: ไม่มี (พื้นหลังเป็นหน้า dashboard รายรับเดิมที่เบลอ)
- สถานะ/ป้าย: ไม่มี chip ในภาพนี้ (ยังไม่เปิด submenu สถานะ)
- น่าเอามาใช้: 1) โครงเอกสารฝั่งรายจ่ายครบวงจรคู่ขนานฝั่งรายรับ: ใบสั่งซื้อ→ใบจ่ายเงินมัดจำ→บันทึกซื้อสินค้า→บันทึกค่าใช้จ่าย→ใบสั่งซื้อสินทรัพย์→ซื้อสินทรัพย์→ใบกำกับภาษีซื้อ→รับใบลดหนี้/เพิ่มหนี้→ใบรวมจ่าย 2) แยก "บันทึกซื้อสินค้า" กับ "บันทึกค่าใช้จ่าย" เป็นคนละประเภท (สินค้าคงคลัง vs ค่าใช้จ่ายทั่วไป) และแยก "ใบสั่งซื้อสินทรัพย์"/"ซื้อสินทรัพย์" ออกจากการซื้อสินค้าปกติ (สำหรับ fixed asset) 3) "ใบรวมจ่าย" คู่กับ "ใบวางบิล" ฝั่งรายรับ — รวมหลายรายการจ่ายเป็นชุดเดียว
