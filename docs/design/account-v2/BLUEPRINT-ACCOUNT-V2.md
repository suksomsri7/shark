### 0.3 หลัก "ง่าย simple" ที่ใส่เพิ่มจาก PEAK (ฟีเจอร์ที่ทำให้ดีกว่า)
1. **โหมดง่าย / โหมดนักบัญชี** สวิตช์เดียวทั้งโมดูล (เก็บต่อผู้ใช้): โหมดง่ายซ่อนช่อง บัญชี/WHT/ประเภทราคา/สมุด ให้ค่าเริ่มต้นทำงาน · โหมดนักบัญชีเห็นทุกช่อง (= สลับ พื้นฐาน|ขั้นสูง ของทุกฟอร์มพร้อมกัน)
2. **เช็กลิสต์เริ่มต้น 5 ขั้น** บนหน้าหลัก (ตั้งค่ากิจการ → เพิ่มช่องทางเงิน → เพิ่มลูกค้า/สินค้า → ออกเอกสารใบแรก → เชื่อมระบบ) หายเมื่อครบ
3. **สร้างด่วน ⌘K / ปุ่ม +** ทุกหน้า: พิมพ์ "ใบแจ้งหนี้ ณัฐพล 24900" → เปิดฟอร์มเติมให้
4. **งานที่รอคุณ** (มีในแบบ) + **แจ้งเตือนอัตโนมัติ**: ครบกำหนดพรุ่งนี้ · พ้นกำหนด · ใบกำกับซื้อยังไม่ได้รับ · เช็คถึงกำหนด · ภ.พ.30 ใกล้ยื่น (ผ่าน AppNotification + LINE ทีมงานที่มีอยู่)
5. **ส่งให้ลูกค้าทางที่ลูกค้าอยู่**: ปุ่ม "ส่ง" เลือก อีเมล / LINE (ผ่านห้องแชทที่ผูก Party) / ลิงก์+QR PromptPay → ลูกค้าจ่ายแล้ว **กระทบยอดอัตโนมัติ** (webhook PromptPay ที่แพลตฟอร์มมี)
6. **AI ช่วย 3 จุดที่คนเบื่อ**: อ่านบิลจากรูป (มี) → บันทึกค่าใช้จ่าย · จับคู่รายการเดินบัญชี · สรุป "ภาษีเดือนนี้ต้องยื่นเท่าไร" เป็นภาษาคน
7. **เอกสารประจำ (recurring)**: ใบแจ้งหนี้รายเดือน (ค่าเช่า/ค่าบริการ) สร้างร่างอัตโนมัติ + เตือน
8. **ยกเลิกได้ปลอดภัย**: ทุก "ยกเลิก/void" = reversal ไม่ลบ · มี "เลิกทำ" 5 นาที (soft-undo) ในการกระทำที่ไม่กระทบเลขรัน
9. **ภาษาคนทุกที่**: ไม่มี enum · error บอกวิธีแก้ · tooltip (?) ทุกหัวคอลัมน์บัญชี · empty state = สอน 1 ประโยค + ปุ่ม
10. **มือถือทำงานได้จริง** ไม่ใช่แค่ดู: สร้างเอกสาร/รับชำระ/ถ่ายบิล/อนุมัติ จากมือถือ
