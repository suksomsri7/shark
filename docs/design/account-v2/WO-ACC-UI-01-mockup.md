## 1. ทิศทางออกแบบ (ตัดสินแล้ว — ไม่ต้องถามซ้ำ)

**"โครงเมนูและหน้าจอ = PEAK · สี/ตัวอักษร/ปุ่ม/การ์ด = SHARK"**

- **เอาจาก PEAK**: แถบเมนูหลัก 9 หมวดแนวนอนพร้อมเมนูย่อยแบบ dropdown · หน้าแรกเป็น dashboard มีกราฟ · หน้า "ดูภาพรวม" ของรายรับ/รายจ่าย/การเงิน · หน้ารายการเป็น **ตารางจริง** มีแท็บสถานะ+ตัวกรอง+ค้นหา+หน้า (pagination) + ปุ่ม "ทำรายการ ▾" ต่อแถว · ผู้ติดต่อมีคอลัมน์กลุ่มซ้าย · สินค้ามีแท็บ สินค้า/บริการ/จัดชุด · ผังบัญชีเป็น tree ซ้าย + รายละเอียดขวา · คลังเอกสารมีแท็บ "ยังไม่ออกเอกสาร" + list/grid + thumbnail · ตั้งค่าเป็น accordion ซ้าย + เนื้อหาขวา
- **ไม่เอาจาก PEAK**: สีม่วง/ฟ้าไล่เฉด · ป้าย NEW สีส้ม · ปุ่มกลม pastel · จานสีกราฟหลายสี · ป๊อปอัปสอนใช้งาน · ปุ่ม Intercom
- **SHARK skin** (จาก `globals.css` + chat-v2 mockup): พื้นขาว `#fff` · พื้นรอง `#fafafa` · ตัวอักษร `#0a0a0a` / รอง `#404040` / muted `#737373` · เส้น `#e5e5e5` · **accent เดียว `#1d4ed8`** (แท็บ active, ลิงก์, series หลักของกราฟ, จุดเน้น) · danger `#b91c1c` เฉพาะ "พ้นกำหนด/ติดลบ/ผิดพลาด" · ฟอนต์ `'Noto Sans Thai'` · ปุ่มหลัก = พื้นดำตัวขาว `rounded-lg` · ปุ่มรอง = ขอบเทาพื้นขาว · การ์ด `rounded-xl border` ไม่มีเงาหนัก · chip สถานะ = ขอบเทาโทนเทา/ดำ/แดงเข้ม (ตาม `StatusChip` 3 tone)
- **กราฟ** (เรียก skill `dataviz` ก่อนวาด): ใช้ได้แค่ accent + เฉดเทา (`#0a0a0a`, `#737373`, `#d4d4d4`, `#e5e5e5`) + danger สำหรับ "พ้นกำหนด" เท่านั้น · ห้ามเขียว/ส้ม/ม่วง · ค่าบวก/ลบบอกด้วยเครื่องหมายและตัวหนา ไม่ใช่สี · แกน/กริดบาง · ตัวเลขบนแกนเป็น `฿` ย่อ (เช่น ฿120k)
- **ตัวเลขทั้งหมดในแบบเป็นข้อมูลสมมติของ "ร้านดำน้ำ SIAM DIVE CENTER"** (ทริป/คอร์ส/ค่าเช่าอุปกรณ์/ค่าเรือ/ค่าน้ำมัน) — ให้ดูสมจริงและสอดคล้องกันทุกเฟรม (ยอดเดียวกันต้องเท่ากันทุกที่ที่โผล่) · ห้ามใส่ข้อมูลจริงจาก DB
- ภาษา: ไทยล้วน ไม่มี enum/jargon · เงิน `฿12,500.00` ในตาราง/เอกสาร · `฿12.5k` เฉพาะแกนกราฟ
- **ของที่ SHARK มีแต่ PEAK ไม่มี ต้องอยู่ในแบบให้เห็น** (inventory §E): aging 5 ช่วงอายุ · ปิดงวดอัตโนมัติ · เช็ครับ/จ่าย · WHT 2 ขา + 50 ทวิ + ภ.ง.ด.3/53 · ภ.พ.30 · จุดรับรู้ VAT · ลิงก์/QR ขอใบกำกับ · เงินไหลจาก POS/CRM/HR/คลัง · AI บันทึกค่าใช้จ่าย · ธง "ต้องตรวจ" (needsReview) · ทะเบียนสินทรัพย์+ค่าเสื่อม

## 2. โครงหน้าจอร่วม (ทุกเฟรมเดสก์ท็อป 1440×900)

```
┌ Topbar h-56 (ของแอปเดิม: ☰ · "SIAM DIVE CENTER")  ──────────────────────────────┐
│ NavDrawer ปักซ้าย w-288 (ของแอปเดิม: รายชื่อระบบ · "บัญชี" active)             │
│   ┌ พื้นที่โมดูลบัญชี ──────────────────────────────────────────────────────┐ │
│   │ แถบเมนูบัญชี 9 หมวด (ไอคอนเส้น + ป้าย) — active = ตัวหนา+ขีดล่าง accent    │ │
│   │ [หน้าหลัก][รายรับ▾][รายจ่าย▾][ผู้ติดต่อ▾][สินค้า▾][การเงิน▾][บัญชี▾][คลังเอกสาร▾][ตั้งค่า▾] │
│   │ breadcrumb เล็ก (บัญชี › รายรับ › ใบแจ้งหนี้)                               │ │
│   │ PageHeader: h1 + ปุ่ม action ขวา                                           │ │
│   │ เนื้อหา ...                                                                │ │
│   └────────────────────────────────────────────────────────────────────────┘ │
└──────────────────────────────────────────────────────────────────────────────┘
```

- วาด Topbar + NavDrawer ให้ "พอรู้ว่าเป็นของเดิม" (เทาอ่อน ตัวอักษรจาง) — จุดโฟกัสคือพื้นที่โมดูล
- แถบเมนูบัญชีแทนที่ SubNav sidebar 200px เดิม (UI_STANDARD §2.9/§4 จะถูกอัปเดตตอน coding — จดไว้ใน SITEMAP)
- dropdown เมนูย่อย: การ์ดขาว ขอบเทา เงาบาง กว้าง ~260px รายการสูง 40px · รายการที่ยังไม่มี (🕓) ให้ตัวจาง+ป้าย "เร็ว ๆ นี้"
- **มือถือ 390×844**: Topbar เดิม (☰ เปิด drawer ระบบ) · แถบเมนูบัญชี 9 หมวดเลื่อนแนวนอนใต้ Topbar (ไอคอน+ป้ายสั้น) · แตะหมวดที่มีเมนูย่อย = **bottom sheet** รายการเมนูย่อย (ไม่ใช่ hamburger ซ้อน hamburger) · ตารางยุบเป็นการ์ดแถว (`DataList`) · การ์ด KPI 2 คอลัมน์ · กราฟกว้างเต็มจอ
