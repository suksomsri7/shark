# เปิดใช้ "ข้อความเด้งทันที" (realtime) — คู่มือสำหรับเจ้าของร้าน

> WO-CV9 · มติ V4 "ใช้บริการสำเร็จรูป" · ผู้ให้บริการที่เลือกใช้: **Ably**

## สรุปสั้นที่สุด

ตอนนี้กล่องแชท **ใช้งานได้ครบอยู่แล้ว** โดยไม่ต้องทำอะไรเลย —
หน้าจอดึงข้อมูลใหม่ให้เองทุก 5 วินาที (โหมด `polling`)

ถ้าอยากให้ข้อความ **เด้งทันทีแทนที่จะรอถึง 5 วินาที** ให้ทำ 3 ขั้นด้านล่าง
ใช้เวลาประมาณ 5 นาที และ **ไม่มีค่าใช้จ่าย** ในแพ็กเริ่มต้น

---

## ขั้นที่ 1 — สมัคร Ably (ฟรี)

1. เข้า https://ably.com แล้วสมัครบัญชี
2. สร้าง App ใหม่ (ตั้งชื่ออะไรก็ได้ เช่น `shark-chat`)
3. เข้าเมนู **API Keys** ของ App นั้น
4. คัดลอกกุญแจของ key ตัวแรก (ชื่อ `Root`) — หน้าตาประมาณ
   `AbCdEf.GhIjKl:MnOpQrStUvWxYz01234567`

> แพ็กฟรีของ Ably ให้ 6 ล้านข้อความต่อเดือน — ร้านขนาดปกติใช้ไม่ถึงเศษเสี้ยว
> เพราะระบบส่งออกไปแค่สัญญาณ "ห้องนี้มีของใหม่" ไม่ได้ส่งเนื้อความ

## ขั้นที่ 2 — ตั้งค่าบน Vercel

1. เปิดโปรเจกต์ `shark-in-th` บน Vercel → **Settings → Environment Variables**
2. เพิ่มตัวแปรชื่อ (ตัวพิมพ์ใหญ่ทั้งหมด สะกดตรงเป๊ะ):

   ```
   ABLY_API_KEY
   ```

3. วางกุญแจจากขั้นที่ 1 เป็นค่า
4. เลือกให้มีผลกับ **Production** (จะใส่ Preview ด้วยก็ได้)
5. กด Save

## ขั้นที่ 3 — ไม่ต้องทำอะไรต่อ

**ไม่ต้อง redeploy** — ระบบตัดสินโหมด "ตอนใช้งานจริง" ไม่ใช่ตอนสร้างเวอร์ชัน
ตั้งค่าเสร็จแล้วรอสักครู่ (เครื่องที่กำลังทำงานอยู่หมุนเวียนใหม่ตามปกติ)
แล้วเปิดกล่องแชทใหม่อีกครั้ง ข้อความจะเริ่มเด้งทันที

---

## สิ่งที่ Ably ได้รู้ และสิ่งที่ Ably **ไม่มีวัน** ได้รู้

| Ably ได้รู้ | Ably ไม่ได้รู้ |
|---|---|
| ร้านไหน · ระบบแชทตัวไหน · ห้องไหน มีของใหม่เมื่อไหร่ | **เนื้อความที่ลูกค้าพิมพ์** |
| มีคนกำลังพิมพ์อยู่ในห้องไหน (พร้อมเวลาหมดอายุ) | **ร่างที่ทีมกำลังพิมพ์** |
| ลูกค้าอ่านข้อความแล้วหรือยัง | ชื่อ · เบอร์ · อีเมลลูกค้า · ไฟล์แนบ |

ระบบกรองสิ่งที่ส่งออกด้วย **บัญชีขาว** ที่ขอบทางออก (`src/lib/realtime/events.ts`)
ต่อให้วันหน้ามีใครเผลอส่งเนื้อความมาที่ชั้นนี้ ของนั้นจะถูกทิ้งก่อนออกจากเซิร์ฟเวอร์เสมอ
เนื้อความจริงถูกดึงจากเซิร์ฟเวอร์ของเราเองผ่านเส้นทางที่มีด่านสิทธิ์ครบทุกครั้ง

---

## ถ้าอยากปิด / เปลี่ยนใจ

ลบตัวแปร `ABLY_API_KEY` ออกจาก Vercel — ระบบกลับไปโหมด `polling` เอง
**ไม่ต้อง redeploy และไม่มีอะไรพัง** (ทุกอย่างยังใช้งานได้ครบเหมือนวันนี้)

## ถ้าตั้งแล้วแต่ยังไม่เด้ง

เรียงจากที่เจอบ่อยที่สุด:

1. กุญแจถูกวางไม่ครบ — ต้องมีเครื่องหมาย `:` อยู่ตรงกลางเสมอ
2. ตั้งไว้เฉพาะ Preview ไม่ได้ตั้งใน Production
3. โควตาเดือนนั้นหมด — ระบบ **ไม่แจ้งเตือนบนจอโดยตั้งใจ** และตกกลับไปใช้ 5 วินาทีเหมือนเดิม
   (ดูโควตาได้ที่หน้า Dashboard ของ Ably)

ทุกกรณีข้างบน **ไม่ทำให้ข้อความหายและไม่ทำให้ส่งข้อความไม่ได้** — อย่างแย่ที่สุดคือช้าลงเป็น 5 วินาที
