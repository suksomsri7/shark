# SHARK Secretary API (แอปมือถือ · `/api/mobile/*`)

> สัญญา route ของเลขา AI · ใบ S0.3 · 4 พ.ย. 2569 · สัญญาข้อมูล/ฟังก์ชันอยู่ที่ `docs/modules/31-secretary.md` (§5) · คำตัดสิน `ledger/secretary-briefs/sec-brief-RESOLUTIONS.md`
> ใบที่สร้าง route: S1.14 (secretary/* · account/delete) · S1.21 (inbox/*) · S1.19 (auth/sms/*) · S1.25 (tenants/from-app · staff/*) · S1.17 (help/*) · ตารางนี้ = ของที่ route ต้องตรง (ใบนั้นแก้ตารางนี้เมื่อของจริงต่าง)

## กติการ่วม
1. **Auth**: `Authorization: Bearer <mobile token>` (`issueMobileToken` · `src/lib/mobile/auth.ts`) ทุกเส้น ยกเว้น `auth/sms/*` (ก่อนล็อกอิน) · เส้นระดับกิจการต้องมี `x-tenant-id` → `requireMobile` (Membership `acceptedAt ≠ null` + ร้านไม่ SUSPENDED/CLOSED) · เส้นระดับผู้ใช้ (`secretary/me`, `secretary/inbox`, `account/*`) ใช้ `mobileUser`/`requireMobileUser` (แผน)
2. **มองไม่เห็น = 404** (`not_found`) ไม่ใช่ 403 · ไม่มีสิทธิ์ทำ = 403 `forbidden` พร้อมข้อความไทยไม่โทษผู้ใช้
3. **Rate limit** ด้วย `checkRateLimitDb` (`src/lib/core/rate-limit-db.ts`) ต่อผู้ใช้ (หรือเบอร์+IP สำหรับ OTP) · เกิน = 429 + `Retry-After`
4. **Body** zod `.strict()` · เพดาน 64 KB (แนบไฟล์ 10 MB ผ่าน `inbox/attachments` เท่านั้น) · เขียนที่ส่งซ้ำได้ใช้ `clientMessageId`
5. **DTO ไม่มี** token/micro-dollar/ต้นทุน/คีย์/รหัส OTP/codeHash/credentials ช่องทาง/prompt (X10) · ตัวเลขผู้ใช้ = งาน · % · นาที
6. **รูปตอบ**: สำเร็จ `200 { ...dto }` · ล้มเหลว `{ error: code, message: "<ไทย>" }` (`mobileError` เดิม) · list = `{ items, nextBefore }` (cursor `before` = ISO ของแถวสุดท้าย)
7. เวลา ISO-8601 UTC · เงินเป็นสตางค์ · แชทลูกค้า: `systemId?` ไม่ส่ง = ระบบแชทตัวแรก (`resolveChatSystemId`) · ด่านสิทธิ์ใช้ค่าคงที่ `CHAT_READ_ACTION` (guard.ts) และ `"chat.message.send"` (permissions.ts) ที่ import มา (R-K13/R-K14)

## หมายเหตุ
- ห้อง AI รุ่น 1.0 (`/api/mobile/conversations/*` · `/api/mobile/chat/send` SSE · `/api/mobile/proposals/*` · `/api/mobile/plans/*`) คงเดิมทุกตัวอักษร (COMMON §C.11) · แอปจอใหม่ใช้ `/api/mobile/secretary/*` เท่านั้น

  - แชทลูกค้า (S1.24): `/inbox/<convId>?e=helper` (ถูกเรียกช่วย) · `?e=handoff` (ถูกส่งต่อ) · `?e=assigned` (กฎรับเรื่องมอบหมายให้) · `?e=sla` (เตือน/ย้ายเพราะรอนาน) — `e` แยกเรื่องให้ตัวกันสแปม 60 วิของ `notifyUser` (ผูก link) ไม่กินแจ้งเตือนเรื่องที่ต่างกัน · แอปอ่านแค่ path ก็พอ
- เส้นใดเรียกโมเดล (`rooms` POST · `rooms/[id]/send` · `proposals/[id]/reject` (RULE ให้เลขาแก้)) — คิดเงินผ่าน `chargeUsageSafe` และนับงานเฉพาะ `rooms` POST (R-K6)
